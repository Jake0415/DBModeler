# 웹 데이터 모델러 — 기능 인벤토리 (v1)

> 상태: **기획 초안 (1차 — 기능 정리)**. 구현 계획 아님.
> 목적: 데스크톱 데이터 모델링 도구(DA# 5 Modeler)의 기능 범위를 **사용자 매뉴얼·도움말 목차와 화면** 기준으로 정리하고,
> 웹 버전 1차 범위(P0~P2)와 docuCBD 기존 자산 재사용 지점을 정한다. 2차(UX 개선)의 입력이 된다.

## 4. docuCBD 기존 자산 재사용 지점

> 아래 경로는 모두 docuCBD 저장소(`D:\project\docuCBD`) 기준이다.

| 웹 모델러 기능 | docuCBD 자산 | 현재 한계 |
|---|---|---|
| 논리 엔터티·속성 | D8 엔티티 관계 모형 (`docs/design/d8-erd-pipeline-v1.md`) | ERD가 PlantUML 정적 렌더 — **캔버스 편집기 없음** |
| 물리 테이블·컬럼·FK | D9 DB 설계서 (`docs/design/d9-db-design-view-v1.md`) | 편집은 드로어 폼, 다이어그램 직접 편집 없음 |
| 표준 사전·명명·준수 검사 | 공통표준 사전 (`docs/design/std-dictionary-v1.md`) — 용어·단어·도메인, 명명 엔진, 후보 큐, 준수율 | 재사용도 가장 높음 |
| 표준화 통합 | DB 표준화 통합 계획 (`docs/planning/cbd-db-standardization-integration.md`) | 진행 중 |
| 편집·동시 편집 락 | 중간모델 편집 v1/v2 (`docs/design/artifact-model-edit-v1.md`) — DB 락·TTL | 노드 단위 편집, Undo 없음 |
| DDL 생성 | 개발 번들 scaffold `schema.sql` (D9 물리 원천) | 산출물 메뉴에서 단독 사용 불가 |
| 엑셀·문서 출력 | D8/D9 DOCX·XLSX 생성기 | 모델러 전용 서식 없음 |

**결론**: 데이터 모델·표준·출력은 상당 부분 있고, **없는 핵심은 "대화형 다이어그램 편집기"와 "Undo 가능한 클라이언트 모델 상태"**다. 1차 개발의 중심은 여기다.

## 5. 웹 1차 MVP (P0) 요약

1. 프로젝트 → 모델 → 주제영역 트리 (Browser: 모델 관리 · 다이어그램 객체)
2. 논리 ERD 캔버스 — 엔터티·속성·관계(식별/비식별, IE 표기), PK/FK 상속, AK
3. 물리 모델 — Target DBMS(1~2종), 테이블·컬럼·인덱스·RI, 논리↔물리 변환
4. 표준 적용 — 기존 표준 사전 연결, 속성/엔터티 표준 동기화, 준수 검사
5. 편집 기본기 — Undo/Redo, 복사/붙이기, 찾기, 일괄 편집 표, 자동 배치 1~2종, 미니맵
6. 출력 — DDL 생성, 엑셀 출력
7. 저장 — 서버 자동 저장 (자체 JSON 모델)
