# DA# 기능정의서 — 07. 저장소·협업 상세 (5차)

> 상태: **5차 — 저장소(A/R)·공유 엔터티**. 상위: [00-index.md](00-index.md).
> 환경: SQLite 표준사전 사본에 A/R 연결한 상태(2차에서 연결).

## 0. 수행 요약

| 기능 | 결과 |
|---|---|
| A/R 연결 | 성공(2차). 연결 후 **표준 기능만 활성** |
| 올리기 / 내려받기 / 관리 | **연결 후에도 비활성**, 툴팁·사유 없음 (F-46). SQLite 사전은 표준 데이터만 담고 모델 저장소 역할은 서버 DB(또는 정식 라이선스)가 필요한 것으로 추정 |
| 공유 엔터티 관리 | 화면 확인(목록 비어 있음) |

## 1. 기능 정의 (ID `RP-xx`)

### RP-01 A/R 연결 (M-D01) ★★★ (S0)

04 ST-01 참조. 표준 사전 연결과 모델 저장소 연결이 **같은 버튼**이다. 어떤 기능이 그 연결로 켜지는지 화면에서 구분되지 않는다 (F-46).

### RP-02 모델 올리기·내려받기·LOCK·관리 (M-D02, 📖) ★★ (협업)

| 항목 | 내용 (도움말 목차 기준) |
|---|---|
| 기능 | 신규 모델 올리기 / 편집된 모델 올리기 / 내려받기 / LOCK 설정·해제 / 모델 관리 |
| 실측 | 비활성 — 실행 못 함 |
| As-Is 문제 | 비활성 사유 미표시 (F-46, U-05와 같은 패턴). 파일(.damx) 단위 체크아웃·LOCK 방식이라 동시 편집 불가 |
| To-Be | 웹 서버가 저장소. 모델은 항상 서버에 있고 변경 이력·버전 비교·되돌리기 제공. LOCK 대신 객체 단위 동시 편집 또는 주제영역 단위 잠금 |

### RP-03 공유 엔터티 (M-D03, 엔터티 우클릭 ▸ 공유/Import/원천/타겟 엔터티로 설정) ★★ (S4)

| 항목 | 내용 |
|---|---|
| 화면 | 공유엔터티 리스트(엔터티·모델·사용 여부·소속·생성일·수정일·경로) + 참조엔터티 리스트(엔터티·모델·소속·생성일) |
| 버튼 | 공유 해제 / 공유 대체 / 갱신 / 미정의 참조엔터티 / 닫기 |
| 엔터티 속성 | 공유 엔터티·원천 엔터티·공유/연계 참조중 (02 LG-01) |
| 📖 | 공유 엔터티 등록·내려받기·변경체크·대체 |
| To-Be | 공통 엔터티(코드·사원 등)를 서버 라이브러리로, 사용처 목록과 변경 알림. 표준 사전의 "엔터티 용어"(04 ST-R06)와 연결 |

## 2. 신규 문제

| ID | 심각도 | 문제 | 근거 |
|---|---|---|---|
