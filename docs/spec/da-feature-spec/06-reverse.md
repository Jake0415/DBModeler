## 0. 수행 요약

| 기능 | 결과 |
|---|---|
| DDL 리버스 | 입력창에 DDL 붙여넣기/파일 읽기 → [적용] 시 **"CoCreateInstance fail!"** 오류로 실패 (F-42). 설치본에 파서 COM 구성요소가 등록되지 않은 것으로 보임 — 시스템 설정 변경(구성요소 등록)은 하지 않았다 |
| 파일 리버스(ERD 작성) | Excel 불러오기 → 항목 자동설정(헤더명 기반) → 적용 → **엔터티 14개 생성 성공** |
| 관계 생성(자동 관계 찾기) | 리버스 후 활성화. 가상관계선 1건 생성, 결과 요약 없음 |
| DB 리버스 / JSON·META 리버스 | 접속할 DB·입력 없음 → 미실행 (📖) |

## 1. 기능 정의 (ID `RV-xx`)

### RV-01 DDL 리버스 (M-R02) ★★ (현행 DB 표준 진단 입력)

| 항목 | 내용 |
|---|---|
| 화면 | "CREATE 문을 입력한 후 적용 버튼을 누르십시오" + 편집창(구문 강조) + 파일 읽기 / 적용 / 닫기 |
| 실측 | 파일 읽기 성공(파일 대화상자 기본 필터 `*.*` 텍스트가 이어 붙어 첫 시도 실패). 적용 → `CoCreateInstance fail!` |
| As-Is 문제 | 개발자용 원시 오류 메시지, 원인·조치 안내 없음 (F-42). 대상 모델·주제영역 선택 없이 현재 모델에 넣는 구조 |
| To-Be | 서버 측 DDL 파서(DBMS 방언별), 파싱 결과 미리보기(테이블·컬럼·PK·FK) → 대상 모델/주제영역 선택 → 반영. 파싱 실패는 줄 번호와 원인 표시 |

### RV-02 파일 리버스 — Excel로 ERD 작성 (M-R03) ★★

| 항목 | 내용 |
|---|---|
| 화면 | 모델 소스(문서 열기·설정 불러오기·항목 자동설정) + 소스 설정(대상 DBMS, 데이터 시작줄, 데이터 여부 설정 Y/N, 명칭 기준 논리명/물리명) + 시트 그리드(열마다 매핑 대상 헤더, 미지정은 "not used") |
| 매핑 대상 (확인) | 테이블명·엔터티명·테이블 동의어·테이블 보조명·컬럼명·속성명·데이터타입·길이·소수점·기본값 … |
| 처리 | 자동설정 = 문서 헤더명 기준 매핑(확인창) → 적용 → "모델 생성 설정을 저장하시겠습니까?"(매핑 프리셋 저장) → "완료 되었습니다" |
| 실측 | 14개 엔터티가 **현재 모델·현재 주제영역**에 추가, 기존 엔터티와 **겹쳐 배치**. 물리 테이블도 생성되나 물리 다이어그램에는 미배치(트리에서 회색). 생성된 엔터티에 **식별자 없음** (F-44) |
| 강점 | 헤더명 자동 매핑 + 매핑 프리셋 저장 — **계승** (04 ST-R04의 일괄등록과 같은 방식으로 통일) |
| As-Is 문제 | 대상 모델/주제영역 선택 없음, 배치 겹침 (F-43). PK 미지정 시 경고 없음 (F-44). 완료 메시지에 경고 아이콘 (F-28) |
| To-Be | 새 모델 또는 새 주제영역으로 가져오기 기본, 자동 배치 후 표시, 결과 요약(엔터티 N, PK 없는 엔터티 N → 바로가기) |

### RV-03 자동 관계 찾기 (M-R04, 엔터티 우클릭 ▸ 자동 관계 찾기) ★

| 항목 | 내용 |
|---|---|
| 처리 | "엔터티 사이의 관계를 찾아 가상관계선을 생성합니다" → 대상 설정 / 예 / 아니오. 동의어 설정(자동 관계 동의어 설정)으로 컬럼명 차이 보정 |
| 실측 | 관계 1건 추가(상태바 10→11). 무엇이 생성됐는지 목록·요약 없음 |
| As-Is 문제 | 결과 요약 없음, 근거(어느 컬럼이 일치했는지) 미표시 (F-45) |
| To-Be | 후보 관계 목록(부모·자식·일치 컬럼·신뢰도) 미리보기 → 선택 생성 |

### RV-04 DB 리버스 · JSON/META 리버스 · 리버스 타입 변환 옵션 (M-R01, M-R02) 📖

## 2. 신규 문제

| ID | 심각도 | 문제 | 근거 |
|---|---|---|---|
| F-42 | 상 | DDL 리버스가 `CoCreateInstance fail!`로 실패 — 원시 오류, 조치 안내 없음 | DDL Reverse [적용] |
| F-43 | 중 | 파일 리버스 결과가 현재 모델·주제영역에 겹쳐 배치, 대상 선택 없음 | ERD 작성 후 다이어그램 |
| F-44 | 중 | 리버스로 만든 엔터티에 식별자가 없어도 경고 없음 | 고객 엔터티(모든 속성 `o`) |
| F-45 | 하 | 자동 관계 찾기 결과·근거 미표시 | 상태바 숫자만 증가 |
