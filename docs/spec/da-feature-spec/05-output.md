# DA# 기능정의서 — 05. 산출물(DDL·엑셀) 상세 (4차)

> 상태: **4차 — 산출물 상세 정의**. 물리 모델은 [03-physical.md](03-physical.md).
> 근거: 1차 워크스루(DDL 2회 생성), 2차(표준 적용 후 DDL), 4차(엑셀 출력물 화면).

## 1. 기능 정의 (ID `OUT-xx`)

### OUT-01 스크립트 생성기 (M-P07) ★★★ (S6)

| 항목 | 내용 |
|---|---|
| 탭 | DDL / DML |
| DDL 옵션 | [CREATE TABLE] Drop Table(Drop Ref_fk)·Drop PK·Create Table·Table Storage·PK Index(Index Using, PK Storage)·Primary Key·FK·UK·Check·Comment / [CREATE VIEW] / [CREATE INDEX] / [CONSTRAINT] PK·UK·FK·Check 각 Drop·Add / [DROP TABLE] / [COMMENT] Column·Table |
| 버튼 | 객체 선택 / 스크립트 생성 / DB 연결 / 모두 실행 / 실행 / 저장 / 닫기 |
| 범위 | **현재 선택된 테이블만, 선택이 없으면 전체** — 화면에 표시 없음 (F-22) |
| 저장 | 기본 위치 '문서' 폴더, UTF-16 LE(BOM) (U-21) |
| 옵션 보존 | 세션 안에서는 마지막 체크 상태 유지(4차 확인), 첫 실행은 전부 해제 (U-20) |
| 실측 문제 | 데이터타입 없는 컬럼 무경고 출력 (U-01) · **FK 0건 — 모델에 FK 제약조건 객체가 없기 때문** (U-02 → F-38) · Create Table▸Comment와 [COMMENT] Section이 같은 주석을 두 번 출력 (U-04) · 한글 테이블·제약조건명 무경고 (F-23) |
| To-Be | 범위 명시(전체/선택/주제영역), 프리셋, 게이트 B(타입 누락·예약어·FK 누락·이름 길이·비ASCII 식별자), 결과 요약(테이블 N, FK N/관계 M), UTF-8 기본 |

### OUT-02 출력물 생성 — 엑셀·HTML (M-D14) ★★ (S6)

| 항목 | 내용 |
|---|---|
| 화면 | 출력 대상 객체 유형(트리, 항목별 체크·엑셀헤더명·순서 ▲▼) + 상세 옵션 + **출력 서식 관리**(서식 목록·저장·다른 이름으로 저장·삭제) + 항목 선택·객체 선택·항목 초기화·HTML문서·엑셀 출력 |
| 서식 프리셋 | 관계선목록_논리 / 관계선목록_물리 / 뷰목록 / 엔터티목록 / 엔터티속성목록 / 인덱스목록 / 테이블목록 / 테이블컬럼목록 |
| As-Is 문제 | **열 때 대상 유형이 현재 선택 객체로 정해짐**(관계가 선택돼 있으면 "출력물 생성-Relation") — F-22와 같은 암묵 범위 패턴. 서식 콤보에서 마우스 선택이 반영되지 않음 (F-26과 같은 콤보 문제) |
| To-Be | 산출물 종류(정의서 유형)를 먼저 고르고 범위는 별도 선택. docuCBD DOCX/XLSX 생성기 재사용 (인벤토리 §5) |

04 ST-14 참조. 준수 체크·준수도 결과를 엑셀로.

주제영역/모델 그림 파일 저장, 빠른 인쇄·미리보기·페이지 설정.
