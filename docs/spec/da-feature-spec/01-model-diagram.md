# DA# 기능정의서 — 01. 모델·주제영역·다이어그램 상세 (5차)

> 상태: **5차 — 모델 구조와 다이어그램 편집**. 상위: [00-index.md](00-index.md) · [02-logical.md](02-logical.md).
> 근거: 1차 워크스루(U-11~U-15), 5차 실습(자동 배치·주제영역·파일 리버스로 엔터티 23개 상태).

## 1. 기능 정의 (ID `DG-xx`)

### DG-01 모델 구조 (M-F01·M-F02, M-C04) ★

프로젝트 > 모델 폴더 > 모델 > 주제영역 폴더 > 주제영역 > 논리/물리 ERD. 모델 트리는 **주제영역목록**과 **객체목록**(논리 객체: 엔터티·관계·용어·도메인 / 물리 객체: Table·Relation·Constraint·Index·View)으로 나뉜다. 다이어그램에 없는 물리 테이블은 트리에서 회색.

### DG-02 주제영역 (M-C05, 주제영역목록 우클릭) ★

| 항목 | 내용 |
|---|---|
| 메뉴 | 주제영역 추가 / 폴더 주제영역 추가 / 이름순 정렬. 개별 주제영역: 이름 변경·정의·엔터티 참조·복제·논리/물리 다이어그램·모델로 내보내기·객체 정보 |
| 추가 (실측) | "Subject Area" 영문 창: 주제영역 이름 + 물리 다이어그램 추가(ORACLE True/False). 이름 기본값 "주제영역1"이 선택되지 않아 입력이 뒤에 붙음 → "주제영역1투자관리" (F-47) |
| 엔터티 배치 (실측) | 트리에서 엔터티를 끌어 놓으면 같은 엔터티가 여러 주제영역에 표시(참조) — **계승** |
| To-Be | 주제영역 = 같은 모델의 여러 뷰. 추가 시 이름 입력란 전체 선택, 엔터티는 검색으로 추가 |

### DG-03 자동 배치 (M-T01) ★

| 항목 | 내용 |
|---|---|
| 종류 | HTREE / Layered TREE / 방사형 / 자식 소집 / 관계선 배치, 위치 고정·해제 |
| 실측 | Layered TREE: 관계 있는 엔터티는 계층 트리로, 관계 없는 엔터티는 아래쪽 격자로 정렬. 한 번에 적용, Undo 가능 |
| As-Is 문제 | 배치 결과 미리보기 없음. 리버스 직후 자동 적용되지 않음 (F-43) |
| To-Be | 배치 알고리즘 계승, 미리보기·부분 적용(선택 영역), 고정 엔터티 존중 |

### DG-04 그리기·편집 기본 (M-H02~H10, M-C01~C03) ★

엔터티·관계 생성(U-11), 크기 최적화(U-12), 확대/축소, Undo/Redo, 글꼴·색, 텍스트 박스·풍선 도움말·OLE·선·표. 상세 문제는 워크스루 U-11~U-15와 02-logical.

### DG-05 정렬·서식 (M-T02, M-T03) ★

맨 앞/뒤, 그룹 지정, 크기 최적화, 하위 재배치, 속성 너비 맞춤, 맞춤 / 디자인·폰트 디자인 프리셋.

### DG-06 패널 (M-B01, M-B02) ★★

다이어그램 객체(현재 주제영역의 엔터티·관계) · 조건검색 · 표준 관리 · 태그 관리 · 레이아웃(미니맵) / 출력(동작·알림·검토·디버그) · 입력(VBScript). 탭 라벨 잘림 (F-18).

### DG-07 모델 검토 (M-D15) ★★ (S6)

기본(명칭 중복·미입력·미사용) / 표준화 / 정합성 / 물리정보 검토. 결과가 안 보이는 문제 (U-09, U-10).
