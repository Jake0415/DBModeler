# 32. 접힌 왼쪽 칸 아이콘 · 미니맵 탐색 — 수정 플랜 (2026-11-26)

> 요청(사용자): “화면을 접으면 아이콘으로 표시하고, 마우스를 올리면 이름이 보이게. 하단 내비게이션(미니맵)을 움직이면 화면도 같이 움직이게.”
> 대상: 목업 `docs/ux/mockups/assets/app.js` · `assets/app.css` · `model.html`. 목업이 사양이므로(CLAUDE.md) 목업을 고치고 [03 ERD 편집기](03-erd-editor.md)에 변경 기록을 남긴다.
> 상태: **브랜치 `Jake0415/erd-rail-minimap`에 구현 · 브라우저 확인 완료(2026-11-26)** — main 병합은 사용자 확인 뒤. D-1은 기본안(아이콘만)으로 구현.

## 1. 지금 동작 (코드 확인)

### 1.1 접힌 왼쪽 칸 (아이콘 줄, `#app.treemin .tmini`)
- 위치: `assets/app.js` 약 2299행 `<div class="tmini">`. 순서: [펼치기] · 시스템 홈(`table` 아이콘) · **업무 영역마다 이름 첫 글자** · 시스템 전체 ERD(`compare`) · 가져오기(`upload`).
- 문제
  1. 업무 영역이 **글자 한 자**(인 · 재 · 회 · 영 · 구 · 재 · 생)라 아이콘처럼 보이지 않고, **‘재무’와 ‘재고’가 둘 다 ‘재’**로 겹친다.
  2. 이름은 브라우저 기본 `title`로만 나온다 → 약 1초 늦게 뜨고, 모양이 제품과 다르고, **키보드 포커스에는 안 뜬다**(WCAG 1.4.13 · 2.4.7 미흡).
  3. 아이콘이 무엇을 하는 칸인지 묶음 구분이 없다(시스템 · 영역 · 도구가 한 줄로 이어짐).

### 1.2 미니맵 (`#cv-mini > svg#mini`, `model.html` 609~621행)
- 그림만 있다. **클릭 · 끌기 처리기가 없다**(이벤트 등록 0건). 캔버스 끌기에서도 제외(`CV_UI`에 `.cv-mini`) → 미니맵에서 무엇을 해도 화면이 안 움직인다.
- 화면 → 미니맵 방향은 동기화된다(캔버스를 끌면 `miniView()`가 테두리 `#mini-vp`를 옮김). **반대 방향(미니맵 → 화면)만 없다.**
- 사양과 불일치: [03 §미니맵](03-erd-editor.md) “현재 보이는 영역 사각형을 **끌어 이동**” — 목업 누락.
- 시스템 전체 보기(`?sys=1`, `miniSys()`)도 같은 상태.

## 2. 수정안

### A. 접힌 왼쪽 칸 — 아이콘 + 마우스 올리면 이름

| # | 내용 |
|---|---|
| A-1 | **업무 영역 항목은 `area` 아이콘**(이미 있는 아이콘 세트)으로 바꾼다. 지금 영역은 기존처럼 흰 바탕 + 테두리(`.on`)로 강조. |
| A-2 | **묶음 구분선**: [펼치기] / 시스템 홈 / ─ / 업무 영역 n개 / ─ / 시스템 전체 ERD · 가져오기. 영역 묶음 위에 접근성 이름 “업무 영역”(`role="group"`). |
| A-3 | **이름 말풍선(공통 1개)** `.rail-tip` — 아이콘 오른쪽 8px에 검은 말풍선(디자인 가이드 툴팁 색: `--ink` 바탕 · `--on-ink` 글자 · 12px). <br>· 내용: 1줄 이름(예 “인사관리”), 2줄 보조(업무 영역 · 엔터티 12개 · 미준수 2) — 도구 항목은 단축키(예 “왼쪽 칸 펼치기 · Ctrl+B”). <br>· 뜨는 때: 마우스를 올리고 **300ms 뒤**, 줄 안에서 다음 아이콘으로 옮기면 **즉시**. **키보드 포커스에도** 뜬다. <br>· 닫는 때: 마우스가 떠나면 · Esc · 클릭 · 스크롤. 말풍선 위로 마우스를 옮겨도 유지(1.4.13). <br>· 화면 아래쪽 끝이면 위로 올려 창 밖으로 나가지 않게. |
| A-4 | `title` 속성은 지운다(기본 툴팁과 이중으로 뜨지 않게). `aria-label`은 유지 — 화면 읽기 프로그램은 지금처럼 이름을 읽는다. |
| A-5 | 적용 범위: 아이콘 줄이 나오는 모든 화면(model · system · standardize · ddl · outputs · import · import-excel). 말풍선 코드는 `app.js` 한 곳(`railTip`)에 두고 `.tmini` 안 `[data-rt]`에만 붙인다. |
| A-6 | 영역이 많아 줄이 넘치면 지금처럼 줄 안에서만 스크롤(말풍선은 스크롤 시 닫힘). |

> **결정 필요(D-1)**: 업무 영역이 모두 같은 `area` 아이콘이 되면, 영역이 많을 때 아이콘만으로는 구별이 어렵다(이름은 말풍선으로 확인). 대안 — 아이콘 오른쪽 아래에 **작은 첫 두 글자**(예 “인사”)를 겹쳐 표시. 기본안은 요청대로 **아이콘만**, 대안은 승인 시.

### B. 미니맵 ↔ 화면 동기화

| # | 내용 |
|---|---|
| B-1 | **테두리(보이는 범위) 끌기 → 화면이 실시간으로 따라 움직인다.** 끄는 동안 1프레임에 1번만 반영(`requestAnimationFrame` → `applyView()`), 테두리는 `miniView()`로만 옮기고 박스 그림은 다시 그리지 않는다(끝날 때 1번 `mini()`). |
| B-2 | **미니맵 빈 곳 클릭 → 그 지점이 화면 가운데로.** 200ms 부드럽게 이동(`prefers-reduced-motion`이면 즉시). 누른 채 끌면 B-1처럼 이어서 끈다. |
| B-3 | 좌표 변환(지금 `miniK = {k, ox, oy}` 재사용): 미니맵 점 `(mx, my)` → 세계 좌표 `wx = mx / k + ox` · `wy = my / k + oy`. 테두리 왼쪽 위를 `(rx, ry)`로 두면 `panX = -(rx / k + ox) · zoom`, `panY = -(ry / k + oy) · zoom`. 끄는 동안 `miniK`는 고정(경계가 흔들리지 않게). |
| B-4 | 범위 제한: 테두리 중심이 모델 경계 상자(+ 여백 100) 밖으로 나가지 않게 한다 — 빈 바다로 잃어버리지 않게. |
| B-5 | 화면 읽기 · 키보드: 미니맵에 `tabindex="0"`, 화살표 = 보이는 폭의 10% 이동 · Shift+화살표 = 50% · Home = 맞춤. 접근성 이름에 “화살표로 이동”을 덧붙인다. |
| B-6 | 커서 · 크기: 테두리 위 `grab` / 끄는 중 `grabbing` / 빈 곳 `pointer`. 크게 확대해 테두리가 아주 작아지면 최소 8×8px로 그려 잡을 수 있게. |
| B-7 | 시스템 전체 보기(`?sys=1`)에도 같은 동작 — 공통 함수 `miniNav(get, set)`에 업무 영역 보기(`panX · panY · zoom`)와 시스템 보기(`sysX · sysY · sysZ`)를 넘긴다. |
| B-8 | 끌기를 시작하면 `viewTouched = true`(자동 맞춤이 사용자의 위치를 덮어쓰지 않게). 포인터 캡처로 미니맵 밖으로 나가도 끌기가 이어진다. 캔버스 끌기 · 선택 · 노드 끌기와 겹치지 않는다(이미 `CV_UI` 제외). |
| B-9 | 미니맵 휠 → 확대 · 축소(선택, 기본은 하지 않음 — 캔버스 휠과 같음). |
