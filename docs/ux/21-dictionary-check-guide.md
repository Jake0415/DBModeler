# 21. 표준 사전 — 직접 확인 안내 (FE 목업)

- 대상: 표준 사전 화면 작성 · 품의 · 결재 · 모델 연계 (DX-01~22, 보완 5건, 교차 검증 반영, 사용자 결정 Q1~Q7)
- 실행: 목업 서버 `http://localhost:5178` (Claude 앱의 미리보기 ‘mockups’ 또는 `docs/ux/mockups` 폴더를 정적 서버로 열기)
- 사용자 바꾸기: 오른쪽 아래 [목업] → 역할 전환, 또는 주소 끝에 `?as=kim`(모델러 · DA) · `?as=park`(모델러) · `?as=lee`(DA) · `?as=hyun`(기관 담당자 · 최종 승인)
- 목업 데이터는 브라우저 저장소에 있습니다. 처음 상태로 되돌리려면 [목업] → 데이터 초기화(또는 개발자 도구에서 `dbm-` 키 삭제)

## 6. 알려진 목업 한계

- 엑셀 · 공통표준 원본 파일은 실제로 읽지 않고 예시 행으로 단계를 보여 줍니다(오류 가이드 CSV 내려받기는 실제 파일).
- 초안 · 바구니는 이 브라우저에 저장됩니다(제품은 계정별 서버 저장).
- 행정표준코드 코드값은 공통표준 원문 ‘허용값’에서 읽은 일부입니다(소관기관 원본 보완은 새 판 품의로).
