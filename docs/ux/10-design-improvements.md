# 디자인 개선 후보 — Geist 정리 이후 "한 단계 더"

## 적용 기록
- **#1 사전 도구 줄 정리 — 완료 (2026-11-19)**
  - 도구 줄을 `[검색] [종류 구간 선택] [필터 ▾ n]` 한 줄로 줄였다. 1600px에서도 높이 57px로 줄바꿈되지 않는다.
  - 검색 칸 안내 문구는 "이름·약어·초성 검색"으로 짧게 하고, 나머지 검색 대상은 ⓘ 도움말로 옮겼다.
  - 출처·상태·도메인그룹·변경일·길이·도메인 연결·원본 폐기는 필터 팝오버로 옮겼다. 바깥을 누르거나 Esc를 누르면 닫히고, 초기화 버튼이 있다.
  - 걸린 조건은 결과 건수 줄에 칩으로 보인다. 칩마다 × 지우기가 있고, "모두 지우기"도 있다. 필터 버튼에는 걸린 조건 수를 표시한다.
  - 상세 패널은 행을 고를 때만 열린다(기본은 닫힘이라 표가 전체 폭을 쓴다). `?sel=` 링크는 목록 밖의 항목이라도 상세를 연다.
  - 빈 결과의 "필터 지우기"는 모든 조건을 지운다.

- **#2 결재 판단·연속 처리 — 완료 (2026-11-19)**
  - 상세 제목 아래에 요약 줄을 둔다. 내용은 `내 차례 │ 확인할 항목/변경 n건 │ 검사 실패 n건 / 확정 차단 n건 / 검사 통과 │ n일째 · 기한 넘김`이다. 실패·차단 버튼을 누르면 해당 탭(검사 결과·항목)으로 바로 간다.
  - 대기함에서 승인·반려하면 다음 문서가 자동으로 열린다. 토스트로 "처리 · 다음 문서를 열었습니다"를 알리고 [되돌리기]를 준다. 목업에서는 결정 직전 상태로 되돌린다(서버에서는 단계를 되돌린다).
  - 단축키: J/K 이동, A 승인, R 반려. 입력 중이거나 대화상자가 열려 있으면 동작하지 않는다. 내 차례 문서의 하단에 단축키 안내를 표시한다.
  - 대기함을 모두 처리하면 "처리할 결재를 모두 마쳤습니다 · 내 신청 보기" 완료 상태를 보인다.
  - 확인: 0009 승인 → 0016이 자동으로 열림 → J로 다음 → R로 반려 창이 열림 → 되돌리기로 0009가 DA 단계로 돌아가고 다시 열림.

## 권장 진행 순서
1. **사전 도구 줄 정리**(#1). 가장 자주 쓰는 화면이고, 범위가 작다.
2. **결재 판단·연속 처리**(#2). 핵심 업무의 체감 속도를 높인다.
3. **모델 머리줄·작업 상태·배너·보기 전환**(#3·#4). 모델러의 주 화면이다.
4. **엑셀 단계 흐름**(#5).
5. **머리줄 구조 통일 + 상태 세트**(#6·#7). 전 화면 공통이라 앞의 네 화면에서 정한 모양을 일반화한다.
