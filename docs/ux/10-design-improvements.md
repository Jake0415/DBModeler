# 디자인 개선 후보 — Geist 정리 이후 "한 단계 더"

> 2026-11-19 · 출처: Codex(`review/codex-d5.md`)·Claude(`review/claude-d5.md`) 개선 검토, 다크 테마 직접 확인(결재함·모델·홈)

## 적용 기록
- **#1 사전 도구 줄 정리 — 완료 (2026-11-19)**
  - 도구 줄을 `[검색] [종류 구간 선택] [필터 ▾ n]` 한 줄로 줄였다. 1600px에서도 높이 57px로 줄바꿈되지 않는다.
  - 검색 칸 안내 문구는 "이름·약어·초성 검색"으로 짧게 하고, 나머지 검색 대상은 ⓘ 도움말로 옮겼다.
  - 출처·상태·도메인그룹·변경일·길이·도메인 연결·원본 폐기는 필터 팝오버로 옮겼다. 바깥을 누르거나 Esc를 누르면 닫히고, 초기화 버튼이 있다.
  - 걸린 조건은 결과 건수 줄에 칩으로 보인다. 칩마다 × 지우기가 있고, "모두 지우기"도 있다. 필터 버튼에는 걸린 조건 수를 표시한다.
  - 상세 패널은 행을 고를 때만 열린다(기본은 닫힘이라 표가 전체 폭을 쓴다). `?sel=` 링크는 목록 밖의 항목이라도 상세를 연다.
  - 빈 결과의 "필터 지우기"는 모든 조건을 지운다.

- **#2 결재 판단·연속 처리 — 완료 (2026-11-19)**
  - 상세 제목 아래에 요약 줄을 둔다. 내용은 `내 차례 │ 확인할 항목/변경 n건 │ 검사 실패 n건 / 확정 차단 n건 / 검사 통과 │ n일째 · 기한 넘김`이다. 실패·차단 버튼을 누르면 해당 탭(검사 결과·항목)으로 바로 간다.
  - 대기함에서 승인·반려하면 다음 문서가 자동으로 열린다. 토스트로 "처리 · 다음 문서를 열었습니다"를 알리고 [되돌리기]를 준다. 목업에서는 결정 직전 상태로 되돌린다(서버에서는 단계를 되돌린다).
  - 단축키: J/K 이동, A 승인, R 반려. 입력 중이거나 대화상자가 열려 있으면 동작하지 않는다. 내 차례 문서의 하단에 단축키 안내를 표시한다.
  - 대기함을 모두 처리하면 "처리할 결재를 모두 마쳤습니다 · 내 신청 보기" 완료 상태를 보인다.
  - 확인: 0009 승인 → 0016이 자동으로 열림 → J로 다음 → R로 반려 창이 열림 → 되돌리기로 0009가 DA 단계로 돌아가고 다시 열림.

- **#3·#4 모델 화면 — 완료 (2026-11-19)**
  - 머리줄을 `경로 · 버전 배지 · 저장 상태 … [다이어그램|표] [논리|물리] [⋯] [주 행동]`으로 줄였다(버튼·링크 7개 → 4덩어리).
  - **저장 상태 한 자리**: 편집할 때마다 `저장됨 · 14:32`을 표시한다. 다른 탭과 충돌하면 `저장 안 됨 · 최신본 확인`(빨강), 결재 중이면 `검토 중 · 조회 전용`, 권한이 없으면 `조회 전용`, 예시 화면이면 `예시 화면 · 저장 안 함`을 보인다.
  - **주 행동 하나**: 미준수가 있으면 `미준수 n건 해결`(채움, 표준 맞추기로 이동), 없으면 `확정 신청`이다. 준수율 줄의 표준 맞추기는 보조 버튼으로 낮췄다.
  - **⋯ 메뉴**: 가져오기(DDL), DDL 만들기, 산출물, 이미지로 내보내기, 기준 확정본과 비교, 기준 확정본 보기. 기준 버전은 버전 배지 툴팁으로도 보인다.
  - **배너 한 자리**: 우선순위(연결 끊김 > 잠금 > 조회 전용 > 물리 점검 > 남은 미준수 > 대형 모델 > 동기화)대로 가장 높은 하나만 띄운다. 나머지는 `안내 n건 더`로 접고, 누르면 펼친다. 공동 편집 안내의 왼쪽 색 막대는 없앴다.
  - **보기 전환**: `[다이어그램 | 표]`로 바꾸고, 표는 떠 있는 창이 아니라 캔버스 영역 전체를 차지하는 본문 전환이다(도구 막대·배너·미니맵 숨김). Esc나 "다이어그램으로"로 돌아간다.
  - **일괄 적용 범위(#4)**: `표시된 선택 n · 숨겨진 선택 m`을 보인다. 기본 버튼은 `표시된 n개 적용`이다. 숨은 선택까지 바꾸려면 `숨겨진 m개 포함…`을 누르고 다시 한 번 눌러 확인해야 한다.

- **#5 엑셀 가져오기 단계 흐름 — 완료 (2026-11-19)**
  - 단계 표시를 머리줄 오른쪽에서 **머리줄 아래 전용 단계 줄**(48px)로 옮겼다. 지금 단계는 회색 바탕에 검정 번호로 표시한다. 끝난 단계는 버튼이라 눌러서 돌아갈 수 있다(검증 중에는 돌아갈 수 없다).
  - 본문 폭을 단계와 관계없이 **960px로 고정**했다. 결과 검토 격자(5단계)만 전체 폭을 쓴다.
  - **아래 고정 동작 줄**(56px): `[이전] 저장 상태 … 안내 [다음 행동]`. 다음 버튼 이름은 단계마다 다르다: 파일 올리기 → 열 매핑 확인 → 검증 시작 → 신청 준비 → n건 신청.
  - 열 매핑 첫 줄에 요약을 둔다: `파일명 │ 필수 항목 2/2 연결 │ 확인 필요 1 … [파일 바꾸기]`.
  - 검증 중에는 지금 검사 단계를 표시한다(입력 형식 → 업무 규칙 → 기준본·사전 비교 → 결재 대기 확인). 취소 버튼은 "취소하고 열 매핑으로"로 돌아갈 곳을 밝힌다. 결과가 도착하면 결과 영역으로 포커스를 옮긴다.

- **#6 화면 머리줄 구조 통일 — 완료 (2026-11-19)**
  - 모든 화면을 `[경로 /] 제목 [상태 배지 1] … [보조 ≤2] [⋯] [주 행동 1]` 한 줄로 맞췄다.
  - `← 모델`·`← 사전` 뒤로 버튼은 경로 링크로 바꿨다(DDL·표준 맞추기·산출물·가져오기·업로드·변경 내역·후보·엑셀).
  - 제목 옆 회색 부연 문구는 없앴다. 필요한 설명은 제목 툴팁이나 배지 하나로 옮겼다(감사 로그 "보존 5년", 산출물 "양식 KDA v2", 시스템 "Oracle 19c · RQMS").
  - 사전 머리줄은 `[내려받기 ▾] [⋯ 엑셀 가져오기·변경 내역·업로드 이력] [+ 등록 신청]`이다(공표는 DA일 때만).
- **#7 상태 세트 — 완료 (2026-11-19)**
  - **처리 중 버튼**(`data-busy`): 누르면 글자 앞에 스피너를 보이고, 처리하는 동안 키보드로도 다시 누를 수 없다(승인·반려·자기 승인·다시 분석·산출물 만들기·DDL 내려받기·파싱·가져오기).
  - **목록 뼈대**(`.skel`): 견본과 `?skel=1`에서만 보인다. 데이터가 이미 있는 화면을 덮지 않는다.
  - **저장 상태 하나**(`.savest`): 점 + 글자로 모델·엑셀에서 같은 모양을 쓴다.
  - **빈 상태 3종**: 결과 없음(`none`, 돋보기), 처음 사용(`first`, + 아이콘 + 주 행동 하나), 다 끝남(`done`, 체크). 제목 줄(`.et`)과 설명 한 줄을 둔다.
