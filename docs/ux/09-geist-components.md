## 2. Geist 사용 규칙 (문서 본문)
- **배지**
  - 한 행에 하나만 쓴다. 클릭할 수 없다.
  - 색 = 의미다: 초록 정상, 빨강 오류, 주황 경고, 파랑 정보, 회색 중립.
  - 안에 체크·X 아이콘을 넣지 않는다.
- **표**
  - 숫자 열은 같은 폭 숫자로 쓰고, 빈 값은 "—"로 쓴다.
  - 열쇠-값 정보는 표가 아니라 설명 목록으로 보여 준다.
  - 행이 없으면 빈 상태를 표 밖에 보여 준다.
- **버튼**
  - 상태를 바꾸는 행동은 버튼, 이동은 링크다.
  - 실행할 수 없을 때만 비활성화하고, 툴팁으로 이유를 붙인다.
- **색 단계**
  - 100~300은 바탕, 400~600은 선, 700~800은 채움, 900·1000은 글자다.

## 3. 목업 적용 (v10, 2026-11-19)
- **공통 CSS** (`app.css` 맨 끝 v10 블록): 위 표의 컴포넌트를 모두 옮겼다.
- **기호 정리**: 모든 화면의 기호 100여 곳(ℹ ! ✓ ◆ ● ⚠ ×, 링크 끝 →)을 SVG 아이콘으로 바꿨다. 자리표시 `<i data-ic=이름>`을 쓰면 app.js가 자동으로 바꾼다. 배지 안의 체크는 지웠다.
- **교차 검토 반영** (`review/*-d2.md`)
  - 태그 원문이 노출되던 모델 확정 배지를 고쳤다.
  - 비활성 버튼이 두 번 흐려지던 문제를 고쳤다.
  - 선택 행은 blue-100으로 표시해 hover·머리줄과 구분한다.
  - 배지는 24px로 맞췄다.
  - 패널의 반려 버튼은 빨간 글자의 보조 버튼이다. 빨간 채움은 모달의 최종 확인에만 쓴다.
  - 행 왼쪽의 색 막대를 없앴다.
  - 반쯤 선택된 체크박스를 표시하고, 다크 테마의 체크 대비를 고쳤다.
  - 이름 없는 닫기 버튼에 "닫기" 이름을 붙였고, 아이콘만 있는 칸에는 화면 낭독용 글자를 넣었다.
  - 입력 테두리는 3.2:1로 올렸다.
- **v11 마무리** (남은 다섯 가지)
  - 사전·모델의 자체 메뉴·팝오버·자동 완성을 공통 메뉴 규격(반경 12, 36px 항목)으로 옮겼다.
  - 모델 도구 막대의 선택 표시는 회색 바탕이다. 분류 표시는 알약형이다.
  - 한 행에는 배지를 하나만 둔다. 출처·종류·차수는 글자로 바꿨다(사전·후보·마이페이지·변경 내역).
  - 모델 캔버스의 미준수 속성 옆에 상태 이름을 붙였다(조합·미등록·예외·신청 중). 신청 중은 속이 빈 점이다.
  - 표가 비면 머리줄을 숨기고, 아이콘 칸과 가운데 정렬 문구로 바꾼다. 화면마다 고치지 않고 공통 규칙 하나로 처리한다.
  - 모든 표를 8px 테두리 상자로 통일했다. 스크롤 영역 안의 목록 표는 16/20 여백을 둔다.
  - 남은 그림 기호(📝 ⛔ ✎ ⚙)를 정리했다.

- **확인 검토 d3 반영** (`review/*-d3.md`, 두 검토 모두 "고친 뒤 올릴 것")
  - **빈 상태 표시 방식**: 화면이 빈 상태라고 표시한 행(`tr.er`, 19곳)만 바꾼다. 그래서 DDL 파싱 오류 한 줄이 빈 상태로 보이던 문제가 사라졌다. 아이콘 칸은 실측대로 54px이다. 패널 안의 작은 빈 행(예외 없음·변경 없음)은 조용한 한 줄로 둔다.
  - **고정 머리줄**: 스크롤되는 목록 표는 각진 상자로 두고, 머리줄이 위아래 선을 직접 그린다. 그래서 내려도 선이 남고 모서리 틈이 생기지 않는다. 둥근 8px 상자는 고정 머리줄이 없는 표(홈 구역·견본·`.box`)에만 쓴다.
  - **모델 표 보기**: 이미 떠 있는 패널이라 안의 표는 평평하게 둔다(상자 속 상자 해소).
  - **그 밖에 고친 것**
    - 엑셀 검증 격자의 선택 행 색을 고쳤다.
    - 표준 맞추기 기호(! – ◆)를 글자로 바꿨다.
    - 메모 삭제 버튼의 이름을 "메모 삭제"로 바꿨다.
    - 테마 버튼에 선택 상태(aria-pressed)를 넣었다.
    - 표준 맞추기의 테이블명, 모델의 참조 배지를 글자로 바꿨다.
  - **의도적 보류**
    - 보조 버튼의 링 대비(1.66:1): 글자가 있는 버튼이라 경계 대비 기준을 적용하지 않는다(Claude 검토도 보류로 판정).
    - 화면별 개별 입력 높이와 작은 버튼 28px: 업무 밀도를 고려해 유지한다.

## 4. 목업에서 다르게 둔 것
- **보조 글자색**: 연한 회색 글자 `#8f8f8f`는 대비가 3.2:1이라 쓰지 않는다. 글자는 `#4d4d4d`와 `#666666`만 쓴다.
- **표 행 높이**: 44px다. Vercel 마케팅 표는 64px다.
- **한글 글꼴**: 한글은 Pretendard로 이어 쓴다.
