## 1. 결론 요약

지금 목업은 기능·흐름은 탄탄하지만, 겉모습이 **"Vercel 스타일을 흉내 낸 AI 생성 대시보드"의 평균값**에 가깝다. 원인은 세 가지다.
1. 참조 원본(제3자 Vercel 해석)의 색을 거의 그대로 쓴다.
2. 모든 상태를 같은 모양(점 + 알약 배지)으로 그린다.
3. 모든 구역을 테두리 상자(카드)로 감싼다.

방향은 **"데이터 표준 원장(Registry)"** — 장식 대신 정밀함으로 신뢰를 주는 도구다.

| 바꿀 것 | 지금 | 바꾼 뒤 |
|---|---|---|
| 정체성 | 무채색 + Vercel 파랑 `#0070f3` | 그래파이트 잉크 + **기관 고유 강조색 하나**(§4, A/B 중 선택) |
| 상태 표현 | 모든 상태가 색 점 + 알약 배지(파랑이 화면을 덮음) | **주의가 필요한 상태만 색**. 정상·진행은 무채색 글자 |
| 구획 | 구역마다 카드 상자 | **선과 제목으로 구획**. 상자는 떠 있는 것·선택된 것만 |
| 아이콘 | 유니코드 기호(ℹ ! ✓ ◆ ●) 92곳 | SVG 선 아이콘 한 벌(가이드 §7 그대로) |
| 숫자 | 굵은 큰 숫자(700) KPI 타일 | 고정폭 숫자 + 600 굵기 + 비교 기준(목표·전주)을 같은 줄에 |
| 말투 | 모든 배너가 길게 설명, 줄표(—) 남발 | 한 줄 사실 + 행동 버튼. 설명은 펼침·도움말로 |

## 2. 현황 점검 — "AI 티"가 나는 곳

### 2.1 코드 집계(목업 전체)

| 패턴 | 건수 | 주로 나오는 곳 | 판단 |
|---|---|---|---|
| 유니코드 기호 아이콘 `ℹ ! ✓ ◆ ● ×` | 92 | 엑셀·모델·결재·사전 | **AI 티 1순위.** 가이드 §7(SVG 선 아이콘 한 벌)과도 어긋남. 스킬 금지 패턴 "Emoji as icons" |
| 배너 앞 `ℹ`/`!` 기호 | 52 | 모델·엑셀·결재·업로드 | 배너가 너무 많고 모양이 다 같음 → 경고 피로 |
| `b-violet` 배지·보라 강조 | 31 | 결재·모델·홈 | 스킬이 공공·B2B의 금지 패턴으로 꼽는 **"AI purple"** 계열 |
| `box-shadow` | 41 | app.css·모델 | 대부분 정당(떠 있는 요소). 카드에 쓰인 것은 걷어낼 대상 |
| 왼쪽 색 막대(`border-left 3~4px`) | 5 | 새 홈 할 일 카드 | 템플릿 대시보드의 전형 |
| `font-weight:700` | 2 | 새 홈 KPI | 가이드 §3 "700 미사용" 위반 |
| 그라데이션 | 2 | app.css·모델 | 확인 후 제거 |
| 화면 HTML 안 hex 직접 사용 | 6 | 모델 | 토큰 원칙 위반 |

### 2.2 화면에서 보이는 인상(홈 캡처 기준)

- **"이데이터님, 안녕하세요"** 인사 머리말: AI 생성 대시보드의 상투구다. 업무 도구에서는 공간 낭비다.
- 결재 목록의 모든 행이 같은 **파란 `● DA 승인` 알약**이다. 색이 정보를 주지 못하고 화면 전체를 파랗게 만든다.
- 구역마다 둥근 카드 + 헤어라인 + 제목 줄이 반복된다. 상자 속 상자(card soup)가 되어 위계가 사라진다.
- 오른쪽 "새 기능 1.0.0" 배지 + 릴리스 노트 카드가 마케팅 SaaS 문법이다.

### 2.3 접근성 수치(측정)

| 토큰 | 값 | 흰 바탕 대비 | 기준 4.5:1 |
|---|---|---|---|
| `--fg-3` | `#888888` | **3.54** | 미달 — 메타 정보 글자가 전부 해당 |
| `--warning`(글자로 쓸 때) | `#f5a623` | **2.03** | 크게 미달 — 경고 글자·아이콘 |
| `--info` | `#0070f3` | 4.55 | 경계선 |

## 3. 원칙 개정안 (가이드 §1 교체)

v1의 원칙 7개 중 5개는 유지하고, AI 티를 막는 원칙 3개를 더한다.

| # | 원칙 | 상태 | 적용 |
|---|---|---|---|
| 1 | 무채색이 기본, 색은 **행동이 필요한 상태에만** | 강화 | 정상(표준·완료·진행 중)은 무채색 글자. 색은 미준수·오류·반려·기한 넘김·예외에만 |
| 2 | 잉크 버튼은 화면당 하나 | 유지 | — |
| 3 | **상자보다 선** | 강화 | 구획은 1px 선 + 제목 + 여백. 카드 상자는 떠 있는 것(모달·팝오버)과 선택된 대상에만 |
| 4 | 촘촘하되 답답하지 않게 | 유지 | 행 32px. 대신 구역 사이 여백 24→32 |
| 5 | 두 가지 글꼴 목소리 | 확장 | 물리명·ID뿐 아니라 **모든 수치(건수·%·일수)도 고정폭 숫자** |
| 6 | 색만으로 전달하지 않는다 | 유지 | 상태 = 아이콘 + 글자, 색은 보조 |
| 7 | 결과는 항상 보인다 | 유지 | — |
| 8 | **[신규] 장식 금지 목록을 지킨다** | 신규 | §6 목록을 리뷰 체크리스트로 사용 |
| 9 | **[신규] 숫자에는 기준을 붙인다** | 신규 | KPI는 단독 숫자 금지. 목표·전주·전체 대비를 같은 줄에 표시 |
| 10 | **[신규] 사실 한 줄, 설명은 펼침** | 신규 | 배너·토스트는 한 문장 + 행동. 이유·규칙 설명은 [자세히]로 숨김 |

## 4. 색상 톤 개정

### 4.1 기본(무채색) — 차가운 회색을 "그래파이트"로

순수 회색(#888, #ebebeb)은 Vercel 복제 인상의 핵심이다. 아주 약하게 푸른 기가 도는 그래파이트로 바꿔 고유한 온도를 준다. 대비는 모두 측정했다.

| 토큰 | 지금 | 제안 | 흰 바탕 대비 |
|---|---|---|---|
| `--bg` | `#fafafa` | `#f6f7f8` | — |
| `--surface` | `#ffffff` | `#ffffff` | — |
| `--surface-2` | `#f5f5f5` | `#f0f2f4` | — |
| `--border` | `#ebebeb` | `#e3e6ea` | — |
| `--border-strong` | `#a1a1a1` | `#aeb4bc` | — |
| `--fg` / `--ink` | `#171717` | `#1b2128` | 16.2 |
| `--fg-2` | `#4d4d4d` | `#4a5360` | 7.8 |
| `--fg-3` | `#888888` (3.54 미달) | `#6b7480` | **4.74 통과** |

### 4.2 강조색 — 둘 중 하나 선택

강조색은 **링크·포커스·선택 행·내 차례 표시**에만 쓴다. 버튼 채움은 계속 잉크다.

| 안 | 색 | 대비 | 인상 | 위험 |
|---|---|---|---|---|
| **A. 청록(권장)** | `#0e6b67` / soft `#e3f0ee` | 6.3 / soft 위 5.4 | "표준·정합" 느낌. SaaS 평균(파랑·보라)과 확실히 구분 | 성공 녹색과 가까워 보일 수 있음 → 성공색을 더 노란 녹색으로 분리(§4.3) |
| B. 남색 | `#24396b` | 11.2 | 공공기관의 신뢰감, 보수적 | 잉크와 가까워 강조력이 약함, 흔한 "관공서 파랑" |

### 4.3 의미 색 — 채도를 낮추고 역할을 줄인다

| 의미 | 지금 | 제안(글자/soft) | 대비 | 쓰는 곳 |
|---|---|---|---|---|
| 정상·표준 | `#1a7f37` | `#1f7a3d` / `#e6f2ea` | 5.4 | **아이콘·글자만**(배경 채움 안 함) |
| 오류·반려·미준수 | `#ee0000` | `#b4232a` / `#f8e5e5` | 6.5 | 배지·배너·행 표시 |
| 경고·기한 임박 | `#f5a623` (2.0 미달) | `#8a5a00` / `#fbf1dc` | **5.9 통과** | 배지·배너 |
| 진행 중 | 파랑 알약 | **무채색 테두리 배지**(`--fg-2` 글자) | 7.8 | 결재 단계, 신청 중 |
| 예외(사유 있음) | 보라 `#7928ca` | 갈색 계열 `#7a4e2d` 또는 경고 soft + ◇ 아이콘 | 측정 후 확정 | 보라 제거 |
| 후보 큐·모델 확정 | 보라 배지 | 무채색 배지 + 종류 글자 | — | 보라 제거 |

차트는 **한 색 계열 + 회색**을 기본으로 한다. 강조할 계열 하나만 강조색, 나머지는 회색 단계로 그린다. 무지개 누적 막대는 쓰지 않는다(스킬 `gridline-subtle`, `contrast-data`).

## 6. 금지 목록 (리뷰 체크리스트)

스킬의 금지 패턴(공공·B2B: *AI purple/pink gradients, Ornate design, Excessive animation*)에 이 프로젝트 기준을 더했다.

1. 이모지·유니코드 기호를 아이콘으로 쓰지 않는다(✓ ◆ ● ℹ ⚠ ✨ 🚀).
2. 보라·분홍 강조, 그라데이션, 유리 효과(글래스모피즘), 네온·발광 그림자를 쓰지 않는다.
3. 왼쪽 색 막대 카드, 상자 속 상자를 쓰지 않는다.
4. 정상 상태에 색 배경을 칠하지 않는다(색은 주의 상태 전용).
5. 기준 없는 큰 숫자를 쓰지 않는다. 장식용 추세선·시드 차트를 실데이터처럼 보이게 하지 않는다.
6. 인사말 머리말, "새 기능 ✨", 마케팅 문구를 업무 화면에 쓰지 않는다.
7. 굵기 700, 20px 넘는 제목을 쓰지 않는다.
8. 한 화면에 배너를 둘 이상 쌓지 않는다.
9. 줄표(—)로 문장을 잇지 않는다. 한 문장에 한 사실만 쓴다.
10. 장식 애니메이션을 쓰지 않는다(패널 150ms, 드롭다운 100ms만).

## 8. 적용 계획

| 단계 | 내용 | 범위 | 확인 |
|---|---|---|---|
| D1 | 토큰 교체(§4) — `app.css :root`와 다크 값, 01 가이드 §2·§9 갱신 | 공통 1파일 | 대비 측정표, 전 화면 크롤 오류 0 |

## 11. v9 — Vercel Geist 체계로 전환 (2026-11-19, 사용자 결정)

사용자가 Vercel 색상표와 컴포넌트 형태를 그대로 쓰기로 결정했다. §10의 "청록 = 고유 강조색" 결정을 대체한다.

- **색**: vercel.com/geist/colors에서 실제 값을 읽어 `--ds-*` 토큰(배경·gray·blue·green·red·amber, 라이트·다크)으로 넣었다. 기존 토큰 이름은 별칭으로 남겼다.
  - 단계 규칙은 100~300 바탕, 400~600 선, 700~800 채움, 900·1000 글자다.
  - 글자에는 900·1000만 쓴다. gray-700 `#8f8f8f`는 흰 바탕에서 3.2:1이라 아이콘에만 쓴다. 3순위 글자는 `#666666`(5.7:1)이다.
- **글꼴**: Geist(영문·숫자) + Pretendard(한글)를 함께 쓴다. 자간은 −0.1px이다.
- **컴포넌트**: AI Gateway 모델 페이지에서 측정한 값을 따랐다.
  - 표 머리줄은 `#f2f2f2` 바탕, 14px·굵기 400, 높이 44, 좌우 여백 16이다.
  - 행은 44px이다. 표를 8px 테두리 상자(`.tbl.box`)로 감싼다.
  - 알약 탭(선택 시 gray-100), 완전히 둥근 32px 검색, 점선 둥근 필터 칩을 쓴다.
  - 버튼 반경은 6이다.
  - Geist 배지는 둥근 모양에 연한 채움과 900 글자를 쓰고, 안에 체크·X 아이콘을 넣지 않는다.
  - 빈 값은 "—"로 표기한다.
- **틀**: 상단 바와 사이드 메뉴는 background-200 `#fafafa`, 콘텐츠 영역은 흰색이다.
- **적용 범위**: 견본·홈·결재함은 형태까지 바꿨다. 다른 화면은 토큰·표·배지 모양만 바뀌었다.
