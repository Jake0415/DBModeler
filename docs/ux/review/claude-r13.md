# 목업 v7.2 교차 검토 — Claude (CL13)

대상: [codex-r12.md](codex-r12.md) (CX12) ↔ [claude-r12.md](claude-r12.md) (CL12). 다르게 본 곳은 코드를 다시 읽어 확인했습니다. 줄 번호는 `docs/ux/mockups/` 기준입니다.

## 1. 총평

- 두 검토의 진단은 같습니다. 고정 HTML로 남은 화면(표준 맞추기·후보 큐·게이트 A·DDL·산출물·감사)이 상태 계층을 읽지 않아 **재진입하면 옛 판정이 다시 보이고**, 화면 사이에서 **대상(영역·기준본·종류)이 인계되지 않습니다**.
- CX12의 상 23건 가운데 동의 15 · 수정 동의 7 · 반대 1(CX12-11)입니다. 시나리오는 T1~T4 실패에 합의했고, T5·T7·T8은 '조건부 통과', T9는 '실패'로 맞추자고 제안합니다.
- 합의 수정 목록은 18묶음입니다. 가장 큰 작업은 표준 맞추기·후보·결재 검사를 상태 계층으로 옮기는 세 묶음입니다. 동시성, 가상화, 서버 캡처·해시 계산은 구현 설계로 넘깁니다.
