# 목업 v5 교차 검토 — Claude (r8)

> 대상: [codex-r7.md](codex-r7.md) ↔ [claude-r7.md](claude-r7.md). 다툰 판정은 목업 코드(`docs/ux/mockups/`)에서 다시 확인했습니다.

## 1. 총평

1. Codex는 "입력부터 결재·반영·재진입까지 결과가 이어질 때만 닫힘"이라는 더 엄격한 기준을 썼습니다. 다시 확인해 보니 Codex가 찾은 잔여 결함(재신청이 옛 문서 집계를 바꿈, 참조함의 처리 버튼, 보정 취소가 이후 선택까지 지움, SC-15 이어서 작업의 숫자 덮어쓰기)이 실제로 있어서, 내 '닫힘' 판정 대부분을 '부분'으로 낮춥니다.
2. **합의 제안 닫힘 수: v4 Top 10은 1/10(Top 6), R1~R8은 1/8(R5), 07 Top 10은 0/10.** Top 6·R5는 목록에 적힌 모든 쓰기 경로가 `guard()`를 거치므로 닫힘을 유지하자고 제안합니다. 오래 열린 탭 문제는 Top 3(최신 상태 재확인)에서 다룹니다.
3. Codex 새 발견 24건 중 동의 13, 수정 동의 11, 반대 0입니다. 같은 문제 짝은 16쌍이고, 둘 다 놓친 문제 4건(CL8-01~04)을 추가했습니다.
