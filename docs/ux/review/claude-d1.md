# D1 검토: Claude (v8 토큰·컴포넌트 + 홈·결재함·견본)

> 대상: `assets/app.css`(토큰, v8 components 342행~), `assets/app.js`(icon·tag·docTag·docAge·docLate), `home.html`, `approvals.html`, `styleguide.html`
> 방법: 코드만 읽고 판단했다(브라우저 없음). 다른 화면의 기호·배지는 판정하지 않았다.

## 총평

결정한 뼈대(그래파이트 토큰, 청록 강조색, 상태 태그 7종, 구획을 선으로, 8:4 홈, 밑줄 탭, 머문 일 열, 패널 지표 한 줄)는 거의 그대로 들어갔다. 결재 동작 코드(`act`, pending 고정, 재검사, 확정 차단, 확인 표시)는 바뀌지 않았고, 홈 숫자도 같은 공용 함수(compOf·modelLock·linkState·myQueue)를 쓴다. 남은 문제는 세 가지다. 공용 토스트에 옛 기호가 남았다. 현황 원장의 열 의미가 행마다 다르다. 결재함에 기호와 긴 문장이 일부 남았다.

## 결정 준수 확인(문제 없음)

- 토큰: `--fg-3 #6b7480`(4.74), 경고 글자 `--warning-deep #8a5a00`, 오류 `#b4232a`, 청록 `#0e6b67`, 반경 3/4/6/8, 보라는 무채색으로 바뀌었다. 한글 제목의 음수 자간을 없앴고 포커스 링을 3px로 올렸다.
- 선택 행은 `--accent-soft` 바탕만 쓰고 왼쪽 막대는 없앴다(`app.css` `.tbl tr.sel`). 예외는 점선 + flag로 새 색이 없다.
- 홈: 인사말·카드·타일·추세선·새 기능·공지를 걷어 냈다. 홈에 기호 0개. 8:4 비대칭.
- 결재함: 유형은 글자, 단계 태그는 1개, 머문 일은 고정폭 숫자로 오른쪽 정렬, 패널 지표는 한 줄, 링크 줄, 변경 비교는 삭제만 오류색이다.
- 기능: 승인·반려·회수·자기 승인·확인 표시·확정 차단·재검사 코드는 바뀌지 않았다. 목록 정렬(내 차례 → 머문 일)은 `list()`를 쓰는 모든 곳에 똑같이 적용돼 첫 행 자동 선택과도 맞는다. `docAge`·`docLate`는 예전 홈의 계산식과 같다.
- 참고: `--warning #a86b00`은 흰 바탕 대비 약 4.4로 글자로 쓰기엔 조금 모자란다. 지금 두 페이지에서는 글자로 쓰지 않으므로 지적에서 뺐다. 다른 화면에 적용할 때 글자로 쓰지 않는지 확인해야 한다.
