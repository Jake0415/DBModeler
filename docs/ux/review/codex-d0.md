| 4. 상자 범위 | 홈의 할 일·현황·통계·업무 영역·내 신청·후보 결과·관리 이력은 14px/600 제목과 1px 위 선으로 구획한다. 결재함은 목록과 상세 사이 1px 세로선, 상세 머리말·하단에 1px 가로선만 둔다. 확인 모달·팝오버와 승인 차단 배너(최대 1개)는 상자로 남긴다. 선택 행은 청록 배경+2px 좌측 표시로 충분하다. | 제목과 행이 읽는 순서를 만들고, 상자는 확인이나 조치가 필요한 곳에 집중된다. |

| 6. 홈 배치 | 머리말은 좌측 ‘홈’, 우측 기준 차수·조회 범위. 1920px에서 사이 간격 24px로 왼쪽 가변·오른쪽 360px을 배치한다. 왼쪽 위는 **할 일** 32px 행(업무·건수·최장 대기·동작), 아래는 **업무 영역** 표(영역·현재 단계·준수율·다음 조치). 오른쪽은 **현황** 수치 행(예: 준수율·목표·차이) 아래 **내 신청**(보완 우선, 신청번호·단계·날짜). 관리·기관 역할에서는 현황을 첫 읽기 순서로 두고, 기존 권한에 따라 하단 전폭 **통계**를 노출한다. 영역별 준수율은 기준선이 있는 가로 막대 또는 순위표로 읽고, 시드 추세선은 뺀다. | 역할별로 먼저 확인하는 정보가 다르다. 결재 대기와 영역 진행을 표로 연결하면 업무를 고르고 다음 화면으로 이동하기 쉽다. |
| 7. 결재함 | 목록은 32px 행, 32px 고정 헤더, 13px 본문. 유형은 일반 글자로 두고 현재 단계 열의 상태만 표시한다. 선택 행에는 2px 청록 표시, 키보드 초점에는 3px 링을 쓴다. 1920px 상세는 560px을 유지하고 제목 → 신청번호·요청자·일시 → 결재 단계·신청 사유 → 항목·검사 결과·처리 이력 탭 순으로 둔다. 현재 단계만 청록, 자기 승인은 단계 옆에 글자와 펼칠 수 있는 사유로 표시한다. 고정 하단은 회수·반려를 보조 버튼으로, 승인 또는 자기 승인을 우측 잉크 버튼으로 배치하고 차단 사유를 가까이 둔다. | 여러 문서를 훑는 목록과 근거를 읽는 상세의 밀도를 각각 유지할 수 있다. 자기 승인과 승인 차단 정보도 행동 직전에 확인할 수 있다. |
| 8. 금지 목록 | 이모지·그라데이션 숫자·알약 남용 금지를 유지한다. **추가**할 항목은 모든 구획에 같은 간격, 텍스트·수치 일괄 중앙 정렬, 아이콘+제목+설명 3단 카드, 여러 줄로 반복하는 안내다. 행 32px, 제목 아래 8px, 구역 사이 24px(08의 32px 대신), 버튼·입력 4px/모달 8px를 기준으로 한다. 텍스트는 좌측, 수치는 우측에 정렬한다. **완화**할 항목은 제목 크기 일괄 금지(페이지 제목 22px/600, 구역 14px/600), 줄표 일괄 금지(문장 연결에는 금지, 결측값은 ‘미제출’처럼 확인 가능한 실제 의미 표시), 안내 한 줄 제한(원인과 조치에 최대 2문장, 상세 규칙은 펼침)이다. | 정보의 위계는 간격과 정렬로 드러난다. 화면 제목과 업무상 필요한 오류 설명에는 그 위계에 맞는 공간이 필요하다. |

## 가장 중요한 변경 5개

1. 홈을 할 일·업무 영역 표와 현황·내 신청 보조 열로 재배치한다.
2. 두 화면의 반복 카드 테두리와 그림자를 걷고 제목·1px 구분선으로 구획한다.
3. 정상·진행을 무채색으로 정리하고 주의·오류·사유 있는 예외에 서로 다른 상태 표현을 적용한다.
4. 결재함에서 선택 행, 현재 결재 단계, 승인 차단 사유가 바로 보이도록 한다.
5. 공용 SVG로 기호를 통일하고 장식용 추세선과 반복 안내를 줄인다.
