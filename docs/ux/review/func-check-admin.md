## 공용 파일(app.js)에 필요한 변경 — 남김

1. `assets/app.js:130` 외 시드 결재 문서가 공통표준(2025.11) 전체 적재 뒤 검사에 걸림. 0014 ‘산출물제출일자’ 약어 `DLVRBL_SBMT_DATE`는 공통 단어 기준 `DLVRBL_SBMSN_YMD`여야 함. 0014 ‘검수’, 0012 ‘수령자’, 0017 ‘변경’은 공통표준에 이미 있는 단어임. 그래서 목차 T7 ‘내 신청 자기 승인’(0014)이 재검사 실패로 끝남. 공통표준에 없는 단어로 바꾸거나 ‘변경’ 신청으로 바꿔야 함. model.html:504 · standardize.html:102 · outputs.html:77 · excel-import.html:250의 같은 값도 함께 바꿔야 함.
2. `assets/app.js:744` ‘같은 이름의 ${same.kn}이 이미 있음’ → `${josa(same.kn, '이/가')}`(‘단어이’ → ‘단어가’).
3. `assets/app.js:1138` `MOCK_TODAY = new Date(2026, 10, 19)`인데 결재 처리 시각(nowStr)은 실제 날짜라, 홈이 ‘11/19(목)’을 보이는 사이 이력에는 11/20이 찍힘. 둘 중 하나로 맞춰야 함.
4. `assets/app.js:1157` SCREENS에 std-common · domain-groups · dict-grid · term-wizard · styleguide 항목 추가(목차 화면 지도 · 목업 › 화면 정보 · 로그인 배너 이름에 쓰임).
5. `assets/app.js:2082~2086` 검토 모드는 `<a>` 클릭만 `&audit=1&as=`를 붙임. `location.href` · `location.replace`로 옮기는 곳은 각 화면이 따로 붙여야 함. 공용 도우미(예: `window.navKeep(url)`)를 두면 화면마다 같은 코드를 쓰지 않아도 됨. 이번에는 approvals · system · settings · audit에 각각 넣음.
