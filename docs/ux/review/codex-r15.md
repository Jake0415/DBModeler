## 시나리오 T1~T10

- T1 통과 — 초기 적재 후 생성된 문서로 자기 승인·최종 승인·사전 반영 경로가 연결됨.
- T2 통과 — 모델에서 등록한 후보가 공유 큐에 표시됨.
- T3 통과 — 예시 DDL을 새 영역으로 가져와 표준 맞추기를 적용하고 시스템 홈과 전체 ERD에서 영역을 열 수 있음.
- T4 통과 — 공유 후보를 PN-12로 전환해 신청·승인·모델 재검토 가능.
- T5 막힘 — 기본 적용 경로에서 연결 용어 신청을 먼저 완료해야 모델 확정 가능(CX15-06).
- T6 통과 — 충돌·연결 끊김 시연과 검토 중 조회 전용 경로 유지.
- T7 통과 — 타인 승인·자기 승인·최종 승인 역할 전환과 Admin 설정 제한 경로 유지.
- T8 막힘 — 0014를 선행 처리하는 단계가 빠져 최종 승인과 v6 시작에 도달하지 못함(CX15-06).
- T9 막힘 — 지도 결재가 차단 예시 0016을 열며, 실제 필터 기준본 비교도 여전히 어긋남(CX15-07, CX14-05).
- T10 통과 — 검색, 403 역할 요청, 요청한 Admin 부여·감사, 로그인 복귀의 기본 경로가 연결됨.

**종료 불가** — r14 상 미해결 항목이 남았고, 확정 결재와 역할 요청의 새 규칙 위반 및 안내 시나리오 막힘이 있습니다.
