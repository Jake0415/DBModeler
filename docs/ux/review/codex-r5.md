# 표준 사전 엑셀 왕복 편집 플랜 독립 검토

## 1. 총평

- E1~E6은 엑셀로 사전을 편집하는 흐름을 잘 잡았고, 특히 셀 단위 보정과 보정본 다운로드는 반복 작업을 줄인다.
- 왕복 편집의 우선 과제는 기준본·엑셀 수정본·현재 승인본을 정확히 대조하고, 사용자가 확인한 변경만 신청하는 것이다.
- 파일 누락, 대기 신청, 상위 항목 변경은 오판 시 여러 항목과 모델에 영향을 주므로 W1 신청 경로에서 먼저 차단 규칙을 확정해야 한다.
- 최종 승인 후에도 제외 행과 미제출 편집분이 남을 수 있어, 반영본과 함께 남은 작업을 확인하고 이어갈 수 있어야 한다.
- v5 목업은 고정 예시 대신 실제 선택과 상태 전이를 공유하는 데이터로, 내려받기부터 반영본으로 재업로드하기까지 검증해야 한다.

## 3. 열린 질문 권고안

1. **파일에서 빠진 행은 기본 무시.** 내려받기 필터, 파일 분할, 복사 및 시트 제외는 삭제 의사와 무관하다. 기준본 범위를 확인할 수 있을 때만 누락을 별도 표시하고, 미사용과 삭제는 각각 명시적 선택·사유·참조 검사를 거치게 한다. (CX5-03, CX5-09)
2. **업로드 1회는 작업 단위, 기본 1종류·동일 결재 단위당 문서 1건.** W1의 한 종류 파일에서는 정상 행을 기본 한 문서로 제출한다. 여러 종류가 섞이면 신청 전에 독립 문서별 건수·결재선과 선행 승인 필요 행을 보여 준다. 코드값처럼 원자성이 필요한 그룹과 도메인·신규 분류의 공동 승인 단위는 유지한다. (CX5-02, CX5-22, CX5-34)
3. **초성은 공통·기관의 현재 표준명에 동일 적용, 과거 이름은 기관의 열람 가능한 이력부터.** 통합 조회 체계를 유지하면서 공통표준 구판의 이름 연결 근거도 보존할 수 있다. 공통은 출처·버전·ID가 검증된 개정 이력을 확보하면 확대한다. 현재명·이전명·금칙어 일치를 구분하고, 초성은 일반 검색과 같은 권한·페이징을 적용한다. (CX5-27, CX5-28)
4. **제정차수는 DA의 공식 공표 시에만 올리는 정책을 권고.** 원문에서 부여한 차수는 그대로 보존하고, 기관 사전이 자체 차수를 관리한다면 공표 주체·시각·근거를 남긴다. 개별 결재는 항목 Vn만 갱신한다. 공식 공표 기능을 W1에서 제공하지 않는다면 가져온 메타데이터를 표시하는 데 그친다. (CX5-23, CX5-32)

## 4. 플랜에 추가할 것

- **왕복 계약과 종료 조건.** 기준본의 범위와 파일·시트·행·항목 식별, 빈 셀 의미, 적용된 기준과 양식 버전을 정한다. 보정본, 반영본, 미해결 행을 각각 어떻게 다음 회차에 쓰는지 안내한다. 예시 완료 조건은 정상 행 최종 승인 후 받은 반영본이 재업로드에서 동일로 판정되고, 제외 행은 기존 업로드에서 이어서 보정되는 것이다.
- **문서·웨이브 반영.** 30에는 5색과 ⛔·📝·⚠의 독립 규칙, 최신 상태에서의 재검사, 기준본과 업로드 상태, MD-11·12·24 처리 규칙을 명시한다. §4의 오래된 단일 결재 문구는 MD-20의 단계별 검사와 맞춘다. 20에는 W0 저장 기반과 W1 ST-R03·04의 왕복·이력 의존 및 완료 조건을 적는다. SC-15 재개·결과 추적은 W1, SC-16은 W1 기본 변경 내역·보고서와 W2 고급 기준점 비교로 나누는 것을 권고한다. 02 §1과 §3.1·§3.3에 역할·진입·복귀를 함께 추가한다.
- **최소 검증 시나리오.** 두 사용자가 같은 기준본을 받고 각기 다른 필드와 같은 필드를 수정하는 경우, 새 대기 신청 발생, 필터링한 파일에서 한 줄 제거, 경고 확인 후 규칙 변경, 공통 항목 링크 접근, 여러 코드값 중 한 건 충돌, 반려·회수·부분 제외 후 재개를 포함한다.

## 5. 목업 v5 변경 목록

- **SC-13 엑셀 가져오기.** 1단계에 기존 빈 양식, 편집 파일 사용 안내, 실제 [이어서 작업] 링크를 둔다. 2~3단계에서 파일 선택·드롭, 종류·시트·기준본 해석 결과와 매핑 오류를 같은 단계 폼과 하단 액션으로 표시한다. 4단계에 작업 진행·취소·완료 상태와 돌아오는 링크를 둔다. 5단계는 5색 범례와 검증 아이콘, 종류별 건수, 선택 범위, 다음 오류, 편집 셀 및 실행 취소를 그리드에 추가한다. 우측 패널에 선택 행의 셀 위치·기준/현재/파일/보정 값·영향·분해 후보를 표시한다. [오류 행 내려받기]와 [보정본 내려받기]를 결과의 보조 액션으로, [신청 준비]를 하단 기본 액션으로 둔다. 6단계에는 실제 신청 및 제외 건수, 행별 예외 확인, 신청 사유, 결재선, 만료 후 재비교를 표시한다. (CX5-07~16, CX5-29~30)
- **SC-10 사전·PN-11 상세.** 기존 검색창과 칩을 실제 필터에 연결하고 검색어가 비면 기관 최근 변경 및 [전체 보기]를 제공한다. 결과에 일치 근거, 버전·수정일, 진행 중 신청 및 열람 가능한 모델 사용처 수를 표시한다. 기존 상단 액션에 [내려받기]를 추가해 편집용 범위·제외 건수와 빈 양식을 보여 준다. 우측 패널은 선택 ID에 맞춰 렌더링하고 공통은 읽기 전용, 기관 대기 항목은 신청 링크와 차단 사유를 표시한다. 이력 탭에는 Vn·제정차수·반영 시각을 각각 표시하고, 필드 전후 비교와 해당 결재 링크 및 이력용 엑셀을 둔다. (CX5-01, CX5-21, CX5-23, CX5-27~28, CX5-31)
- **SC-15 업로드 이력.** 사전과 가져오기 양쪽에 진입점을 둔다. 초안·검증 중·신청 후 결과별 상태, 저장 및 만료 시각, 연결 문서를 목록에 표시한다. 행 상세에서 권한에 따라 이어서 작업·보정본·반영본·남은 행·원본에 접근한다. (CX5-17~22)
- **SC-16 사전 변경 내역.** 사전에서 기간·종류·작업·신청번호로 찾고, 변경 전후와 사용처를 우측 패널에서 본다. 현재 조회 범위를 요약한 보고서 내려받기를 둔다. 두 시점 비교를 보여 줄 경우 반영 범위·시각·삭제 표시가 일치하도록 한다. (CX5-24~26)
- **결재함·후보 큐·알림.** 결재함은 업로드가 만든 실제 문서를 열고, 승인 시 최신 검사와 적용 범위를 보여 준다. 반려·회수는 해당 작업의 보완 링크로 돌아간다. 후보 큐까지 연동할 경우 선택한 후보의 원래 업로드/행으로 돌아간다. 알림은 신청자 등 실제 수신자에게 문서별 반영본 또는 보완 링크를 제공한다. (CX5-19, CX5-22, CX5-32~34)
- **공통 상태·접근성.** 목업 공통 데이터에 사용자·업로드·행·항목·문서 관계를 두고 각 화면이 같은 상태를 읽는다. 필터·오류 이동을 키보드로 실행하고 행 전환 또는 모달 종료 후 초점을 복원한다. 화면 이동 후에도 초안, 대기 상태, 신청번호를 재현한다. (CX5-15, CX5-29~33)

## 6. 우선순위 Top 10

1. **기준본과 행 식별을 확정.** 범위·ID·버전·서명·자료형·매핑 계약부터 맞춘다. (CX5-01~05, CX5-35)
2. **낡은 제출을 차단하고 셀 단위로 재비교.** 동시 제출의 중복과 독립 필드 수정 유실을 막는다. (CX5-06~08, CX5-22)
3. **권한·영향·V0 안전장치.** 공통 읽기 전용, 누락 무시, 참조 중 삭제, 상위 변경의 재검사를 같은 정책으로 집행한다. (CX5-01, CX5-09~10, CX5-21)
4. **검증 의미를 통일.** 5색과 ⛔·📝·⚠, 분해 후보 선택, 단계별 재검사를 같은 결과로 연결한다. (CX5-07, CX5-11~13)
5. **신청 문서와 반영 범위를 확정.** 실제 기안자·선택·사유·결재선을 고정하고 의존성 단위와 재신청 규칙을 정한다. (CX5-19, CX5-22, CX5-34)
6. **승인 결과를 엑셀로 되돌림.** 보정본·승인본·미해결 행, 보완 재신청, 버전과 제정차수를 연결한다. (CX5-17~20, CX5-23, CX5-32)
7. **안전한 오류 보정.** 선택 범위와 전후 미리보기, 작업별 되돌리기, 오류 셀 탐색을 구현한다. (CX5-14~15, CX5-30)
8. **대용량과 작업 재개.** 비동기 검증·취소·재진입, 초안 충돌 방지, 업로드 이력 접근권한을 검증한다. (CX5-16, CX5-20~21, CX5-29)
9. **검색·이력을 실제 데이터로 연결.** 현재명과 이전명, 필드별 전후, 결재 링크, 내보내기 대상 수를 검증한다. (CX5-23~24, CX5-27~28, CX5-31)
10. **문서와 목업의 W1 완료 기준을 맞춤.** SC-15·16의 진입과 범위, 사용자별 알림, 기본 왕복 실습과 고급 비교의 웨이브를 확정한다. (CX5-25~26, CX5-32~33)
