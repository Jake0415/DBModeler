# 정리 — 사전 메뉴 '화면 안내' (2026-11-24)

- 요청: 사용자 — 후보 큐 · 변경 내역도 직접 등록 · 도메인 그룹처럼 간단한 기능 설명과 가이드를 주고, 사전의 모든 메뉴를 같은 모양으로.
- 만든 것: 공통 부품 `pageGuide()`(`assets/app.js` `PAGE_GUIDE`, `assets/app.css` `.pguide`) — 사전 탭 바로 아래, 사전 메뉴 8개 화면(통합 검색 · 엑셀 가져오기 · 업로드 이력 · 직접 등록 · 후보 큐 · 변경 내역 · 도메인 그룹 · 분류 · 공통표준 · 행정표준코드)에 같은 자리 · 같은 모양. 화면마다 따로 있던 안내(도메인 그룹 구축 순서 띠, 공통표준 안내 띠, 직접 등록 흐름 줄)는 이 부품으로 합쳤다.
- 리뷰: Claude UX `claude-dict-guide.md`(DG-01 ~ 16). 상태: **P1 · P2 전부와 P3 일부 적용**.

## 부품 규칙 (01 디자인 가이드 §6.3에 추가)
| 항목 | 규칙 |
|---|---|
| 한 줄 설명 | 늘 보임. 한 문장, "~합니다."로 끝, 45자 안팎. 글자 14px `--fg-2`, 앞에 정보 아이콘(읽기 전용이면 자물쇠) |
| 사용 방법 | [사용 방법 보기 / 접기] 토글(`aria-expanded` · `aria-controls`, 화살표 14px). 번호 단계 3개("~합니다", 마침표 없음, 동사 하나) |
| 메타 줄 | **언제 / 누가 / 참고** 중 있는 것만(12px). '언제'는 "~할 때" |
| `[ ]` | 화면 버튼 라벨을 **글자 그대로** 옮긴다 |
| 링크 | "조건 → 화면 이름" (조건은 명사구) |
| 용어 | 사용자의 행위 = **신청**, 승인 과정 = **결재**, '품의'는 버튼 이름을 인용할 때만 |
| 역할 변형 | 권한이 없으면 설명 · 단계 · 링크를 '볼 수 있는 것'으로 바꾸고 "보기만 가능 — 신청은 모델러 · DA"를 설명 줄에 붙인다. 이때 화면의 읽기 전용 띠는 숨긴다(상자 하나) |
| 펼침 | 그 화면 첫 방문만 펼침, 두 번째부터 접힘(사용자가 펼쳐 두면 유지). [다른 화면도 접기]로 모두 접기. `?` 키로 열기/접기(입력 칸 밖). 접힌 높이 37px · 펼친 높이 89px |
| 이름 | 랜드마크 `section[aria-label="○○ 화면 안내"]` |

## 확인
1600에서 8개 화면 × 2역할(모델러 · DA / 기관 담당자) 오류 0, 안내가 사전 탭 바로 아래 한 번만, 기관 담당자의 직접 등록 · 엑셀 가져오기는 자물쇠 안내 하나(화면 읽기 전용 띠 숨김), 두 번째 방문 접힘(37px), 단축키 팝오버 열림.

## 후속 (2026-11-24, 사용자 피드백) — 기본 접힘 · 후보 큐 설명 보강
- **공간 우선:** 안내는 **기본으로 접혀 있고 높이 0**. 사전 탭 줄 오른쪽 끝 **[ⓘ 화면 안내]** 버튼(또는 `?` 키)으로 펼치면 탭 바로 아래에 패널이 열린다. 패널 오른쪽 [접기] · Esc로 닫는다. 펼쳐 둔 화면만 다음에도 펼쳐 둔다(`dbm-guide-<id>`). 첫 방문 자동 펼침 · [다른 화면도 접기] · 읽기 전용 띠 합치기는 없앴다(접힌 안내 대신 화면의 읽기 전용 띠가 그대로 보임).
- **후보 큐 설명 보강:** 한 줄 설명을 "모델에서 사전에 없는 단어 · 용어를 쓰면 '후보'로 올라옵니다. DA가 검토해 사전에 넣을지 정합니다."로 바꾸고, 펼친 패널에 세 칸을 더했다 — **후보란?**(어디서 오나 · 같은 이름 묶음 · 그동안 미준수) · **처리 세 가지**([… 신청으로 전환] · [기존 표준어 사용 안내] · [반려]가 각각 무엇을 하는지) · **상태 뜻**(대기 · 신청 전환 · 등록 완료 · 반려 · 기존 표준어 안내). 다른 화면도 같은 `x` 칸을 쓸 수 있다.
- 확인: 8개 화면 × 2역할 접힘 0px · 오류 0 · 탭 줄 넘침 0, 펼침 107px(후보 큐 245px).

## 확장 (2026-11-24) — 결재함 · 설정 · 감사 로그
- 같은 부품 · 같은 동작(기본 접힘 · [ⓘ 화면 안내] · `?` 키 · Esc · 펼친 화면만 기억). 탭 줄이 없는 화면이라 버튼은 **화면 머리 오른쪽 끝**(감사 로그는 [엑셀] 다음), 패널은 머리 바로 아래(설정은 탭 줄 아래)에 열린다.
- 결재함: 3단계(대기함 → 승인 · 반려 → 내 신청 · 회수) + **함 구분**(대기함 · 내 신청 · 참조함 · 집계) · **결재 흐름**(DA 승인 · 최종 승인 · 승인할 때 재검사 · 반려 · 회수 사유). 결재 역할이 없으면 [내 신청] 중심 단계로 바뀜.
- 설정: 3단계(탭 고르기 → 탭 점 · [저장] 막대 → 저장 · 되돌리기) + **탭별로 정하는 것**(기관 · 시스템 · 사용자 · 역할 · 권한표 · 검수 기준). 관리자만.
- 감사 로그: 3단계(검색 · 종류 칩 → 기간 → [엑셀]) + **종류 칩 뜻**(자기 승인 · 영구 삭제 · 결재 · 역할 · 권한 · 설정 · 더보기). 고칠 수 없음 · 5년 보관.
- 확인: 1600 · 1920, 결재함(김모델 · 박설계 · 이현업) · 설정(이데이터) · 감사 로그(이데이터 · 김모델) 오류 0 · 머리 넘침 0 · 접힘 0px, 펼침 231 · 253 · 275px.
