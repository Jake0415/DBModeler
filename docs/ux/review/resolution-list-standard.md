## P1 적용 결과 (2026-11-23)
| 항목 | 적용 |
|---|---|
| 공통 | 로빙 tabindex + `aria-selected`, 페이지가 처리하지 않은 ↑↓ 행 이동, 숨은 건수 알림 칸(`liveCount`), 칸별 검색 `listMatch`(3 프로필), 소유 키만 쓰는 `urlSync`, `filterRows` 빈 결과(`er none` · 모두 지우기 · `.is-empty`, 데이터가 아예 없으면 화면의 `er first`를 그대로 둠) |
| 업로드 이력 | 검색(파일 · 업로드 번호 · 신청번호), 건수 줄 + 적용 칩 + 모두 지우기, 필터로 빈 결과 구분(결함 고침), 패널 기본 닫힘 + 닫기 시 행으로 포커스, 주소 `q` `f` `sel`(옛 `b` 별칭) |
| 사전 | 여러 낱말 AND · 띄어쓰기 흡수 · 모든 칸 대소문자 무시, 낱말별 강조, 검색어 적용 칩, 모두 지우기에 검색어 포함, 전체 선택은 그린 500행 기준 + '필터에 맞는 전체 n건 고르기'(결함 고침), 숨은 선택 수 표시, 건수 줄 `aria-live` 제거, 주소는 소유 키만(검토 모드 키 보존), 문구 '필터 초기화' · '모두 지우기' |
