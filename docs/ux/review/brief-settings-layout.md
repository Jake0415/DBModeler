# 리뷰 요청 — 설정 화면 '왼쪽 치우침' 배치 개선 · 설정형 화면 가이드

## 대상
- 화면: `docs/ux/mockups/settings.html` — http://localhost:5178/settings.html?as=lee&audit=1 (관리자 이데이터). 탭: 기관 · 시스템 · 사용자 · 역할 · 권한표 · 검수 기준.
- 비교할 화면: `mypage.html`(마이페이지, 같은 '폼 + 표' 성격), `audit.html`(감사 로그, 표), `approvals.html`(결재함, 목록 + 오른쪽 상세), `dictionary.html`(표준 사전), `model.html`(왼쪽 트리 있는 화면).
- 공통 셸: `assets/app.css`(`.page`, `.page-header`, `.pad`, `.scroll`, `.tabs`), `assets/app.js`(상단 바 · 왼쪽 트리 — 설정은 트리 없는 '상단 메뉴 화면').
- 기준: `docs/ux/01-design-guide.md`(레이아웃 · 간격), `docs/ux/22-list-standard.md`(목록), `docs/ux/17-publishing-audit.md`.
- 사용자: 관리자(가끔 와서 몇 개 바꿈), DA. 화면 1920 기본 · 1600 최소.

## 관찰 (사용자 제보 · 코드)
| # | 관찰 | 근거 |
|---|---|---|
| S1 | 1920에서 기관 · 시스템 · 검수 기준 탭의 내용이 **왼쪽 960px**에만 있고 오른쪽 약 900px가 비어 있다. 사용자: "설정 화면만 왼쪽 치우침이 심하다" | `settings.html` `.set-wrap { max-width:960px }`, 화면은 트리가 없어 본문이 창 전체 폭 |
| S2 | 행 구조: 왼쪽 240px 항목 이름 · 설명, 오른쪽 입력. 결재선 템플릿 같은 표가 입력 칸 안에 들어 있다 | `.set-row { grid-template-columns:240px 1fr }` |
| S3 | 사용자 · 역할 · 권한표는 표라서 전체 폭을 쓴다 → 탭마다 본문 폭이 960 ↔ 전체로 바뀐다 | 같은 파일 |
| S4 | 저장은 아래 고정 막대 [되돌리기][저장], 탭에 미저장 점, 화면 안내는 머리 오른쪽 [ⓘ 화면 안내] | `.setbar`, `pageGuide` |
| S5 | 다른 상단 메뉴 화면(마이페이지 등)이 같은 문제를 갖는지 확인 필요 | — |

## 검토 요청
1. 왼쪽 치우침의 원인과 영향(시선 이동 · 빈 공간 · 탭 간 폭 변화 · 저장 막대와의 거리)을 평가하라.
2. 개선 방식 후보를 비교하라(장단점 · 1920/1600 · 탭별 · 구현 난이도). 최소한 아래를 포함:
   - A. 본문 열을 가운데 정렬(최대 폭 유지)
   - B. 왼쪽 **섹션 목차(앵커 내비)** + 오른쪽 폼(설정형 SaaS 흔한 배치)
   - C. 폼 폭을 넓혀 2열 배치(항목 카드 그리드)
   - D. 오른쪽에 **도움말 · 마지막 변경 · 영향 범위** 보조 열
   - E. 그 밖의 안(직접 제안)
3. 권고안 하나를 정하고, 1920 · 1600 폭 예산(px)과 텍스트 와이어프레임을 그려라. 탭마다(폼 탭 · 표 탭) 어떻게 보이는지 포함.
4. 마이페이지 등 **같은 성격의 화면에 함께 쓸 '설정형 화면 레이아웃 가이드'** 규칙을 제안하라(최대 폭, 정렬, 섹션 간격, 라벨 열 폭, 저장 막대, 화면 안내 위치, 표 탭과 폼 탭의 폭 통일 여부).
5. 우선순위(P1/P2/P3).

## 출력
- 지정 경로에 한국어 마크다운: 한 줄 총평 → 지적(ID · 심각도 · 근거 → 권고) → 후보 비교표 → 권고안 와이어프레임(1920 · 1600) → 가이드 규칙 → 우선순위.
- **목업 파일은 고치지 말 것.**
