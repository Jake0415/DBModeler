닫힘 수에는 각 목록의 본 항목만 포함했다. 대표 ID와 07 §4 개별 정책은 해당 목록의 분모에 포함하지 않았다. 아래 순위는 양쪽 검토에서 확인한 영향과 이번 재검토를 합친 제안이다.

1. **엑셀 묶음과 결재 문서의 제출 내용을 보존한다.** 행·선택·사유·집계를 문서별로 고정하고 진행 중 재개, 동일 제출 재시도, 반려 후 보완을 구분한다. 예시·잘못된 재개 주소에서 자동 쓰기를 막는다. (CX7-06~09, CL7-01·02·04, CX8-02)
2. **결재와 편집 권한을 실행 시점에 확인한다.** 상세·배너·참조함 가시성을 맞추고 승인·반려·회수·모델 편집·업로드 재개에서 최신 역할과 단계·잠금을 검사한다. (CX7-03·05·07, CL7-18·24·30)
3. **사전 항목과 왕복 기준본을 상태에 연결한다.** 선택 항목 변경과 대기 목록을 문서에 전달하고, 승인·공표 뒤 항목 값·Vn·제정차수·검색·이력을 갱신한다. 내려받은 범위·ID·양식과 출발 값을 보존한다. (CX7-16~18, CL7-05~07·21·23, 07 T1·T9)
4. **모델 확정본과 결재 판정을 같은 버전에 연결한다.** 제출 구조를 보존하고 당시 모델로 재검사한다. 비교·확정본 링크와 다음 버전의 작업 시작, 홈과 시스템 상태를 실제 영역·문서에 맞춘다. (CX7-01·02·04·24, CL7-13~16, CX8-03)
5. **신청 조건과 최신성 검사를 묶는다.** 0건·누락 사유·미확인 후보를 확인하고, 파일 값 선택·분해 결과·경고 확인을 제출 행에 기록한다. 칸 단위 병합, 대기·빠짐·의존성·대량 자기 승인 요약을 제출과 결재에서 검증한다. (CX7-10·11·14, CL7-03·10·17·19·25, 07 T2~5)
6. **표준 맞추기는 선택 범위와 처리 방식대로 적용한다.** 영역·행 ID·처리·사유를 넘겨 예외·비대상·후보를 실제 상태에 연결하고 취소 범위를 명시한다. FK 영향은 실제 관계별 속성으로 계산한다. (CX7-03·23, CL7-08~12, R3·R6)
7. **엑셀 보정의 미리보기·취소·오류 탐색을 맞춘다.** 가시 행만 적용하고 실패한 값을 복원한다. 이후 선택을 이전 보정 취소가 지우지 않도록 하며 F8과 오류 결과에서 대상 행을 찾을 수 있게 한다. (CX7-12·13·20, CL7-26, CX8-01)
8. **반영본과 남은 작업을 연결한다.** 동일 반영본 재업로드를 동일로 판정하고 보류 재검증·보완 이어서 작업을 제공한다. 검증 완료, 신청 결과, 묶음별 모델 재검토 알림을 담당자와 실제 대상에 연결한다. (CX7-22, CL7-27, 07 T6·T8, CX8-04)
