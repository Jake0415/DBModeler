> 기준 문서: `01-design-guide.md`, `02-flows.md`, `03-erd-editor.md`, `05-mockup-vs-da.md`
> 방법: HTML/JS를 직접 읽고 각 버튼·칩·행 클릭의 실제 결과를 확인했습니다. "동작 없음"은 이벤트 핸들러도 링크도 없다는 뜻입니다.

## 1. 총평

- 핵심 흐름(사전 신청 → 결재 → 모델 → 표준 맞추기 → 확정)은 화면 단위로 연결돼 있고, 모델 캔버스는 목업치고 동작 수준이 높습니다(자동완성·끌어 놓기·되돌리기·배타 관계·표 보기).
- 하지만 **"되돌릴 수 없는 결정"을 내리는 지점의 방어가 약합니다.** 반려 사유 필수인데 빈칸으로 제출됨, 후보 반려는 클릭 한 번, 모델 확정 승인과 표준 맞추기 "8건 적용"은 확인·되돌리기가 없습니다.
- 모델 편집에도 막다른 길이 있습니다. 속성 상세(NULL·기본값·설명) 편집, 관계 삭제·수정, 엔터티 정의 입력이 없고, 사전 패널은 한 번 접으면 다시 열 수 없습니다.
- **역할 겸임 처리가 목업에서 검증되지 않습니다.** 김모델(모델러·DA)이 최종 승인 단계 문서를 승인할 수 있고, Admin이 아닌데 자기 역할에 Admin을 줄 수 있습니다. 권한 없음 상태가 하나도 없습니다.
- SW 기본 요소가 거의 비어 있습니다. 사용자 메뉴·마이페이지·알림 센터·버전 정보·도움말·로그인/세션 만료·오류 페이지·감사 로그 화면이 없고, 전역 검색은 모양만 있습니다.

## 3. 꼭 필요한데 없는 화면·기능

**사용자 마이페이지 — 없음**
- 프로필: 이름·소속·메일(조회), 표시 이름 수정
- 내 역할·담당 시스템(조회 전용, 바꾸려면 Admin에게 요청)
- 알림 설정: 앱/메일 종류별 받기(결재 요청·결과·참조·후보·재검토), 메일 범위는 정책 안에서만
- 내 신청(결재 상태별)·내 작업(최근 편집한 업무 영역·후보 등록 이력)
- 보안: 비밀번호 변경(자체 인증일 때) 또는 SSO 안내, 접속 중인 세션 목록·다른 세션 로그아웃
- 환경: 테마(라이트/다크/시스템), 단축키 켜기/끄기, 시작 화면 선택

**알림 센터 — 없음 (벨은 결재함 링크)**
- 드롭다운 패널: 안 읽음 수, 종류 필터, 모두 읽음
- 항목: 결재 요청·결과·회수, 참조, 엑셀 검증 완료, 후보 처리 결과, "재검토 가능", 공동 편집 충돌
- 항목 클릭 → 해당 문서·화면, 오래된 알림 보관 기간

**제품 버전 정보(About) — 없음**
- 제품명·버전·빌드 번호·빌드 일시, 서버/클라이언트 버전 불일치 경고
- 릴리스 노트(이번 버전 변경점), 공통표준 사전 버전(예: 2025.11)과 적재일
- 오픈소스 라이선스 목록(React Flow·Yjs·elkjs·Pretendard·Geist 등)
- 지원 연락처·문의 채널

**도움말·단축키·온보딩 — 거의 없음**
- `?` 단축키 도움말 시트(03 §9 표 그대로)
- 화면별 도움말 링크, 용어 설명(예외 vs 비대상, 게이트 A/B)
- 첫 로그인 안내(역할별 3단계 투어), 사전 빈 상태 외 빈 상태(결재함 0건, 후보 큐 0건, 업무 영역 0개)

**로그인·로그아웃·세션 — 없음**
- 로그인 화면(사내 SSO/LDAP 또는 ID·비밀번호), 실패 안내, 잠금 정책
- 세션 만료 예고(n분 전)와 만료 시 편집 내용 보관 후 재로그인
- 로그아웃(공동 편집 중이면 접속자 목록에서 빠짐 안내)

**권한 없음·404·오류 페이지 — 없음**
- 403: 어떤 역할이 필요한지 + 요청 대상(Admin) 안내
- 404: 삭제·이동된 문서/업무 영역, 홈으로
- 500/점검 중: 재시도, 상태 안내
- 1600 미만 권장 해상도 배너(01 §5에 정의, 목업 없음)

**감사 로그 — 없음 (자기 승인 모달·설정에서 "감사 로그에 남는다"고만 언급)**
- 누가·언제·무엇을(결재 처리, 자기 승인, 설정 변경, 역할 변경, 사전 반영, 모델 확정)
- 필터(사용자·기간·종류), 엑셀 내보내기, 수정·삭제 불가 표시

**전역 검색 — 자리만 있음**
- 사전·모델(엔터티·속성)·결재 문서 통합 결과, Ctrl+K 명령 팔레트(화면 이동·명령 실행)

**데이터 내보내기·백업 — 일부만**
- 있음: 산출물·DDL·모델 검토·DBMS 비교 엑셀
- 없음: 사전 전체 내보내기, 모델 전체 백업/복원(JSON 등), 버전 이력 화면(02에서 W2로 미룸), 삭제 보관함

**시스템 상태(Admin) — 없음**
- 공동 편집 서버 연결·접속자 수, 메일 발송 실패 큐, 백그라운드 작업(엑셀 검증·분석) 상태, 디스크·DB 용량

**홈(시작 화면) — 없음**
- 로고 클릭 대상이 없고 첫 화면이 정해져 있지 않음. "내 차례 결재·최근 업무 영역·내 후보 처리 결과"를 모은 홈 필요

## 4. 우선순위 Top 10

1. **CL-38 권한 없는 사용자의 설정·역할 변경** — 공공기관 제품에서 자기 권한 상승은 보안 감사에서 바로 걸리는 문제입니다.
2. **CL-04·CL-05 결재 대상·자기 승인 판정 오류** — 결재 신뢰성의 근본이고, 겸임이 흔한 환경이라 실제로 자주 일어납니다.
3. **CL-01·CL-02·CL-33 필수 사유 없이 반려·예외 처리** — 감사 추적에 남아야 할 사유가 빈 값이 되면 되돌릴 수 없습니다.
4. **CL-31 표준 맞추기 일괄 적용에 확인·되돌리기 없음** — 운영 DB 물리명까지 바꾸는 가장 영향 큰 일괄 동작입니다.
5. **CL-21·CL-22 속성 상세·관계 편집 불가** — 모델러의 기본 업무를 끝까지 할 수 없는 막다른 길입니다.
6. **CL-44 사용자 메뉴·마이페이지·로그아웃 없음** — 모든 사용자가 매일 쓰는 기본 기능이고 셸 설계에 영향을 줍니다.
7. **CL-43 알림 센터 없음** — 엑셀 검증·후보·참조처럼 "알림으로 알려 준다"는 흐름이 받는 곳 없이 끊깁니다.
8. **CL-42 전역 검색·명령 팔레트 미동작** — 디자인 가이드의 핵심 내비게이션 수단인데 검증되지 않았습니다.
9. **CL-10·CL-19 차단 조건이 있는데 제출됨** — 화면 문구와 실제 동작이 다르면 사용자가 안내를 믿지 않게 됩니다.
10. **CL-45·CL-46·CL-47 접근성(라이브 영역·키보드·대비)** — 공공기관 웹 접근성 인증(KWCAG) 대상일 가능성이 높아, 컴포넌트 단계에서 잡아야 비용이 적습니다.
