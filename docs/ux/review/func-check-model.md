# 기능 점검 — 모델 화면군 (model · standardize · term-wizard · ddl · outputs · import)

- 점검일: 2026-11-20 · 대상: `docs/ux/mockups` 정적 목업
- 방법: 내장 브라우저 전용 탭에서 실제 클릭(computer/find ref)·키 입력 + 페이지 안 순회 스크립트(보이는 버튼·링크·탭·칩·선택 상자를 하나씩 누르고, 누를 때마다 `window.__errs`·콘솔 오류·이동 주소 기록, 이동은 막고 주소만 기록)
- 역할: kim(모델러+DA, 기본) · park(모델러) · lee(Admin+DA) · hyun(기관 담당자) · choi — 주소에 `&audit=1&as=<역할>`
- 화면 크기: 1920×1080, 1600×900
- 데이터: 다른 작업자와 localStorage가 겹치지 않도록 같은 정적 파일을 별도 포트(5187)로 띄워 점검했습니다. 5178에서 처음 점검하며 바뀐 모델 데이터 키는 백업본으로 되돌렸습니다.
- 결과 표기: **정상** = 그대로 동작 · **수정함** = 결함을 고침 · **남김** = 목업 범위 밖이거나 공용 파일 수정이 필요해 남김
