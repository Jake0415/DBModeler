## 1. 총평

1. **P0 닫힘률은 13/23행(57%)** 입니다. 부분 8 · 열림 1 · 회귀 1. T1(데이터 손실)과 T2(권한)는 거의 닫혔고, 남은 문제는 T4(표준 정합성 0/3)와 T5(확정 결재)에 몰려 있습니다.
2. 가장 큰 구조 문제: 결재 상태는 `dbm-docs`에 저장하는데, **모델 화면 잠금은 URL `state=`만 보고 정합니다.** 그래서 DA 대기 중에도 내비에서 모델을 열면 편집할 수 있고, 리스크 링크를 누르면 REQ-0015 [회수]가 나옵니다. 재신청하거나 v6에서 다시 신청하면 승인이 끝난 REQ-0015를 되돌리고 이력까지 지웁니다(회귀).
3. 표준 맞추기는 미리보기·요약을 잘 만들었지만, [적용]이 **선택과 처리 방식을 무시하고** 모델에 늘 같은 고정 결과를 보여 줍니다. 필터로 숨긴 행도 선택에 들어가고, 화면이 약속한 [실행 취소]도 없습니다.
4. T6 셸(사용자 메뉴·마이페이지·알림·제품 정보·단축키·홈·오류·감사)은 §3 명세의 뼈대를 대부분 갖췄습니다. 빠진 것은 알림의 대상·상태 연동, 1600 미만 해상도 배너, 로그아웃 화면에 남는 로그인 셸입니다.
5. v5에서 먼저 할 일: **결재 문서를 단일 원천으로 삼아 잠금·버전·버튼을 계산**하고, **신청 번호·이력은 바꿀 수 없게** 하고, **선택 = 실행 범위**를 모든 일괄 동작에 적용합니다.

## 4. 06 §3 명세 대비 빠진 것

- **§3.1 버전 3종 구분**
  - 사전 버전은 사전 화면 헤더에 "공통표준 2025.11 · 기관 사전"만 있고 **제정 차수·적재일이 없음**(dictionary.html:17). 결재 문서와 산출물 표지에는 사전 버전이 없음.
  - "서버와 화면 버전이 다를 때 배너"가 없음. 제품 정보의 "최신 버전" 배지가 고정(app.js:145).
- **PN-50 사용자 메뉴**: 내용은 모두 있음. `role=menu`의 화살표 이동과 포커스 복귀가 없음.
- **SC-51 마이페이지**
  - 내 신청에 "반려 보완 바로가기"가 없음(열기만).
  - 내 작업의 "내 후보 처리 결과"가 1행 고정.
  - 시작 화면 설정이 동작하지 않음.
  - 알림 설정은 앱·메일 × 종류가 있지만, 결재 역할이 없는 사용자에게도 "결재 요청 메일 필수"가 보임.
- **PN-52 알림 센터**

  - 사용자 기준 수신이 아님.

  - 벨의 `aria-label` "알림 N건"이 읽음 처리 뒤에도 그대로.
- **MO-53 제품 정보**: 거의 완비. 라이선스 전문과 버전 복사는 토스트(목업 허용).
- **PN-54 단축키**: **검색 기능 없음**.

## 5. v5 우선순위 Top 10

1. **결재 상태를 단일 원천으로**: 모델의 잠금·버전 배지·[확정 신청/회수/v6] 버튼을 `dbm-docs`에서 계산하고, `area`별 문서와 연결(CL3-01·03·04, CL-03).
2. **신청 번호·이력 불변**: 신청할 때마다 새 번호, 끝난 문서는 수정 불가, 보완 재신청은 원본에 연결, `?new=` 배너는 실제 결과로(CL3-02·15, CX-31 회귀).
3. **표준 맞추기 적용을 실제로 반영**: 선택 행 × 처리 방식을 모델에 전달하고, REQ-0017을 결재함에 생성하고, 적용 후 [실행 취소]를 제공(CL3-05·12, CX-18, CL-32).
4. **선택 = 실행 범위 규칙을 모든 일괄 동작에**: 필터 밖 제외, 숨은 선택 수 표시, 상태별 허용 처리(CL3-06·07, CL-33).
5. **조회 전용 경계 완결**: 끌기·메모·키보드(Enter/Delete) 경로까지 `viewOnly`·잠금 검사(CL3-08·19).
6. **준수율·예외 수 단일 계산**: 확정 패널 카드, 결재 문서, 표준 맞추기 칩, 시스템 전체 카드를 같은 함수로 계산하고 신청 직전 재검사. 찾기/바꾸기 후 실제 재매칭(CL3-09·14, CX-21).
7. **사유 필수 공통 컴포넌트 전면 적용과 엑셀 후보 확인 게이트**(CL3-13, CL-19·CX-17).
8. **실행 취소를 동작 단위로**: 스냅숏 ID 연결, 사라지지 않는 되돌리기 이력, 삭제 영향은 관계의 FK 매핑으로 계산(CL3-10·11).
9. **알림·후보의 대상 정확성**: 사용자 ID로 수신, 문서 상태 연동, 후보 패널·모달·처리 대상을 행별로 일치(CL3-17·18).
10. **셸·작업 공간 마무리**: 로그아웃·만료 화면 셸 제거, 1600 미만 배너, 모델 화면 내비 레일(캔버스 756 → 약 920), 감사 로그 필터 연결, T10 잔여(칩 버튼화·대비 4.5:1·포커스 가두기)(CL3-20·22·23, CL-46·47, CX-40).
