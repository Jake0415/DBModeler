# 리뷰 — 설정 화면 '왼쪽 치우침' 배치 개선 · 설정형 화면 가이드

> 2026-11-24 · 검토자: Claude(UX) · 대상: `settings.html?as=lee&audit=1`(5개 탭) · 비교: `mypage.html` · `audit.html` · `approvals.html` · `dictionary.html` · `model.html`
> 측정: 내장 브라우저 1920×1000 · 1600×900에서 DOM 실측(px). 목업 파일 · 저장값은 바꾸지 않았다(화면 안내를 한 번 열고 닫은 뒤 `dbm-guide-*` 키 삭제 확인).
> 참고: 브리프는 탭 6개로 적었지만 실제 탭은 **5개**(기관 · 시스템 · 사용자 · 역할 · 권한표 · 검수 기준 — '사용자 · 역할'이 한 탭).

## 한 줄 총평

원인은 "폼을 960px로 묶은 것" 자체보다 **폼 탭만 960px 상자 · 표 탭은 창 전체 폭**이라는 두 규칙이 한 화면에 섞인 것이다. 가운데 정렬(A)이나 앵커 목차(B)보다, **행은 창 폭 전체로 긋고 입력 칸만 760px로 제한한 뒤, 남는 오른쪽을 '행별 보조 칸'(마지막 변경 · 적용 시점 · 영향 범위)으로 쓰는 안(E)**을 권한다. 제품 규칙(01 §해상도 "창 폭에 맞춰 꽉 채움")과 맞고, 탭 간 폭 변화가 사라지며, 지금 라벨 칸에 끼어 있는 '마지막 변경'과 입력 아래 흩어진 '저장하면 다음 신청부터 적용' 문구가 제자리를 찾는다.

### 4.6 보조 칸에 넣을 것 (행별)

## 5. 설정형 화면 레이아웃 가이드 (설정 · 마이페이지 공통, 01 디자인 가이드에 추가 제안)

**적용 대상**: 트리 없는 상단 메뉴 화면 중 '값을 바꾸고 저장하는' 탭을 가진 화면(설정 · 마이페이지 · 이후 기관/시스템 관리류).

| # | 규칙 | 값 |
|---|---|---|
| G1 | **본문 상자는 모든 탭이 같다** — 창 폭 − 좌우 20. 탭에 따라 상자 폭을 바꾸지 않는다 | `.pad` 20 · max-width 없음 |
| G2 | 폼은 **설정 행**(`.set-row`)으로 쓴다: 라벨 · 입력 · 보조 3칸 | `grid-template-columns: 240px minmax(480px,760px) minmax(280px,1fr); column-gap: 24px 32px` |
| G3 | 라벨 칸 240 고정(설정 · 마이페이지 공통, 220 폐기). 이름 14px/500 + 설명 12px 최대 2줄. 상태 · 이력은 라벨 칸에 넣지 않는다 | |
| G4 | 입력 칸 최대 760. 입력 2개 나란히는 각 368(`.field-row`). 숫자 입력은 72 + 단위 + 허용 범위 | 텍스트 한 줄 입력은 760을 다 쓰지 않아도 됨 |
| G5 | 보조 칸 = 마지막 변경(시각 · 사람) → 적용 시점 → 영향 범위 · 경고 → 관련 화면 링크 순. 12~13px, 글자 최대 520. 없으면 비움 | 탭 끝 경고 띠 금지 — 해당 행 옆으로 |
| G6 | 행 구분선은 본문 상자 끝까지(1px `--border`). 행 위아래 16 | |
| G7 | 탭 안 행이 5개를 넘거나 주제가 둘 이상이면 **소제목 묶음**: 15px/600, 위 32 · 아래 8, 소제목 아래 선 없음 | 앵커 목차는 쓰지 않는다(탭이 목차) |
| G8 | 표가 들어간 행은 **넓은 행**(`.set-row.wide`): 표가 입력 + 보조 칸을 합쳐 쓰고 최대 1200 | |
| G9 | 표 탭(목록 · 행렬)은 본문 상자 전체. 목록 + 상세는 결재함처럼 테두리 상자 없이 끝까지, 오른쪽 패널 01 D3(420/380) | 행렬 표는 역할 열 고정폭 · 설명 열이 나머지 |
| G10 | **저장 단위 = 화면**, 저장 버튼은 **하단 저장 막대 하나**(`.setbar`, 56px, 변경 있을 때만). 막대 메시지 = 바뀐 탭 · 항목 수 + [변경 보기]. 탭 머리에 미저장 점. 탭 안에 [저장] 버튼을 따로 두지 않는다 | 마이페이지 탭 안 [저장] → 막대로. 단 즉시 실행 동작(비밀번호 변경 · 테스트 발송 · 사용자 등록)은 막대 대상 아님 |
| G11 | 저장 영향이 큰 변경(DBMS · 명명 · 검수 기준)은 [저장] 누를 때 확인 창에서 영향 요약을 한 번 더 보여 준다 | 보조 칸 경고와 같은 문구 |
| G12 | [ⓘ 화면 안내]는 **탭이 있으면 탭 줄 오른쪽**, 없으면 머리 오른쪽. 펼친 안내는 탭 줄 아래 전체 폭 띠 | 01 §화면 안내와 일치시킴 |
| G13 | 정렬은 **왼쪽 정렬**. 머리 · 탭 · 본문 왼쪽 끝을 x20에 맞춘다(가운데 정렬 금지) | |
