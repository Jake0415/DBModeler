# DBModeler 클릭 목업 v4 독립 UX 검증

## 1. 총평

P0 닫힘률은 **35.1% (13/37 ID)**다. 나머지는 부분 21, 열림 2, 회귀 1이다. §2의 T1~T5에 명시된 이전 ID를 한 건씩 셌고, T6에도 나오는 CX-47은 한 번만 집계했다.  
속성 취소·필터 범위·비Admin 설정 차단과 DA/최종 승인 구분은 개선됐다. 모델 잠금, 문서 귀속, 표준 적용 결과는 화면 사이에서 여전히 어긋난다.  
기본 셸과 패널 재열기 경로는 추가됐다. 역할별 대상 일치, 완료 피드백, 키보드 조작은 보완이 필요하다.  
HTML·JS·CSS를 직접 추적하고 결재 상세·귀속과 준수율 경계는 Node에서 원본 함수로 확인했다. 브라우저 픽셀·낭독기 실측은 수행하지 않았다.

## 5. v5 우선순위 Top 10

1. **문서와 모델의 권한·상태를 한 곳에서 판정한다.** 역할, 신청자, 문서 ID, 영역·버전으로 직접 링크, 편집, 회수, 확정본, v6 시작을 통제한다. (CX3-01, 04, 05, 16, 25)
2. **제출 문서의 실제 귀속과 안전한 상태 전이를 보장한다.** 현재 제출자·사유·신청 묶음·결재선으로 문서를 생성하고 다른 탭의 처리로 바뀐 단계와 이력을 재확인한다. (CX3-02, 03, 24)
3. **표준 적용 요약과 모델 변경·실행 취소를 일치시킨다.** 선택 행과 처리 방식별 변경 결과를 모델·결재함·후보 큐에 전달하고 작업 단위로 되돌린다. (CX3-09, 11, 12)
4. **준수율과 게이트를 같은 판정으로 계산한다.** 엔터티·속성의 이름과 타입, 예외·비대상·신청 중·미산정 상태를 분리하고 신청 및 승인 직전에 재검사한다. (CX3-06~08)
5. **필수값과 엑셀 후보 확인을 한 번에 검증한다.** 빈 사유, 숨은 사유의 재사용, 미확인 후보를 차단하고 행별 결과와 실제 제출 집계를 연결한다. (CX3-10, 20 / CL-19, CX-17)
6. **검토 자료와 감사 이력을 실제 문서에 연결한다.** v4/v5별 스냅숏·변경 비교·산출물을 열고 현재 처리 이력, 사유, 검색·내보내기 결과를 같은 문서에서 확인한다. (CX3-15, 22)
7. **ERD 삭제와 일괄 편집의 계수·대상을 검증한다.** 관계별 FK와 속성 ID를 써서 누락·중복·다른 행 수정 및 최신 작업 오취소를 막는다. (CX3-12~14)
8. **수신인별 알림과 사용자 설정을 업무 결과에 연결한다.** 처리된 결재와 후보·참조·재검토 결과를 알리고 현재 사용자의 설정값과 이동 대상을 적용한다. (CX3-17, 21, 23)
9. **1600과 키보드로 같은 업무를 끝까지 수행할 수 있게 한다.** 패널 전환 시 작성 상태를 안내하고 좁은 툴바, 모달 초점, 사전·노드 선택과 대비를 검증한다. (CX3-18, 19 / CL-15, CL-16, CL-47)
10. **오류·재인증 후 원래 작업으로 돌아오게 한다.** 404·500의 실제 출발점, 만료 예고, 초안 보관과 복구, 역할 요청 직접 진입을 연결한다. (CX3-22 / CX-47, SC-56, SC-57)
