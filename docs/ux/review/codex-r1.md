# DBModeler 클릭 목업 독립 UX 검토 — CX

## 1. 총평

- 사전 → 결재 → 모델 → 표준 맞추기 → 물리 → DDL의 큰 정보 구조와 상태 표시는 업무 맥락을 잘 전달한다.
- 주요 버튼 상당수가 화면 이동·토스트에 그쳐 T1~T6를 업무 결과까지 일관되게 완료할 수 없다.
- 기존 속성의 Esc 삭제, 필터 밖 일괄 변경, 근거 없는 준수율 100%, 결재 대상·단계 불일치를 먼저 해결해야 한다.
- 마이페이지·알림 센터·제품 버전 정보·인증 및 장애 복구 화면은 없거나 진입점만 있다.
- 지정 HTML 전부, 공통 JS/CSS와 기준 문서 4종을 직접 읽어 이벤트 경로를 대조했다. 브라우저 클릭 실행·1600 렌더링·스크린리더 실측은 하지 않았다.

심각도: **상** = 데이터 손실·잘못된 승인/표준 판정·핵심 업무 중단, **중** = 반복 업무 지연·운영 기능 누락·접근성 장벽, **하** = 영향이 작은 일관성 문제. 가짜 데이터와 비영속성 자체는 목업 전제로 인정하되 입력·선택 무시와 완료 오인은 지적했다. 아래 근거는 별도 표기가 없으면 docs/ux/mockups/ 기준이며 실제 서버 구현의 결함을 단정하지 않는다. 다른 검토자 결과는 참조하지 않았다.

## 3. 꼭 필요한데 없는 화면/기능

‘없음’은 현재 목업에 화면 또는 끝까지 수행 가능한 흐름이 없다는 뜻이며 서버 기능 미구현을 단정하지 않는다. 기준 문서에서 후속으로 미룬 코드값 전용 관리·버전 이력도 도입 시 필요한 업무로 구분해 적었다.

- **마이페이지 — 없음**
  - 이름·소속·메일·프로필, 보유 역할과 권한, 담당 시스템·영역.
  - 내 신청/반려 보완/후보 요청·최근 작업, 개인 알림 설정.
  - 비밀번호 변경 또는 기관 인증 안내, 활성 세션·다른 세션 종료.
- **알림 센터 — 없음**
  - 결재 요청·결과·참조·후보·표준 재검토·검증 완료, 읽음/미읽음·전체 읽음.
  - 대상 문서/속성 직접 이동·없어진 대상 안내·장기 작업 재진입·메일 실패 구분.
- **제품 정보(About) — 없음**
  - 제품 버전·빌드 ID/날짜·배포 환경, 릴리스 노트·알려진 제한.
  - 라이선스·오픈소스 고지·지원 연락처. 모델 버전과 명확히 구분.
- **도움말·단축키·온보딩 — 없음**
  - 역할별 첫 작업, 표준/조합/후보/예외/비대상 설명, 승인 단계·겸임 처리.
  - 검색 가능한 단축키 표·엑셀/DDL 예제·오류 해결·현재 화면 도움말/문의.
- **로그인·로그아웃·세션 만료 — 없음**
  - 기관 인증/로그인 실패·잠금·복구, 사용자 메뉴 로그아웃, 만료 예고·재인증.
  - 만료 시 미저장/미전송 작업 보관과 원래 화면 복귀.
- **권한 없음·404·일반 장애 — 없음**
  - 접근 범위·권한 요청 방법, 삭제/이동된 문서, 원인·재시도·홈으로 이동.
  - 결재/파일 생성·재검사 실패·권한 변경 시 안전한 복구.
- **감사 로그 — 없음**
  - 자기 승인·결재·권한·정책·백업/복원 등 통합 검색.
  - 대상/행위자/전후 값/사유/시각/신청번호, 조회 권한과 내보내기.
- **전역 검색/명령 팔레트 — 동작 없음**
  - 사전·엔터티·속성·결재 결과, 시스템·버전·담당 범위·권한 구분.
  - Ctrl+K·키보드 탐색, 0건/실패 안내, 결과의 정확한 위치로 이동.
- **백업/복원·원본 내보내기 — 없음**
  - 사전·모델·정책 범위와 기준 버전, 백업 시각·결과·보관 상태.
  - 복원 영향/충돌 미리보기·실행 권한·처리 이력. 산출물 출력과 구분.
- **시스템 상태/작업 관리 — 없음**
  - 서버 연결·최종 저장·미전송 수·검증/출력 작업 큐·메일 실패.
  - 작업 재진입·취소·재시도·오류 상세, 관리자/일반 사용자 조회 범위.
- **최종 승인·확정본/다음 작업본 — 완료 흐름 없음**
  - 승인 전 현재 기준 검사, 확정본 비교와 예외·비대상·보안 사유 검토.
  - 최종 반영·회수/반려 후 편집 복귀, 확정본 열람·다음 작업본 시작.
- **코드값·엔터티 용어 전용 편집 — 없음**
  - 코드그룹·값·의미·유효기간/미사용·중복 검증·결재.
  - 엔터티 분류어·물리명 접미·도메인 비적용, 단건/엑셀 신청 연결.

## 4. 우선순위 Top 10

1. **CX-20 기존 속성 Esc 복원** — 취소가 삭제로 이어지는 직접 손실 경로를 먼저 막아야 한다.
2. **CX-23 필터와 일괄 변경 범위 일치** — 검토하지 않은 항목까지 변경되는 사고를 막는다.
3. **CX-18·21 표준 적용/준수율/확정 조건 정합성** — 근거 없는 100%는 승인·물리·DDL 판단을 모두 무효화한다.
4. **CX-10·11 결재 대상과 필수 사유 일치** — 겸임자의 잘못된 문서 승인과 근거 없는 처리를 막는다.
5. **CX-12·13·31 결재/확정 전 과정 연결** — 최종 반영·회수·보완·다음 작업본까지 업무를 종료할 수 있게 한다.
6. **CX-22 논리/물리 변경 경계** — 반영 전이라고 믿은 구조가 바뀌는 상황을 막고 안전한 DDL 기반을 만든다.
7. **CX-25·26·27 ERD 구조 편집 완결성** — 키·관계·FK를 정확히 생성·수정·삭제할 수 있어야 데스크톱 모델러를 대체한다.
8. **CX-01~07·14~17 사전/엑셀/후보 입력-결과 연결** — 표준 검색·신청이 막히면 모델 설계도 진행되지 않는다.
9. **CX-29·47 세션/연결 단절과 복구** — 공동 편집의 저장 약속을 검증하고 작업 손실을 방지한다.
10. **CX-33·34·39~42 실제 결과물과 기본 접근성** — 산출물을 전달하고 키보드·보조기기로 핵심 업무를 수행할 수 있어야 한다.
