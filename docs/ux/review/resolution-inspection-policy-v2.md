## 합의된 권한(Q1)

Codex(목표 B, 지금 A + 제안)와 UX(A + 제안, B는 모델 검증에만 · 좁히기만)가 같은 방향 → **지금은 A + 모델러 변경 제안**, **다음 차수에 B를 "모델 이름 규칙만 · 시스템별로 좁히기만 · 출처 배지"로 제한** 도입. C는 둘 다 반대 → 기각.

## 갈린 곳 — 사용자 결정 필요

**Q2. "검사 안 함"으로 둔 규칙을 준수율에서 어떻게 셀까**
- Codex: 그 규칙은 준수율의 분자 · 분모에서 모두 뺀다(검사하지 않은 것을 통과로 세면 부풀려짐).
- UX: 분모에 남긴다(항목 수는 그대로, 해당 규칙만 판정 생략 → 꺼도 준수율이 갑자기 튀지 않음).
- Claude 의견: 준수율은 **항목(속성) 단위**라 항목은 분모에 남고, 꺼진 규칙은 그 항목의 판정에서만 빠지는 것이 두 의견이 실제로 겹치는 지점이다. 즉 "항목은 분모 유지 · 꺼진 규칙은 통과/위반 어느 쪽에도 넣지 않음" + 준수율 옆에 "검사 안 함 규칙 n개" 표시. 사용자 확인 후 확정.
