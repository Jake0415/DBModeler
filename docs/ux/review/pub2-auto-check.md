# 퍼블리싱 정합성 점검 2차 — 자동 측정 결과 (2026-11-25)

> 대상: 목업 화면 28개 중 업무 화면 25개(index · styleguide · erd 연결 파일 제외 측정 포함). 기준: [01 디자인 가이드 v2](../01-design-guide.md), [17 퍼블리싱 점검](../17-publishing-audit.md), [24 설정형 화면 가이드](../24-settings-layout-guide.md).

## 1. NeoAudit (1920 · 1600, 25개 화면 × 2)
- 12px 미만 글자 0 · 굵기 700 0 · 이름 없는 버튼 0 · 아이콘 대신 문자 0 · 가로 넘침 0 — 모든 화면.
- 버튼 높이: 28 · 32(업무 화면), 40(로그인) — 가이드 3종 안.
- 이름 없는 입력: **rules(검수 기준) 1**.
- 주 버튼(잉크) 0개 화면: 홈 · 엑셀로 가져오기(단계형) · 검수 기준 · 공통표준 · 감사 로그 · 설정 — 조회형 · 설정형이라 정상인지 확인 필요.
- HTML에 쓴 인라인 스타일(소스): 모델 33 · 견본 15 · 결재함 11 · 엑셀 가져오기 10 · 엑셀로 가져오기 8 · 설정 7 · 홈 6.
- **측정 대상에 데이터 타입 화면(datatypes)이 빠져 있다**.

## 2. 화면 구조 (1920, 23개 화면)
- 페이지 헤더 56px — 모든 화면 같음. 인라인 색(#hex · rgb) 0.
- 경로(crumbs): 모델 계열(모델 · 표준 맞추기 · 용어 자동분석 · DDL · 산출물 · 가져오기 · 엑셀로 가져오기)만 있음 — D4와 같음.
- 우측 패널: 380(모델 · DDL · 산출물 · 후보 큐), 결재함 사전 문서 680/760(넓은 패널 예외).
- 탭 종류: `.tabs`(사전 · 설정 · 마이페이지 등) · `.seg`(모델 보기 · 가져오기 · 결재함 상자) · 혼합(사전 통합 검색 · 직접 등록 · 결재함).
- 제목: `<title>`과 h1이 다른 곳 — 엑셀로 가져오기(제목 ‘엑셀로 가져오기’ · h1 ‘가져오기’), 표준 사전(‘표준 사전 통합 검색’ · ‘표준 사전’, 메뉴는 ‘통합 검색’), DDL 가져오기(‘가져오기’, 메뉴 · 경로는?).

## 3. 문구 · 용어 (HTML + app.js 문자열 검사)
| 기준어 | 섞인 표기 | 위치 |
|---|---|---|
| 도메인 그룹 | 도메인그룹 | 사전 신청 · 도메인 그룹 화면 라벨 · 엑셀 가져오기 · 검수 기준 · 설정 · 권한표 이름(app.js) — 메뉴 · 화면 제목은 ‘도메인 그룹’ |
| (토스트 되돌림 버튼) | ‘실행 취소’ 7곳 · ‘되돌리기’ 1곳(결재함) | 도구 막대 툴팁은 ‘내 편집 되돌리기 (Ctrl+Z)’ |
| 내려받기 | ‘다운로드 시연(목업)’ | 산출물 · 업로드 이력 |
| 변경 내역 | ‘사전변경내역_’ 파일명 | 변경 내역 내보내기 파일명 |
- 말투: 모두 합니다체(‘~하세요’는 공손한 지시). 해요체 없음.
- 디자인 가이드에 **문구 · 용어 기준 절이 없다** — 화면마다 기준어가 문서(02 · 15 · 25 ~ 29)에 흩어져 있다.
