## 1. 총평

- 결재·모델 확정·엑셀 왕복의 **쓰기 경로**(T5·T7·T8)는 끝까지 닫힙니다. v7까지 고친 낡은 탭 차단·스냅숏 격리·보완 재신청도 유지됩니다.
- 끊기는 곳은 **고정 HTML로 남은 화면**입니다. 표준 맞추기 분석 표, 후보 큐, 감사 로그, 사전 분석 결과, DDL·산출물, 게이트 A가 상태 계층을 읽지 않아서 **재진입하면 이전 상태가 다시 보입니다**. 그래서 T2·T3·T4가 실패합니다.
- **판정 기준이 화면마다 다릅니다**(상 3건): 결재 검사는 도메인 존재를 보지 않는데 엑셀 검증은 같은 값을 오류로 막습니다. 엑셀은 승인되지 않은 단어 '검수'로 만든 용어를 '신규'로 신청합니다. 모델 확정은 연결 용어 신청이 아직 진행 중이어도 승인됩니다.
- 시나리오 시작점이 없습니다(T1 '빈 사전' 상태, T2 '후보 등록'). 그리고 `?as=` 역할이 화면을 옮기면 풀려서 검증 도구 자체를 믿기 어렵습니다.
- 발견 45건(상 12 · 중 33). 시나리오는 통과 3 · 조건부 통과 2 · 부분 통과 1 · 실패 3입니다. TODO 31건은 이번 차수 23건 · 구현 설계 8건으로 판정했습니다.
