# v7 클릭 목업 확인 검토

**동결 불가.** 대표 경로 4개 중 사전 변경·보완 경로만 통과했다.
결재함에서 연 확정본은 다음 버전을 시작할 수 없고, 엑셀은 현재 사전과 값이 달라도 왕복 완료를 기록한다. 오래 열린 탭은 다른 탭의 보정값을 덮거나 이전 모델을 제출할 수 있다.
HTML 이벤트와 상태 전이를 추적하고, Node VM에서 원본 핸들러·공통 함수를 메모리 저장소와 최소 DOM으로 재현했다. 실제 브라우저 클릭·드래그·포커스는 확인하지 않았다.
