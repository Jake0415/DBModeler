# 클릭 목업 v5 독립 UX 검증 · Codex r7

## 1. 총평

- **v4 Top 10 닫힘 0/10 · 07 Top 10 닫힘 0/10.** 두 Top 10은 각각 10건 모두 부분이다. 묶음 요건은 입력부터 결재·반영·재진입까지 결과가 이어질 때 닫힘으로 판정했다.
- CX-13·CX-31·CL-29의 대표 회귀와 CX4-02의 중복 삭제는 닫혔다. CX4-01은 대상 고정이 됐고 실행 권한과 초점 복귀가 남았다.
- 문서·업로드 번호는 연결됐지만 제출 행, 모델 버전, 사전 항목 값은 결재 상세와 승인 이후 화면에서 어긋난다.
- 코드의 상태 전이와 화면 표시를 대조했다. 1600은 레이아웃 규칙과 재진입 로직을 검토했으며 브라우저 실측은 포함하지 않았다.

근거 경로는 `docs/ux/mockups/` 기준이다. 닫힘은 해당 경로 충족, 부분은 동작과 잔여 결함이 함께 있음, 열림은 요구 동작이 실행 경로에 없음, 회귀는 이전 동작이 변경으로 깨짐을 뜻한다. 대표 ID는 원래 결함 범위로 판정했다.

## 5. 다음 차수 우선순위 Top 10

1. **문서별 제출 내용을 고정한다.** 행·필드·사유·집계·결재선을 보존하고 재신청이 옛 문서를 바꾸지 않게 한다. CX7-06·09·11·16.
2. **모델 구조를 영역·버전별로 보존한다.** 결재의 스냅숏과 리스크 확정본을 정확히 열고 다음 작업본으로 구조를 이어 준다. CX7-01·02.
3. **권한·최신 상태를 실행 직전에 검증한다.** 결재 참조·딥링크, 업로드 재개, 표준 맞추기, 오래 열린 편집 탭에 적용한다. CX7-03·05·07.
4. **기준본과 실제 입력으로 왕복을 판정한다.** 행 ID·범위·자료형·빈 칸·V0와 칸 단위 병합을 제출 시 다시 검사한다. CX7-08·14, B Top 1~3.
5. **항목별 사전 반영과 공표를 연결한다.** 승인 결과가 Vn에, 확인한 공표 대상만 항목 제정차수에 반영되게 한다. CX7-17·18.
6. **표준 맞추기·준수율·확정 검사를 같은 모델에서 실행한다.** 보이는 행의 처리와 사유를 반영하고 문서 버전의 이름·도메인을 다시 검사한다. CX7-04·23.
7. **반영본과 남은 작업을 이어 준다.** 승인 행은 재업로드 시 동일로 판정하고, 대기·반려·회수 행만 보완하며, 알림은 해당 반영본으로 연다. CX7-09·15·22.
8. **신청·보정 안전장치를 연결한다.** 0건·미사용·후보·대량 자기 승인 조건을 검사하고 보정 범위와 F8·취소를 맞춘다. CX7-10~13.
9. **후보·감사·알림의 대상과 처리 사건을 맞춘다.** 후보 상태·신청번호를 보존하고 묶음별 사용처 알림과 정확한 결재선을 표시한다. CX7-19·22·24.
10. **1600과 키보드로 핵심 왕복을 확인한다.** 엑셀 행 선택부터 결재 완료까지 초점을 이어 주고 모델 재진입에서 패널 설정을 복원한다. CX7-20·21.
