## 이번에 바꾼 것(P3, 커밋 1ddbc36)
- **마이페이지 배치**: 920 상자를 없애고 한 줄을 라벨 240 │ 입력 ≤760 │ 보조 칸으로 나눔.
  - 프로필 = 계정 · 역할 두 묶음. [역할 변경 요청] 버튼은 보조 칸에 둠.
  - 알림 설정 표와 세션 표는 넓은 행(최대 1200)으로 둠.
- **저장 막대**: 프로필 · 알림 설정 · 환경 탭 안에 있던 [저장] 3개를 하단 막대 하나로 합침.
  - 바뀐 탭에 점이 붙고, 막대에 바뀐 건수가 나옴. [변경 보기] · [되돌리기] · [저장]이 있음.
  - 형식이 틀린 탭은 저장하지 않고 그 탭을 엶. 앞서 저장된 탭만 기준값을 갱신함.
- **바로 적용 동작 구분**: 테마 · 표 밀도 · 단축키 · 비밀번호 변경 · 세션 로그아웃은 저장 막대와 별개. 보조 칸에 ‘바로 적용’이라고 적음.
- **화면 안내**: 마이페이지에 탭별 화면 안내를 추가함. 버튼은 탭 줄 오른쪽 끝.
- **공통 CSS 이동**: 설정 화면 스타일에 있던 공통 규칙을 app.css로 옮김.

## 검토 요청
1. 마이페이지와 설정이 **같은 규칙으로 보이고 동작하는지** 확인하라. 다른 점이 있으면 화면 · 줄 · 근거를 적어라.
   - 볼 것: 행 폭, 소제목, 보조 칸 내용의 종류, 저장 막대 문구, 화면 안내 위치.
2. 저장 막대의 동작에서 결함이나 혼란을 찾아라.
   - 부분 실패, 되돌리기, 탭 이동, 나갈 때 확인
   - 바로 적용 동작과 막대 저장이 섞여 생기는 오해
   - 키보드 · 화면 낭독기 접근성
3. 보조 칸 문구가 **짧고 같은 말투**인지, 필요한 정보가 빠지거나 넘치지 않는지 검토하라.
4. 1920 · 1600에서 **빈 공간 · 시선 이동 · 정렬** 문제를 찾아라.
   - 예: 알림 설정 표가 좁아 보임, 내 신청 · 내 작업 탭이 행 3칸 규칙 밖에 있음.
5. 공통 CSS 이동 뒤 **다른 화면에 의도치 않은 영향**이 있는지 확인하라. `.set-row` · `.setbar` · `.tdot`를 쓰는 다른 파일이 있는지도 본다.
6. 개선점은 **번호 · 심각도(높음/중간/낮음) · 근거(파일:줄 또는 관찰) · 제안**으로, 우선순위 순서대로 적어라. 고칠 필요가 없는 것은 ‘유지’로 적어라.
