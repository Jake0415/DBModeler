# 표준 사전 화면 기능 점검표 (func-check-dict)

- 점검일: 2026-11-20 · 대상: `docs/ux/mockups` 사전 화면 8종 (공통표준 16,662건 적재 상태)
- 방법: 내장 브라우저로 실제 클릭·키보드 입력(1920×1080, 1600×900), 역할 `&audit=1&as=<역할>` — kim(모델러+DA) · park(모델러) · lee(DA+관리자) · hyun(기관 담당자) · choi(기관 담당자+모델러)
- 매 조작 뒤 `window.__errs` · 콘솔 오류 확인 — 점검 끝까지 JS 오류 0건
- 확인 결과: **정상** = 손대지 않아도 맞게 동작 · **수정함** = 결함을 고친 뒤 다시 확인 · **남김** = 공용 파일(app.js/app.css) 또는 정책 판단이 필요해 남김

## 끝-끝 흐름 (실제 통과)

| 흐름 | 조작 | 결과 |
|---|---|---|
