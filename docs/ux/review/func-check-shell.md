# 기능 점검 — 공용 영역 (상단 바 · 모델 트리 · 공용 기능)

- 일자: 2026-11-20
- 대상: `assets/app.js` · `assets/app.css`가 그리는 모든 화면 공통 부분
- 방법: 브라우저에서 1600×900으로 직접 클릭했습니다. 트리 항목 전체와 메뉴 명령은 자동 클릭 스크립트로 눌렀습니다. 클릭할 때마다 화면 오류 수집(`__errs`)과 콘솔을 확인했습니다.

## 3. 발견한 결함과 수정

1. **트리 항목을 한 번 눌러도 화면이 바뀜**(보고: 부서명 · 부서코드)
   - 증상: 홈 · 시스템 홈 · 표준 맞추기 · DDL에서 그 화면이 보여 줄 수 없는 항목(속성 · 엔터티 · 용어 등)을 한 번만 눌러도 모델 화면이나 사전으로 넘어갔습니다.
   - 수정: 한 번 누르면 선택만 하고, 처음 한 번 "두 번 누르거나 Enter를 누르면 모델 화면에서 엽니다"라고 안내합니다. 두 번 누르기, Enter, 메뉴 [선택]일 때 이동합니다.
2. **트리에서 열고 오면 트리가 접히고 사전 탭이 열림**
   - 증상: 1920보다 좁은 화면에서 모델 화면에 도착하면 트리가 기본으로 접혔습니다. 직전에 사전 탭을 썼으면 사전 탭이 열렸습니다.
   - 수정: 트리에서 이동할 때 `&tree=1`을 붙입니다. 이때는 트리를 펼친 채 모델 탭에서 해당 항목(예: 부서명)을 선택해 보여 줍니다.
3. **편집 중 상태가 저장되어 속성 메뉴가 열리지 않음**
   - 증상: 모델 화면에서 이름 바꾸기나 속성 추가를 시작한 채 화면을 떠나면 '편집 중' 표시와 이름 없는 빈 속성이 저장됐습니다. 그러면 다른 화면의 트리에서 그 속성(부서코드 · 부서명)을 오른쪽 클릭해도 메뉴가 열리지 않았습니다.
   - 수정: 모델을 읽을 때 정리합니다. 편집 중 표시는 지우고, 이름 없는 새 속성과 이름을 못 받은 새 엔터티는 버립니다(`tidyModel`).
4. **거르기 창의 분류 칩이 한 글자씩 세로로 꺾임**
   - 원인: 창 폭이 약 150px라 칩 다섯 개가 34px로 눌렸습니다.
   - 수정: 창 최소 폭을 280px로 넓히고 칩 글자가 줄바꿈되지 않게 했습니다.
5. **전체 검색에서 정확히 일치하는 항목이 밀림**
   - 증상: 공통표준 16,662건이 들어온 뒤 '부서명'을 검색하면 '요청부서명' 같은 항목이 먼저 나오고, 정작 '부서명'은 6건 안에 들지 못했습니다.
   - 수정: 정확히 일치 → 앞부분 일치 → 포함 순으로 정렬하고, 같은 순위는 짧은 이름을 먼저 보여 줍니다.

6. **시드 품의 REQ-2026-0014가 재검사에 실패**
   - 원인: 공통표준 전체 적재 뒤, '산출물제출일자'의 약어(DLVRBL_SBMT_DATE)가 공통 단어 '제출'(SBMSN)과 맞지 않게 됐고, 새로 신청한 단어 '검수'가 공통표준에 이미 있었습니다. 그래서 목차 T7 '자기 승인' 흐름이 끝까지 가지 못했습니다.
   - 수정: 약어를 DLVRBL_SBMSN_YMD로 고치고, 새 단어를 공통표준에 없는 업무 단어 '품질검토'(QLTRVW)로 바꿨습니다. 이미 저장된 진행 중 문서도 읽을 때 같은 값으로 고칩니다.
   - 0012 '수령자'는 이제 공통표준과 같은 이름이라 검사에서 "같은 이름의 단어가 이미 있음(공통)"으로 걸립니다. DA가 반려하는 예시로 둡니다.
7. **처리 시각과 홈 날짜가 어긋남**
   - 증상: 홈은 목업 기준일 11/19(목)을 쓰는데, 결재 처리 시각과 사전 변경일은 실제 날짜를 썼습니다.
   - 수정: 둘 다 목업 기준일을 씁니다.
8. **화면 목록 누락**
   - 증상: 화면 일괄 작성, 도메인 그룹 · 분류, 공통표준 · 행정표준코드, 용어 자동분석이 화면 목록(SCREENS)에 없었습니다. 그래서 [화면 정보]에 "목록에 없음"으로 나왔습니다.
   - 수정: 네 화면을 목록에 넣었습니다.
9. **검토 모드 역할 유지**
   - 증상: 링크(`<a>`)가 아닌 스크립트 이동(트리 두 번 누르기, 메뉴 명령)에서는 `&audit=1&as=`가 빠졌습니다.
   - 수정: 공용 `navKeep(url)` · `keepUrl(url)`을 두고 트리 이동에 적용했습니다.
10. **기타**
    - 트리의 'DDL 가져오기'는 지금 업무 영역을 넘깁니다(`import.html?area=`).
    - 시연용 `href="#"` 링크를 눌러도 페이지 맨 위로 튀지 않습니다.
    - 오류 문구 "같은 이름의 단어이"의 조사를 고쳤습니다.

## 4. 점검 중 생긴 부작용과 복구

- 상단 바 버튼을 일괄로 누르는 점검에서 테마(어두운 모드), 화면 크기(1600 고정), 화면 정보 열림 설정이 저장됐습니다. `dbm-theme` · `dbm-frame` · `dbm-frame-v2` · `dbm-scr-open`을 지워 원래 상태로 되돌렸습니다.
