# 종합 — 엑셀로 ERD 시작하기(26) 목업 리뷰

> 리뷰: Codex [codex-excel-import](codex-excel-import.md)(XE-01 ~ 14) · UX [claude-excel-import](claude-excel-import.md)(UX-01 ~ 19). 요청은 [brief-excel-import](brief-excel-import.md).
> 상태: **Z-01 ~ Z-15 적용 완료**(2026-11-24) — 기록은 [26 §7](../26-erd-excel-import.md).

## 결론
결정 다섯 가지(병합 기본 · 참조 오류 막기 · 관계명은 ERD에서 · 다른 영역 참조는 미리보기에서 선택 · ‘필수’)는 두 리뷰 모두 유지로 봤다. 고칠 것은 넷이다.
1. **위치를 검사보다 뒤에 고르는 구조** 때문에 같은 영역 테이블이 참조 엔터티로 하나 더 생겼다.
2. **덮어쓰기 · 병합에서 기존 FK와 관계가 꼬였다.**
3. **다른 영역 참조 선택이 숨어 있고, 고른 값이 유지되지 않았다.**
4. **저장 · 취소 확인과 검사 결과 엑셀의 행 위치가 부정확했다.**

## 합의된 수정
| # | 심각도 | 수정 | 근거 |
|---|---|---|---|
| Z-01 | 높음 | **단계 순서 바꾸기**: ① 파일 → ② 가져올 위치(새 영역 · 기존 영역 병합/덮어쓰기) → ③ 검사 · 미리보기 → ④ 완료.<br>· 검사는 최종 대상 기준으로 한다. 대상 영역의 테이블은 ‘대상 영역’으로 잇고, 참조 엔터티로 만들지 않는다.<br>· 위치 · 방식 · 충돌 선택을 바꾸면 다시 검사한다. | XE-01, UX-01 |
| Z-02 | 높음 | **덮어쓰기 계획 = 실제 결과**<br>· 빠지는 테이블, 남는 테이블에서 빠지는 컬럼, 지워지는 관계를 모두 보여 준다.<br>· 기존 관계는 지우고 엑셀의 참조로 다시 만든다(관계선만 남는 일 없음).<br>· 두 번째 확인은 같은 계획일 때만 받는다. | XE-02, UX-02 |
| Z-03 | 높음 | **병합 관계 중복 · 충돌**<br>· 같은 부모 · 자식 · FK 짝 전체(대소문자 무시)면 ‘이미 있음’으로 건너뛴다.<br>· 엑셀의 FK 컬럼이 이미 다른 관계의 FK면 ‘충돌’로 보이고 만들지 않는다.<br>· 병합 미리보기에 관계 ‘새로 · 이미 있음 · 충돌’ 건수를 보여 준다. | XE-03, UX-04 |
| Z-04 | 높음 | **저장 · 취소 안전**<br>· 새 영역은 등록과 구조 저장을 모두 확인한 뒤 완료로 넘어간다. 실패하면 정리하고 알린다.<br>· [가져오기 취소]는 두 번 눌러 확인하고, 가져온 직후 상태(같은 버전 · 저장 수)일 때만 된다. 다른 편집이 있었으면 막고 이유를 보인다. | XE-04, UX-08 |
| Z-05 | 높음 | **예전 양식 이어받기**<br>· 시트가 바뀌면 이어받기를 새로 시작한다.<br>· 예전 양식은 표준용어 · 원천 열로만 판정한다.<br>· 새 양식의 논리명 · 설명은 빈 값까지 원문으로 비교한다. | XE-05 |
| Z-06 | 높음 | **다른 영역 참조**<br>· 확정본에서 찾는다.<br>· 참조 사본에 부모 PK 전체를 담는다.<br>· 고른 값은 다시 검사해도 유지하고, 끄면 문제 탭 경고와 요약이 바로 바뀐다.<br>· 다른 영역 참조가 있으면 미리보기를 **관계 탭으로 열고**, 요약에 ‘다른 영역 참조 n — 고르세요’를 보인다. | XE-06, UX-03 |
| Z-07 | 높음 | **참조 키**: 부모 복합 PK는 **전부** 참조해야 한다. 일부만 참조하면 **오류**(빠진 키 표시)로 막는다. 타입 계열 검사는 그대로 둔다. | XE-07 |
| Z-08 | 중간 | **관계 결과**<br>· 재귀 관계는 자식 컬럼 논리명이 ‘상위’로 시작하면 역할명 ‘상위’를 넣는다(그 밖에는 ERD에서 입력).<br>· 같은 두 테이블 사이 두 번째 관계는 ‘두 번째 관계 — 역할명은 ERD에서’로 표시한다.<br>· 완료 · 감사에는 실제로 만든 관계 수를 쓴다. | XE-08 · 12, UX-12 · 04 |
| Z-09 | 중간 | **파일 읽기**<br>· 읽는 중 표시를 한다. 읽기 실패와 늦게 끝난 읽기를 처리한다.<br>· 파일 오류는 1단계 화면 안 띠로 보여 준다(토스트만 쓰지 않음). | XE-09, UX-13 |
| Z-10 | 중간 | **검사 결과 엑셀**<br>· 원본 시트 · 행 · 열을 그대로 두고, 맨 끝에 ‘검사 결과’ 열을 더한다(빈 행 · 예전 양식 열 유지).<br>· ‘검사 요약’ 시트는 다시 올릴 때 건너뛴다.<br>· 문제 표의 행을 누르면 그 행의 값이 보인다. | XE-10, UX-06 · 07 |
| Z-11 | 중간 | **Y 값 읽기**<br>· PK · 필수 칸은 Y · 예 · O · 1을 ‘예’로 읽고, N · 아니오 · X · 0 · 빈칸을 ‘아님’으로 읽는다.<br>· 그 밖의 값은 경고한다.<br>· 테이블 이름도 예약어 · 길이를 검사한다. | XE-11, UX-07 |
| Z-12 | 중간 | **충돌 선택**<br>· 기본은 ‘엑셀 값’이다. [모두 엑셀 값] · [모두 지금 값]을 둔다.<br>· 논리명이 다르면 충돌 목록에 넣는다.<br>· 병합으로 바꾼 속성의 표준 판정을 다시 계산한다. | UX-05, XE-12 |
| Z-13 | 중간 | **배치 · 보기**<br>· 새 엔터티는 기존 엔터티 아래에 놓는다.<br>· ‘가져온 테이블 (파일명)’ 보기를 만든다. | XE-12 |
| Z-14 | 중간 | **권한 · 진입**<br>· 권한이 없으면 [가져오기]를 끄고 이유를 보인다.<br>· 출발 영역이 잠겨 있으면 그 이유를 2단계 위에 계속 보인다.<br>· 시스템 홈 새 영역 창의 이름을 넘긴다. | XE-13 |
| Z-15 | 중간 | **접근성**<br>· 탭은 `role=tab` · `aria-selected` · 방향키로 움직인다.<br>· 관계 체크박스 이름에 부모 → 자식을 넣는다.<br>· 단계를 바꾸면 그 단계 제목으로 포커스를 옮긴다.<br>· 3단계 오류를 입력란에 연결한다.<br>· 방식을 바꾸면 덮어쓰기 경고를 지운다. | XE-14, UX-09 · 10 · 11 |

## 하지 않는 것 (기록)
- **명명 템플릿 위반 경고**(XE-11 일부): 명명 템플릿 검사는 표준 맞추기에서 한다.
- **UNIQUE 참조**: 양식에 UK 열이 없으므로 PK 참조만 받는다. 1:1(UK)은 ERD 관계 패널에서 바꾼다.
- **같은 이름의 테이블이 여러 영역에 있을 때 영역 고르기**: 확정본이 있는 첫 영역을 쓰고, 미리보기에 영역 이름을 보인다. 고르기는 구현 단계에서 한다.
