## 총평

T1 범위가 대부분 들어갔다.
- 트리 구조: 영역 › 바로가기 줄 / 보기 / 엔터티·관계·서브타입(물리는 테이블·관계(FK)·제약조건·인덱스) / 사용한 표준 › 객체 › 속성
- 논리/물리와 열린 버전 따라가기(`treeData`, 펼침 키 `area@ver`)
- 캔버스 → 트리 선택 표시(포커스는 옮기지 않음)
- 찾기(2글자 이하는 앞부분 일치)와 결과 수 낭독, 거르기 줄
- roving tabindex와 ↑↓←→ Home End `*` 글자 이동
- [모델 | 사전] 한 칸, 내용 맞춤 폭과 760px 상한, 손잡이(두 번 누르면 맞춤)
- 트리 → DDL·표준 맞추기·산출물 이동

FK 판정도 `fkOf` 하나로 트리·오른쪽 패널·DDL이 함께 쓴다. 전역 키 충돌은 두 겹(`stopPropagation` + `.mtree` 가드)으로 막았다.

남은 것은 다섯 가지다.
- 트리에서 속성·관계를 고르면 **선택이 엔터티 줄로 바뀌어** 버린다.
- 자기 참조 관계의 FK 상태가 화면마다 다르다.
- 홈·DDL에서 **영역의 모델을 여는 길**이 없다.
- 거르기 메뉴가 한 번 누를 때마다 닫힌다.
- DDL·산출물에서 트리가 그 화면의 버전을 따르지 않는다.
