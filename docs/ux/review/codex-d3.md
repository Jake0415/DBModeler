## 3. 사용자 확인에 올려도 되는가

**아니오.** 가져오기 오류가 빈 목록처럼 표시되고 실제 0건 목록에는 빈 상태가 빠지며, 결재함의 긴 목록에서 고정 머리줄이 유지되지 않는다.
