# D8 검토: Claude (NeoDB 셸 재설계: 상단 메뉴·모델 트리·BI)

> 기준: [11-navigation-brand-plan.md](../11-navigation-brand-plan.md). 사용자 선택: BI A(연결된 N) / 상단 메뉴 화면은 트리 숨김·전체 폭 / 관리는 드롭다운 하나 / 홈은 트리 보임
> 대상: 작업 트리 diff(`app.js` buildShell·drawTree·MARK·목업 버튼, `app.css` v17, 각 화면 title, `model.html` showRP, `system.html` #new)
> 방법: 코드만 읽고 판단했다(브라우저 미사용). 줄 번호는 지금 작업 사본 기준이다.

## 총평

계획의 뼈대는 그대로 들어갔다.
- 로고(MARK 20px + NeoDB 15/600, `aria-label="NeoDB 홈"`), 기관명 구분선
- 상단 메뉴: 모델 / 사전 ▾ / 결재함 건수와 기한 넘김 점 / 관리 ▾
- 검색은 오른쪽으로 옮겼다.
- 트리: 시스템 선택, 찾기, 지금 연 영역 펼침과 하위 4링크, 시스템 도구, 최근 연 엔터티, 56px 접기와 접힘 기억
- 상단 메뉴 화면은 `notree`로 전체 폭이다. 홈은 트리를 보인다.
- 화면 HTML에 남은 `DBModeler`는 0건이다.

`data-page` 매핑도 맞다. ddl·import·outputs·standardize는 `model`, uploads는 `excel`, dict-history는 `dictionary`로 잡혀 있어 활성 탭과 트리 표시가 모두 맞다.

남은 문제는 세 가지다.
- 목업 버튼이 엑셀 가져오기의 `이전` 버튼을 가린다.
- 드롭다운이 Tab으로 빠져나가도 닫히지 않는다.
- 1600px 모델 화면이 세 칸(트리·사전 패널·오른쪽 패널)으로 좁아진다.

## 확인했고 문제 없음
- 활성 탭 매핑: `system/model`(ddl·import·outputs·standardize 포함) → 모델, `dictionary/excel/candidates`(dict-history·uploads 포함) → 사전, `approvals` → 결재함, `settings/audit` → 관리. mypage·error는 탭 없음.
- 역할별 관리: Admin은 설정+감사 로그, DA는 감사 로그, 모델러·기관 담당자는 관리 메뉴 없음(계획과 같음).
- 트리 찾기: 영역 이름 또는 엔터티 논리·물리명으로 거르고, 결과가 없으면 빈 줄 안내, Esc로 지운다(전역 Esc로 번지지 않음). 펼침 상태는 `dbm-tree-open`에 기억하고, 다시 그린 뒤 포커스를 되돌린다.
- 1600px 상단 바: 로고·기관명·메뉴 4개·검색 260·알림·사용자를 합쳐 약 1000px라 넘치지 않는다.
- 글리프: 셸에 `▾`·`→`·기호가 없다(전부 `data-ic` 아이콘). 트리 영역 줄은 상태 표시가 하나(`v5` 글자 또는 `검토`/`확정` 배지)다.
- 접기: `aria-expanded`와 레이블이 상태에 따라 바뀌고, 접힘을 기억하며, resize 이벤트로 캔버스가 다시 맞춰진다.

사용자 확인에 올려도 되는가: 예. 다만 1번(엑셀 가져오기 `이전` 버튼이 가려짐)은 고친 뒤 올리기를 권합니다.
