## 가장 먼저 할 5가지

1. **D5-01 머리줄 구조 통일**: 경로 줄 / 제목 + 상태 / 주 행동 1 + ⋯. 모든 화면의 첫인상과 1600px 넘침을 한 번에 해결한다.
2. **D5-03 결재 연속 처리**: 다음 문서 자동 열기, 되돌리기, 단축키. 핵심 업무의 체감 속도가 가장 크게 오른다.
3. **D5-04 사전 도구 줄 정리**: 검색 + 종류 + 필터 팝오버, 패널은 선택할 때만. 가장 자주 쓰는 화면의 첫 화면 정보량을 늘린다.
4. **D5-02 모델 배너 한 자리 + 우선순위**: 캔버스를 지키고 중요한 경고를 드러낸다.
5. **D5-06·D5-07 상태 세트(로딩·저장·빈 상태 3종)를 견본에 추가**: 실제 제품으로 옮길 때 빠지기 쉬운 피드백을 지금 정해 둔다.
