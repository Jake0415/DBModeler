## 0. 결론
- **배치는 가이드대로 맞다.**
  - 1920 오른쪽 빈 폭 16%, 1600 약 0%.
  - 행 3칸 · 소제목 · 화면 안내 자리가 두 화면에서 같다.
  - 공통 CSS를 옮긴 영향은 `.tdot` 하나뿐이다.
- **문제는 저장 동작의 세부와 접근성이다.** 높음 3건은 둘 다 같은 결론이다.
  1. 마이페이지의 부분 실패
  2. 테마 새로 고침이 미저장 값과 충돌
  3. 두 화면의 실패 처리가 다름
- **설정 화면은 목업 신뢰성 문제가 있다.** 고쳐도 저장 막대가 뜨지 않는 입력이 남아 있다.

## 1. 합의된 개선 (두 리뷰 공통 또는 실측 확인)
| # | 심각도 | 개선 | 근거 |
|---|---|---|---|
| R-01 | 높음 | **저장 실패 규칙 하나로**: 두 화면 모두 ① 바뀐 값 전부 검사 → ② 오류가 있으면 **전부 보류**, 첫 오류 탭을 열고 그 칸에 포커스, 칸 아래 사유 + `aria-invalid` · `aria-describedby`, 토스트 “저장하지 않았습니다 — 오류 n건” → ③ 영향 큰 변경 확인 창 → ④ 저장. 마이페이지의 ‘앞 탭만 저장’ 분기는 없앤다(실행될 일도 없음). 17 S-7을 이 문장으로 고친다 | SP-03 · 04, UP-01 · 03 · 06 |
| R-02 | 높음 | **테마는 새로 고침 없이 바로 적용**: 앱 상단 메뉴의 즉시 적용 경로를 써서 미저장 입력과 저장 막대를 그대로 둔다 | SP-01, UP-02 |
| R-03 | 높음 | **설정의 편집 칸 = 저장 대상**: 저장 경로가 없는 칸(기관명 · 기관 사전 이름 · DBMS · 버전/스키마 등)은 조회 전용으로 표시하고, 시연하는 칸은 변경 감지 · 변경 보기 · 되돌리기 · 저장에 모두 넣는다. 시스템을 바꾸면 남는 숨은 변경도 정리한다 | SP-02, UP-13 · 22 |
| R-04 | 중간 | **탭 점 크기 버그**: 트리용 `.tdot:not(.ok):not(.half):not(.ex)`(app.css:333, 12px)가 `.tabs .tdot`보다 명시도가 높다. 탭용 점의 클래스 이름을 따로 두고(`.tabdot`), 색 대비를 3:1 이상으로 한다 | UP-04 (코드 확인) |
| R-05 | 중간 | **낭독기 전달**: 탭에 `role="tab"` · `aria-selected`를 두고, 미저장이면 접근성 이름에 “저장하지 않은 변경 n건”을 넣는다. [변경 보기]는 펼침 영역으로 만들어 열린 동안 갱신한다. 저장 · 되돌리기 뒤에는 포커스를 활성 탭으로 돌린다. 막대 live 영역은 건수가 바뀔 때만 알린다 | SP-05, UP-05 · 07 |
| R-06 | 중간 | **저장값 = 화면값**: 공백 제거 · 이메일 소문자 같은 정규화 결과를 입력에 반영한 뒤 기준값을 갱신한다. [되돌리기] 툴팁은 ‘모든 탭의 저장하지 않은 변경’으로 한다 | SP-06, UP-18 |
| R-07 | 중간 | **‘바로 적용’ 표시를 컨트롤 옆으로**: 보조 칸 대신 컨트롤 바로 옆에 작은 태그 ‘바로 적용’. 문구는 하나로 통일하고, 세션 [로그아웃]에도 붙인다. 시작 화면도 바로 적용으로 바꿔 **환경 탭 전체를 바로 적용**으로 하고 저장 막대 대상에서 뺀다. 막대 대상은 프로필 · 알림 설정만 남는다 | SP-07, UP-08 · 09 |
| R-08 | 중간 | **짧은 컨트롤은 제 폭**: 세그먼트 · 표시 이름 · 시작 화면은 760으로 늘이지 않는다(`justify-self:start`, 입력 최대 360). 알림 표는 체크 열을 고정(앱 알림 · 메일 각 120)하고, 표 폭을 내용에 맞춘다(최대 720). 넓은 표는 표 래퍼 안에서만 가로 스크롤한다 | SP-08, UP-10 · 11 |
| R-09 | 중간 | **보조 칸 말투 통일**: 두 화면 모두 ‘-ㅂ니다’ 짧은 문장, 한 줄에 하나. 용어는 ‘관리자’로 통일(‘Admin’ 쓰지 않음). 연락처 · 알림 설정에는 적용 시점(‘저장하면 바로 적용’)을 적는다. 알림 안내는 ‘앱 알림을 끄면 알림 목록에 오지 않습니다’와 ‘메일은 결재선 담당자에게만 보냅니다’로 나눈다 | SP-07 · 09, UP-12 |
| R-10 | 중간 | **설정 검수 기준 탭을 행 3칸으로**: 표는 넓은 행에 넣고, 안내 띠 2개는 보조 칸 · 각주로 옮긴다 | UP-14 |
| R-11 | 중간 | **설정 화면 안내 문구 갱신**: ‘항목 이름 아래 마지막 변경’ → ‘오른쪽 칸에 마지막 변경’ 등 P1 배치에 맞춘다 | UP-15 |
| R-12 | 낮음 | **마이페이지 보안 소제목**: ‘인증’(인증 방식 · 비밀번호 변경) · ‘접속 기록’(세션 · 최근 로그인). 비밀번호 마지막 변경일은 보조 칸 첫 줄로 옮긴다 | SP-09 |
| R-13 | 낮음 | 막대 문구의 탭 이름을 두 화면 모두 탭 글자 그대로 쓴다(설정 ‘기관 설정’ → ‘기관’). 영향 확인 창이 열린 동안 주 버튼이 둘 보이지 않게 한다. `Ctrl+S`로 저장한다 | UP-16 · 17 · 20 |

## 2. 유지 (고치지 않음)
- 내 신청 · 내 작업은 설정의 사용자 · 역할 · 권한표처럼 **전체 폭 표 탭**으로 둔다. 행 3칸 대상이 아니다(SP 유지, UP-23은 낮음 — 두 표의 열 꼴 정리만 나중에).
- 저장 막대 기본 구성(건수 · 탭 이름 · 변경 보기 · 되돌리기 · 저장 · 저장 시각)과 화면 안내 위치.
- 나갈 때 확인은 브라우저 기본 창을 쓴다(UP-19). 앱 안 이동 확인은 구현 단계에서 한다.
- 막대가 나타날 때 본문이 56px 줄어드는 것은 허용한다(UP-21). 막대는 아래에 붙어 있고, 내용이 가려지지 않는다.
