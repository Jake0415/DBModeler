## 이번에 넣은 것

1. **자동 수정 미리보기:** 전에는 브라우저 확인창(confirm)이었습니다. 이제 대상 행 · 규칙 · 칸 · 파일 값 → 바뀔 값을 보여 주는 창에서 행마다 골라 적용합니다.
   - 규칙별로 걸러 볼 수 있습니다.
   - 적용 뒤 [실행 취소]로 그 작업만 되돌립니다.
2. **찾아 바꾸기(Ctrl+H):** 지금 표에 보이는 행만 대상으로 합니다.
   - 칸을 고를 수 있고, '칸 전체 일치'와 '대소문자 구분' 옵션이 있습니다.
   - 실행 전에 바뀔 칸 수와 행별 전후 값을 미리 보여 줍니다.
   - 바뀐 값이 규칙에 맞지 않는 칸(예: 사전에 없는 도메인)은 '건너뜀'으로 표시하고 바꾸지 않습니다.
   - 결재 대기 · 버전 충돌 · 파일에서 빠짐 행과 계산 칸(용어 약어 · 도메인명)은 바꾸지 않습니다.
   - 오류 칸이 바뀌어 규칙을 통과하면 그 행은 바로 신규/변경이 됩니다.

## 검토해 주세요

- 엑셀 왕복 편집 전체 6단계(방식·종류 → 업로드 → 열 매핑 → 검증·비교 → 결과 검토·보정 → 신청)가 실제 업무에서 막힘 없이 이어지는지
- 5단계에서 오류를 찾고 이해하고 고치는 흐름: 오류 요약 바, 칸 표시, 행 패널, 자동 수정, 찾아 바꾸기, F8, 내려받기(오류·수정 가이드 / 보정본)
- 대량(수천 행) 상황에서도 쓸 만한지, 실수(잘못 바꾸기 · 되돌리기)를 막는지
- 접근성(키보드 · 포커스 · 화면 낭독), 문구(한국어, 업무 용어), 1600 · 1920 화면 배치
