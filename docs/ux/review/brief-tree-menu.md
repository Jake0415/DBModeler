# 리뷰 요청 — 모델 트리의 업무 영역 메뉴 구조 (설명 · 바로가기 위치와 가독성)

## 사용자 피드백 (2026-11-23)
> "인사관리 밑에 설명이 있고, 모델 · 표준 맞추기 등이 있는데 다른 데는 없어. 배치가 잘못된 것 같아. 메뉴 구조를 다시 리뷰해서 위치 조정을 어떻게 할지 정리해 줘. 모델 · 표준 맞추기 같은 사용자 선택 메뉴는 가독성을 높여 사용자가 인지해야 해."

## 지금 구조 (왼쪽 칸 · 모델 트리)
```
[통합ERP · Oracle 19c · ERP ▾] [‹ 접기]
[찾기 ……………………] [거르기 ▾]
업무 영역                          (?) (+)
▾ 인사관리                    v5 작업 중  (⋯)      ← 지금 보는 영역
    사원 · 부서 · 발령 · 근태 · 휴가 · 급여 · 교육   ← 설명 줄(12px 회색)
    모델  표준 맞추기 5  DDL  산출물                 ← 바로가기 줄(13px 회색 링크, 현재 화면은 굵게)
  › 다이어그램 3
  › 엔터티 11
  › 관계 13
  ▾ 표준 용어 · 도메인   용어 56 · 도메인 20
▾ 재무관리                    v2             ← 다른 영역: 펼쳐도 설명 · 바로가기 없음
  › 엔터티 10 …
```
- 설명 · 바로가기는 **지금 영역에만** 보인다(직전 작업에서 기본값을 '지금 영역'으로 바꿈. 거르기 메뉴 '영역 설명' = 지금 영역 · 모두 · 숨김). 그래서 영역마다 모양이 달라 보인다.
- 바로가기는 트리 항목(`role=treeitem` 링크)이고 형제 수에 포함된다. 미준수 수가 숫자로 붙는다(표준 맞추기 5).
- 같은 목적지가 다른 곳에도 있다: 영역 행 ⋯ 메뉴(모델 열기 · 표준 맞추기 · DDL 만들기 · 산출물 · 결재함 열기 …), 각 화면 머리의 경로(통합ERP / 인사관리), 모델 화면 도구.
- 영역 행 = 이름 + 상태 배지 1개. 행 높이 32(영역) · 28(그 밖), 표 밀도 설정을 따름.

## 검토 요청
1. 설명 · 바로가기를 어디에 둘지(영역 안 트리 항목 / 영역 행 자체 / 트리 위 '지금 영역' 막대 / 화면 머리 탭 / ⋯ 메뉴만 등) — 장단점과 권고 1안.
2. 지금 영역과 다른 영역의 일관성 규칙(펼치면 모두 같은 모양인지, 다른 영역은 어떻게 보이는지).
3. '모델 · 표준 맞추기 · DDL · 산출물'을 사용자가 **선택 메뉴로 인지**하게 하는 표현(버튼/세그먼트/아이콘+글자/현재 화면 표시/미준수 수 배지)과 크기 · 대비 · 키보드 · 낭독.
4. 설명 줄의 필요성과 위치(툴팁 · 영역 요약 패널 · 시스템 홈 등).
5. 중복 목적지(⋯ 메뉴 · 경로 · 화면 머리)와의 역할 분담.

## 출력 형식
- 지정 경로에 마크다운. 한 줄 총평 → 지적(`ID · 심각도 · 제목` → 근거(file:line) → 권고) → **권고 구조(텍스트 와이어프레임)** → 적용 범위 · 순서.
- 한국어, 짧고 쉽게. **목업 파일은 수정하지 말 것**.
