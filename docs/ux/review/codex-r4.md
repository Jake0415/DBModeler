# DBModeler 클릭 목업 v4 교차 검토

## 1. 총평

P0 합의 제안은 **35.1% (13/37)**이며, v6 신청과 완료 문서 회수에서 결재 상태를 되돌리는 회귀를 확인했다.  
두 검토는 모델 잠금, 문서 귀속, 표준 적용 범위의 불일치에 수렴한다. v5에서는 화면 간 대상과 실행 결과를 먼저 맞춰야 한다.  
이 문서는 v4 HTML·JS·CSS의 정적 재확인 결과다. 1600px 수치는 CSS 산식이며 브라우저 및 보조기술 실측은 수행하지 않았다.

## 6. 합의 P0 닫힘률과 v5 Top 10

**합의 제안 35.1% (닫힘 13 / 전체 37 ID).** 분모는 `06-ux-review-plan.md` §2 T1~T5의 고유 이전 ID 37개다. CX-47의 T6 중복과 ID 없는 시나리오 행은 분모에 추가하지 않았다. 판정 수는 닫힘 13, 부분 19, 열림 2, 회귀 3이다. 회귀는 CX-13·CX-31·CL-29다.

분자 13개는 CX-20, CX-23, CX2-01, CX2-02, CL-38, CL-05, CL-07, CL-01, CX-11, CL-02, CL-03, CL-08, CL-09다.

1. **업무 영역·버전·결재 상태를 연결한다.** 현재 문서로 잠금·회수·확정본·다음 버전을 정하고, 리스크 링크와 완료 문서의 회수 경계를 확인한다. (CX3-04·16, CL3-01·03·04)
2. **신청마다 올바른 문서와 검토 자료를 만든다.** 신청자·사유·선택·버전·결재선의 스냅숏을 새 ID에 묶고, 원문과 이력을 보존한다. 보완 재신청·성공 배너·비교·산출물은 해당 문서를 참조한다. (CX3-03·15·24, CL3-02·15)
3. **결재 대상·권한·최신 상태를 실행 전에 확인한다.** 링크 가시성, 참조 모드, 확인 모달의 문서 ID를 일치시키고 다중 탭의 오래된 상태가 이력을 덮지 않게 한다. (CX3-01·02·19, CL3-16, CX4-01)
4. **표준 맞추기의 선택과 처리 결과를 연결한다.** 보이는 선택 행과 상태별 허용 동작을 적용하고, 실제 반영 결과와 생성한 신청 번호를 표시한다. 모델 표 보기의 숨은 선택과 참조 건수도 검증한다. (CX3-09·11·13, CL3-05·06·07)
5. **준수율과 확정 검사를 통일한다.** 이름·도메인을 다시 판정하고 분모 0, 예외, 신청 중을 구분한다. 확정 신청과 최종 승인 직전에 검사하고 차단 이유를 표시한다. (CX3-06·07·08, CL3-09·14)
6. **조회 전용과 키보드 조작을 일치시킨다.** 끌기·메모·표준 맞추기 직접 진입에 같은 편집 검사를 적용하고, 캔버스 키와 모달 초점의 범위를 제한한다. (CX3-05·19·25, CL3-08·19)
7. **사유와 엑셀 확인 조건을 제출에 연결한다.** 공백·자동 대체값을 차단하고 후보 확인·충돌 처리 결과를 제출 건수와 일치시킨다. 사유는 결재·감사 이력에 전달한다. (CX3-10·20, CL3-12·13·21, CL-19, CX-17)
8. **영향 계산과 실행 취소를 작업 단위로 연결한다.** FK 매핑이 가리키는 속성만 삭제하고, 토스트와 화면 이동 후에도 요청한 작업을 복구할 수 있게 한다. (CX3-12·14, CL3-10·11, CX4-02)
9. **알림·후보·감사 로그의 대상과 결과를 맞춘다.** 사용자와 문서 단계를 기준으로 알림을 갱신하고, 선택 후보의 상세·안내·처리를 연결한다. 감사 행과 필터는 결재 이력을 기반으로 동작하게 한다. (CX3-17·22·23, CL3-17·18·21·23·24)
10. **세션 셸과 1600px 작업 공간을 정리한다.** 로그아웃·만료 후 셸과 업무 접근을 갱신하고, 패널·툴바·사전 탭을 1600px에서 확인한다. 남은 칩 키보드 조작, 대비, 비활성 사유 표시를 보완한다. (CX3-18, CL3-20·22·25, CL-28·46·47, CX-40)
