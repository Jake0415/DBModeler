# D7 확인 검토: Claude (개선 #8~#16 적용분)

> 대상: 작업 사본 14개 파일. 코드만 읽고 판단했다(브라우저 없음).
> 등급은 상(기능 고장·눈에 띄는 깨짐), 중(의도와 다르게 동작하거나 일관성·접근성 문제), 하(다듬기)다.

## 총평

아홉 가지가 모두 들어갔고 상 등급은 없다.

결재 흐름은 건드리지 않았다(approvals는 막다른 패널 두 곳만 `deadEnd()`로 바꿨다). JS 문법 오류로 보이는 곳도 없다.

잘 된 점:
- 표준 맞추기 두 줄 칸: 현재 값에 취소선을 긋고 `sr-only "현재/제안"`을 붙였다. 열이 8개로 줄었고 빈 상태 `colspan="8"`도 맞췄다.
- 설정 저장: 바뀐 값을 원래 값과 비교해서 세고, 되돌리기·`beforeunload`·저장됨 표시·마지막 변경 표시가 들어갔다.
- 지표 카드를 `.mline`/`.kv`로 바꿨다(모델 4곳, DDL, 사전 공표, system).
- 모델 표 보기: 체크한 뒤 포커스가 유지되고, 바꾸기 입력은 버튼을 눌러 펼친다.
- 404·403 화면에 돌아갈 길이 생겼다.

남은 것은 네 가지다.
- 다크 빈 상태 아이콘 보정이 오히려 밝은 상자를 만든다.
- 홈 1700px 규칙이 1600 미리보기에서 동작하지 않는다.
- 표준 맞추기의 주 행동이 선택이 없으면 사라진다.
- 모델 도구 막대가 캔버스 위쪽을 덮는다.

**하 (5개)**
- `settings.html`: 사용자·역할 탭에서 다른 탭에 저장하지 않은 변경이 있으면 패널의 `○○ 역할 저장`(주 버튼)과 아래 줄 `저장`(주 버튼)이 함께 보여 주 버튼이 둘이 된다. 아래 줄의 저장을 보조로 바꾸거나 사용자 탭에서는 줄을 접는다. `sb-msg`가 `aria-live`라 글자를 칠 때마다 "저장하지 않은 변경 n건"을 다시 읽는다. 줄이 처음 나타날 때만 알린다.
- `settings.html`: 시스템 탭의 DBMS·타입 매핑·이름 템플릿 값은 `saveAll()`이 실제로 저장하지 않는다. 그런데도 비교 기준을 다시 잡고(`snap()`) "저장됨"을 보인다. 새로고침하면 값이 되돌아간다(목업 한계). 저장하지 않는 칸에는 `data-nodirty`를 붙이거나 토스트에 "목업: 시스템 탭은 저장하지 않음"이라고 적는다.
- `settings.html` 탭 표시 점 `sdot run`(#f5a623 고정, 흰 바탕 대비 약 1.9)은 색 점만으로 표시하고 `aria-hidden`이다. 아래 줄이 탭 이름을 말해 주므로 큰 문제는 아니다. 점을 `--ds-amber-700` 토큰으로 바꾸고 탭 버튼 `aria-label`에 "(저장 안 됨)"을 더한다.

- `standardize.html:434`, `system.html:543`: 부연 설명을 `th`·`dt`·`dd`의 `title` 속성에 넣었다("윗줄 현재 · 아랫줄 제안", "작업본 기준"). 키보드·터치로는 볼 수 없다. 표준 맞추기는 칸 안 `sr-only`가 있어 낭독은 되므로 보이는 사람용으로 `listhead`에 한 줄 범례("윗줄 현재 · 아랫줄 제안")를 둔다.

## 확인했고 문제 없음
- approvals `deadEnd()`: 신청번호 찾기는 `canSeeDoc`로 권한을 다시 확인하고, 찾지 못하면 `role=status` 안내 후 입력을 선택한다. `내 신청으로`·`결재함 목록으로`는 탭 포커스까지 옮긴다. 결재 처리 함수(`act`)는 바뀌지 않았다.
- error 404 `검색으로 찾기`: `gsearchOpen`과 `#gs-q`가 app.js에 있고(570·595행), 빠진 대상 이름을 미리 채운다. 403은 역할 변경 요청이 주 행동이다.
- settings 비교: `data-nodirty`(시스템 고르기)는 제외한다. 체크박스는 `checked`로 비교하고, 되돌리기는 `fdT()`까지 다시 그린다.
- 선택 행: 바탕 blue-100 + 첫 칸 2px blue-700 표식. 라이트·다크 모두 hover(gray-100)와 구분된다.
- 다크: `--focus-halo`(.16 흰색), `--overlay`(.62), `--ds-red-800`이 토큰으로 바뀌었다.
- 모델 사전 패널: 1600 틀이거나 창 폭이 1920 미만이면 기본으로 접힌다. 사용자가 고른 값(`dbm-side`)이 우선한다.
