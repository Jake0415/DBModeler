# 표준 사전 엑셀 왕복 편집 플랜 교차 검토

## 1. 총평

1. 내려받기·비교·보정의 방향은 두 검토가 일치한다. W1의 완료 기준은 최종 승인본의 재업로드가 ‘동일’로 판정되고 보류·반려 행도 이어서 작업할 수 있는 것이다.
2. 승인된 기준본, 업로드 작업, 결재 문서의 연결을 먼저 고정해야 한다. 오래된 비교와 대기 신청은 차단하고, 미해결 행과 기존 승인본을 보존한다.
3. Claude R5 39건을 판정했다. 자동 문서 분할과 결재 중 행 제거는 채택하지 않으며, W1의 기본 이력과 W2의 고급 비교 범위를 구분한다.

## 6. 합의

### 플랜에 추가할 것

- **왕복 파일 계약.** 기준본 ID에 기관·종류·시트·필터·실제 포함 행과 승인 버전을 연결한다. 발행 정보 검증, 구 양식·CSV 매핑, 중복 ID·개명·파생값·빈 셀·목록·자료형 규칙을 명시한다. 편집용은 기관 항목만 제공하고 역사본·V0는 열람용으로 구별한다.
- **검사와 최신성 계약.** MD-08의 5색과 ⛔·📝·⚠, MD-09 후보 선택, MD-10 대기 차단을 별도 표시한다. 셀별 세 값 비교와 영향·참조 검사(MD-11·12)를 신청 전에 제공한다. 비교 결과의 파일·초안·사전·공통 적재·검수 기준 개정과 실행 ID를 보존한다. 오래된 제출을 차단하고 MD-20의 각 단계 검사와 최종 승인 반영을 적용한다.
- **신청·복귀·동기화.** 업로드–행–문서 관계를 저장하고 문서별 승인 범위·결재선·사유를 고정한다. 제출 재시도는 같은 신청으로, 보완 재신청은 새 신청번호로 연결한다. 보정본은 원래 기준을 보존한다. 반영본은 최종 승인된 버전을 사용하고 보류·미제출·반려 행의 후속 작업과 개별 파일을 제공한다.
- **보정·복구·권한.** 대상 선택 ID와 변경 전후 미리보기, 작업별 실행 취소, 같은 초안의 오류 행 파일 재병합을 명시한다. 파일과 매핑부터 재개할 수 있게 하고 초안·원본·감사 보관을 구분한다. 검색·공유 링크·내려받기·문서·감사의 권한은 같은 정책으로 판단한다.
- **문서 및 웨이브.** 02 §1·§3.1·§3.3에 SC-15·16 및 결재·재개 경로를 연결한다. 30에는 비교·검사·버전·검사 실행 규칙을, 20에는 ST-R03·04의 W1 완료 조건을 반영한다. W1은 기본 변경 내역·보고서까지, W2 후보는 고급 시점 비교다. 삭제·코드는 30:187의 W2를 따른다.

### 우선순위 Top 10

1. **기준본과 행 식별** — 필터 범위·기관·발행 기준·행 ID·자료형의 왕복 계약과 구 양식 경로를 확정한다(CL5-03,08–11,17,38–39).
2. **낡은 제출 차단과 셀 병합** — 같은 기준본에서 서로 다른 필드를 편집한 경우와 같은 필드를 편집한 경우를 모두 검증한다(CL5-06,13,21, CX6-01–02).
3. **누락·대기·상위 영향·V0 안전장치** — 파일 행 제거와 대기 신청 발생에서 의도하지 않은 변경이 발생하지 않도록 한다(CL5-12,14,16, CX5-09–10).
4. **검사 수준과 후보 선택** — 5색, ⛔·📝·⚠, 후보 확정, 사유 기록과 요약 건수를 연결한다(CL5-04–05,07,24,35).
5. **업로드·신청·반영의 식별과 단위** — 의존성, 불변 결재 범위와 재시도, 단계별 최신 검사, 신청자·결재선·알림 대상·문서 링크를 고정한다(CL5-02,23,33–37, CX5-22).
6. **반영본 동기화와 남은 작업** — 최종 승인본 재업로드의 동일 판정과 보류·반려·회수 후 보완을 검증한다(CL5-01,12,19–20, CX5-17–19).
7. **브라우저 보정 안전성** — 실제 선택·전후 미리보기·작업별 취소와 오류 셀 접근성을 검증한다(CL5-15,18,31, CX5-14–15,30).
8. **대용량·재진입·권한** — 비동기 작업, 초안 충돌·만료, 파일 및 원본 감사, 잘못된 작업 링크·권한을 검증한다(CL5-21–22,30,32, CX6-01,04).
9. **실제 검색·항목 이력** — 최근 변경·전체 검색·공통/기관 초성, 일치 근거, 권한별 조회, 제정차수와 Vn 구분을 검증한다(CL5-25,27,29,31, CX5-23,27–28).
10. **문서·웨이브와 v5 완료 조건** — SC-15 재개, SC-16 기본 보고서, W2 시점 비교·삭제·코드, W1 왕복 실습의 범위를 맞춘다(CL5-16,26–28, CX6-03).
