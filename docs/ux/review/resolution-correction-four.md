> 상태: **Y-01 ~ Y-11 적용 완료**(2026-11-24) — 기록은 [25 §9](../25-correction-flows.md).

## 합의된 수정
| # | 심각도 | 수정 | 근거 |
|---|---|---|---|
| Y-01 | 높음 | **권한 판정은 어디서나 시스템 코드**<br>· 결재 문서는 `sysAt.code` → 영역의 시스템 코드 → 옛 이름 순으로 판정한다.<br>· 모델 · 가져오기 · 홈은 코드를 넘긴다.<br>· 등록할 때 다른 시스템의 코드와 같은 이름, 이름과 같은 코드는 막는다. | CQ-01, UQ-04 |
| Y-02 | 높음 | **일괄 처리 저장 확인**<br>· 영역마다 저장 결과를 확인한다. 복제본 저장이 확인된 뒤에만 원본을 사용 중지한다.<br>· 한 영역이 실패해도 나머지를 계속 처리한다.<br>· 결과와 감사 로그에는 실제 완료 · 실패 · 건너뜀을 남긴다. | CQ-02, UQ-08 |
| Y-03 | 높음 | **참조 다시 잇기 범위**<br>· 이번 실행에서 실제로 성공한 영역의 대응표로, 이번에 만들거나 옮긴 작업 중 영역만 고친다.<br>· 다시 이은 참조는 대상이 아직 확정 전이므로 ‘확정본 기다림’(`refVer` 0)으로 표시한다. | CQ-03 |
| Y-04 | 높음 | **매핑 표 검사**<br>· 빈 칸 · 형식(영문 대문자 타입 + `(n)` · `(p,s)` 인자) · 행끼리 같은 타입을 검사한다. 오류가 있으면 저장하지 않고, 첫 오류 칸에 포커스를 준다.<br>· 변환 때 잘못된 행은 그 DBMS 기본값을 쓴다. | CQ-04, UQ-11 |
| Y-05 | 높음 | **옮긴 시스템의 담당자**<br>· 일괄 미리 보기에 원래 시스템 담당자 목록을 보여 주고, [담당 시스템도 함께 옮기기](기본 켬)를 둔다.<br>· 영역 하나를 옮기거나 복제할 때 대상 시스템에 담당 모델러가 없으면 경고하고 설정 › 사용자 링크를 단다. | UQ-01 |
| Y-06 | 높음 | **홈 화면**: 옛 필드 `m.sys` · `m.dbms` 대신 영역의 시스템 코드로 이름 · DBMS · 내 담당 여부를 정한다. | UQ-03 |
| Y-07 | 중간 | **다음 작업 버전은 빈 이동 목록으로 시작한다.** 확정 사본의 이동 기록은 그대로 둔다. | CQ-05 |
| Y-08 | 중간 | **계정 편집에서 사용 중지 시스템 담당 보존**<br>· 체크박스에 없는 사용 중지 시스템의 담당은 그대로 둔다.<br>· 계정 패널에 ‘사용 중지한 시스템: ○○’으로 표시한다. | CQ-06, UQ-16 |
| Y-09 | 중간 | **일괄 창 흐름**<br>· [모두 처리]는 창 안에서 두 번 눌러 확인한다.<br>· 처리 열에 ‘복제 — 확정 결재 다시 받음(확정본 · 결재 이력)’을 적는다.<br>· 참조 열은 ‘이음 n · 빠짐 m’으로 보인다.<br>· 이름 겹침은 건너뜀 이유와 함께 보인다.<br>· 결과는 제목으로 포커스를 옮기고 낭독되게 한다. 부분 성공에도 대상 시스템 링크를 단다.<br>· Esc · [닫기] 모두 목록을 새로 그린다.<br>· 범위 문구는 ‘사용 중인 업무 영역’으로 쓴다. | CQ-07 · 09, UQ-05 · 06 · 07 |
| Y-10 | 중간 | **원래 이름 되찾기**<br>· 사용 중지한 시스템의 이름은 새 시스템에 다시 쓸 수 있다(코드는 다시 쓸 수 없다).<br>· 결과 창에 순서를 안내한다: 원래 시스템 사용 중지 → [시스템 정보]에서 이름 바꾸기. | UQ-02 |
| Y-11 | 중간 | **매핑 표가 시스템별로 읽히게**<br>· 표 머리에 시스템 이름 · 코드 · DBMS를 적는다.<br>· 길이 조건 · 비고는 DBMS별로 보여 준다.<br>· 저장하지 않은 매핑이 있는 시스템은 선택 상자에 ‘· 저장 안 함’으로 표시한다.<br>· 명명 템플릿 · 시스템 컬럼은 ‘모든 시스템 공통’이라고 적는다. | CQ-08, UQ-12 · 13 |

## 하지 않는 것 (기록)
- 일괄 처리 되돌리기(롤백): 목업에서는 영역 단위 결과와 실패 표시까지 한다. 실제 구현은 서버 트랜잭션으로 한다.
- 담당 시스템 이관 결과를 확인 대상 목록으로 따로 보여 주기(CQ-06 일부): Y-01의 이름 · 코드 충돌 방지로 대신한다.
