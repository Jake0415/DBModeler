## 결정표

### 1. 강조색

| 결정 | **A 청록 채택.** 값은 조정: `--accent #0e6b67`, `--accent-hover #0a5552`, `--accent-soft #e6f1ef`(선택 행 바탕), 다크 `#4fb3ab` / soft `#0f2a28` |
|---|---|
| 이유 | 남색은 잉크(`#1b2128`)와 붙어 강조가 안 되고 "관공서 파랑" 평균값이다. 청록은 SaaS 평균(파랑·보라)에서 벗어나면서 "정합·표준" 의미와 맞는다. |
| 조건 | 성공 녹색과 겹치지 않도록 성공색은 **아이콘에만** 쓴다(글자·배경 금지). 강조색은 링크·포커스 링·선택 행·"내 차례" 네 곳에만. 차트 계열 1개 강조에도 쓴다. 버튼 채움은 계속 잉크. |

### 2. 예외(사유 있는 예외) 상태 색

| 결정 | **다른 안: 새 색을 만들지 않는다.** 무채색 + **점선 테두리** + 깃발 아이콘(`flag`)으로 모양만 구분 |
|---|---|
| 이유 | 예외는 "승인된 이탈"이라 행동이 필요한 상태가 아니다(원칙 1). 갈색 `#7a4e2d`(대비 약 7.1)는 경고 `#8a5a00`과 색상각이 가까워 나란히 놓이면 구분이 안 되고, 경고색 공유는 경고 피로를 키운다. |
| 예외의 예외 | 결재 패널의 "표준 예외 목록" 제목에서 **검토 전**일 때만 건수를 경고색 글자로 표시. 검토 표시 후 무채색. |

| 주의(기한 임박·경고 확인) | `--warning-soft` 채움 + `#8a5a00` 글자 + `alert-triangle` | `2일 · 임박` |
| 오류(반려·미준수·기한 넘김·검사 실패) | `--danger-soft` 채움 + `#b4232a` 글자 + `alert-octagon` | `반려됨`, `미준수 3` |

### 5. 아이콘

| 항목 | 결정 |
|---|---|
| 방식 | `app.js`에 `ICON` 객체 + `icon(name, size=16)` 함수 하나. `stroke="currentColor"`, `fill="none"`, `aria-hidden="true"`, 경로는 Lucide(ISC) 그대로 |
| 크기 | 16px·선 1.5(버튼·행 끝·도구 막대), **12px·선 2**(배지 안 — 1.5는 12px에서 흐려짐). 그 외 크기 금지 |
| 범위(20개로 시작) | 상태 6: `check`, `clock`, `alert-triangle`, `alert-octagon`, `info`, `flag` / 행동 10: `x`, `search`, `chevron-right`, `chevron-down`, `external-link`, `git-compare`, `filter`, `download`, `upload`, `history` / 대상 4: `lock`, `file-text`, `table`, `user` |
| 쓰지 않는 곳 | 구역 제목 앞, 왼쪽 메뉴 항목(글자만), 빈 상태 일러스트, 지표 숫자 옆. **의미가 있는 곳(상태·행동)에만** |
| 교체 | `● ✓ ◆ ℹ ! × ⚠ →` 92곳 → 위 아이콘 또는 삭제. 링크 뒤 `→`는 아이콘이 아니라 **삭제**가 기본 |

### 6. 홈 재구성 — 타일 대신 "업무 일지 + 원장" 구조

화면을 **8:4 비대칭 2단**(왼쪽 약 1100px, 오른쪽 약 540px)으로 나눈다. 같은 크기 타일 격자는 쓰지 않는다.

| 위치 | 구역 | 형태 |
|---|---|---|
| 머리말 | `홈` + `11/19(수)` / 오른쪽 `공통표준 2025.11 · 기관 사전 제정 N차` | 인사말·역할 배지 제거(역할은 상단 바 아바타 메뉴에) |
| 왼쪽 1 | **오늘 할 일** | **표** 1개: `할 일 / 건수(mono, 오른쪽 정렬) / 가장 오래(일) / 기한 / 행동 링크`. 행 32px. 기한 넘김 행만 오류 배지. 0건 항목은 표 아래 한 줄 `문제 없음: 후보 큐, 역할 요청` |
| 오른쪽 1 | **현황** | 타일 5개 → **정의 목록 원장**(재무제표처럼): `항목 / 값 / 기준 / 차이` 4열, 5행. 예 `표준 준수율 · 84% · 목표 90% · −6%p(오류색)`. 숫자 Geist Mono 14/500 오른쪽 정렬. 추세선·누적 막대 삭제 |
| 왼쪽 2 | **업무 영역** | 스테퍼 점(✓ 원·글로우) → 표: `영역 / 시스템·DBMS / 단계(글자 "검토 3/4") / 준수율(숫자 + 60px 가는 막대 + 목표 눈금) / 미준수 / 다음 행동`. 막대 색: 목표 이상 `--fg-3`, 미달만 오류색 |
| 오른쪽 2 | **내 신청** | 짧은 표: `신청번호(mono) / 단계 글자 / 머문 일`. 보완 필요만 오류 배지. 스테퍼 제거 |
| 왼쪽 3 (DA·담당자·Admin) | **통계** | 결재 흐름(가로 막대, 한 색 `--fg-3` + 병목 단계만 강조색), 영역별 준수율(위 표와 중복이면 삭제), 막힘 사유 순위(번호 목록) |
| 오른쪽 3 | 오래 머무는 결재 · 사전 변화 6주 | 표 5행 / 단색 막대 6개(공표 주만 강조색 눈금) |
| 삭제 | 새 기능·공지·릴리스 노트 카드, 최근 관리 이력(Admin은 감사 로그 링크 한 줄) | 상단 바 알림·도움말로 이동 |

- 구역 제목 옆 회색 부연 문구("숫자를 누르면…", "남이 기다리는 일 먼저…") 전부 삭제. 필요하면 열 머리 툴팁.
- 역할별 순서 차이는 유지(Admin·담당자는 현황이 위). 단 **같은 틀**에서 순서만 바뀐다.

## 가장 중요한 변경 5개

1. **상태 배지 규칙 교체(§3)** — 정상은 배지 없음, 진행은 테두리, 주의·오류만 채움, 종류는 글자. 보라 31곳과 파란 알약이 한 번에 사라지며 전 화면 인상이 가장 크게 바뀐다.
2. **토큰 교체 + 청록 강조색(§1)** — 그래파이트 무채색, `--fg-3 #6b7480`, 경고 `#8a5a00`, 반경 4/6/8. 공통 1파일로 전 화면에 적용.
3. **홈의 타일·카드 전면 제거(§4·§6)** — 오늘 할 일 = 표, 현황 = 기준이 붙은 원장, 8:4 비대칭. 인사말·새 기능·공지 삭제.
4. **유니코드 기호 92곳 → SVG 20개 또는 삭제(§5)** — 의미 있는 곳에만, 16/12px 두 크기. `→` 링크 꼬리는 삭제.
5. **결재함 "머문 일" 열 + 패널 지표 한 줄화(§7)** — 색 대신 숫자로 긴급도를 보이고, 패널의 카드·배너·장황한 설명을 걷어 결정에 필요한 것만 남긴다.
