입력: [codex-inspection-policy-v2-impl.md](codex-inspection-policy-v2-impl.md)(높음 3 · 중간 5), [ux-inspection-policy-v2-impl.md](ux-inspection-policy-v2-impl.md)(높음 4 · 중간 9 · 낮음 3)

## 채택 · 반영

| 번호 | 내용 | 반영 |
|---|---|---|
| Codex-1 | 모델 확정 승인 재검사(`modelBad`)가 검수 기준을 안 봄 | `modelBad`가 `entRuleProblems` · `attrRuleProblems` 막기도 셈 |
| Codex-2 | 공통표준 새 판 신청에 기관 규칙이 걸림 | `checkDictDoc`에서 `doc.kind === 'common'`이면 `p.rule` 있는 문제(기관 형식 · 명명 규칙) 제외. 중복 · 참조는 유지 |
| Codex-3 · UX N-02 | 구분자 `-`면 물리명 쪽에서 끝없이 막힘 | 따옴표가 필요한 구분자는 물리명에 대해 **확인(경고)** 으로, "물리명은 `_`로 이어야 통과" 안내, [이 줄 고치기] 없음. 꺼진 규칙은 어긋남 검사에서 제외 |
| Codex-4 | 표준 맞추기 '검수 기준 위반' 행에 처리가 없음 | 선택 가능 + [예외로 유지] · [모델에서 이름 고치기] · [기준 보기] |
| Codex-5 | 결재 검사 탭: 변경 항목 경고 없음 · 단계별 버전 없음 | 변경 항목은 바뀐 뒤 값으로 경고 계산, 승인 이력마다 `policyVer`(신청) · `checkVer`(판정) 기록 |
| Codex-6 | 엑셀 `기호 __ 연속`이 P-FORM으로 안 감 | 정규식 `기호 \S+ 연속` |
| Codex-7 | 본문 없는 옛 버전을 기본값으로 보여 줌 | 변경 이력의 단어 약어 상한으로 다시 만들고 `restored` 표시 → `?v=` 배너에 "이력으로 다시 만든 값" |
| Codex-8 | 판정 케이스 표 없음 | `assets/policy-cases.js` 21건 + `styleguide.html` "검수 기준 판정 자체 점검" — 21/21 통과 |
| UX N-01 | '고른 것만'이 곧바로 '쓰지 않음'으로 돌아감 | 줄마다 고른 것만 상태를 따로 둠(`pickOn`) |
| UX N-03 | 어긋남이 맨 위에만 보이고 저장 단추만 꺼짐 | 해당 줄에 "맞지 않음/확인" 배지, 저장 막대에 "서로 맞지 않는 설정 n개 — 무엇이 맞지 않나" |
| UX N-04 | 제안이 DA에게 가지 않음 · "반려" 문구 | 결재함 위 "검수 기준 변경 제안 n건 [검토하기]"(DA · Admin), 처리 단추 "거절" |
| UX 중간 | 줄 단추 이름 같음 · Esc · 검사 안 함 흐림 | `aria-label="필드명 고치기/변경 제안"`, 펼친 줄에서 Esc로 접고 단추로 포커스, 검사 안 함이면 아래 조건 흐리게 |
