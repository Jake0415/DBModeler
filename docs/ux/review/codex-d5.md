## 가장 먼저 할 5가지

1. **D5-01** 모델 표 보기에서 일괄 적용 범위와 숨겨진 선택을 명확히 한다.
2. **D5-02** 모델의 저장·잠금 상태를 고정하고 준수 해결에서 확정 신청으로 이어지는 주 행동을 정리한다.
3. **D5-05** 결재 상세 첫 화면에 변경 근거와 승인 차단 사유를 올린다.
4. **D5-03** 엑셀 검증의 시작 조건과 단계 사이 행동을 명확히 한다.
5. **D5-04** 1600px 사전 도구 줄을 검색·종류·상세 필터 중심으로 재배치한다.
