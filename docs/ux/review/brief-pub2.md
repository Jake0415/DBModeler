## 볼 것
1. **디자인 일관성**: 페이지 헤더 구성(제목 · 배지 · 보조 · 주 버튼), 탭 종류(밑줄 탭 · 세그먼트 · 칩)의 쓰임, 표 · 배지 · 배너 · 빈 상태 · 패널 폭 · 모달, 간격, 새로 생긴 화면(26 ~ 29)이 기존 부품을 쓰는지(화면 전용 CSS · 인라인 스타일).
2. **문구 · 용어 일관성**: 같은 것을 다르게 부르는 곳(메뉴 · 제목 · 버튼 · 토스트 · 안내 · 문서), 버튼 동사(저장 · 신청 · 확정 · 적용 · 반영 …), 토스트 · 오류 문장의 형식, 확인 창 문구, 역할 이름, ‘·’ 띄어쓰기, 숫자 · 날짜 표기.
3. **화면 안내 · 접근성**: 화면 안내(ⓘ) 유무와 내용, 라벨 · aria, 키보드.
4. 결과는 한국어로, 번호(심각도 높음 · 중간 · 낮음 · 근거 파일:줄 또는 화면 · 고칠 방법). 파일은 고치지 않는다. 마지막에 **문구 · 용어 기준표(기준어 · 쓰지 않는 말 · 예)** 제안을 붙인다.
