# 목업 v2 ↔ DA# 기능 비교

> 작성 2026-11-17 · 기준: DA# 전수 목록 [00-index.md](../spec/da-feature-spec/00-index.md)(M-·W- 항목), 목업 v2 [mockups/](mockups/index.html) 12개 화면.
> 목적: DA#에 있는 기능 중 목업이 **대체·개선한 것 / 빠진 것 / 일부러 뺀 것**을 한눈에 보고, v3 목업과 구현 범위를 정하는 근거로 씀.

## 0. 표기

| 목업 상태 | 의미 |
|---|---|
| ● | 목업에서 **동작**함(클릭·입력하면 결과가 바뀜) |
| ◐ | 화면에 **보이기만** 함(정적 표시·토스트) |
| ○ | 목업에 **없음**(설계 문서에만 있거나 아직 설계 전) |
| — | **일부러 뺌**(범위 밖·다른 방식으로 대체) |

| 비교 | 의미 |
|---|---|
| **개선** | DA# 문제(U-·F-)를 해결하거나 흐름을 줄임 |
| **동등** | DA#와 같은 수준 |
| **부족** | DA#보다 덜 갖춤 → v3·구현에서 보완 필요 |
| **제외** | 의도적으로 뺌 |

중요도(★)·단계(S0~S6)는 00-index를 따름.

**핵심 메시지**
1. 표준화의 뼈대(S0~S5)는 DA#보다 짧고 안전해졌습니다. 같은 DB에 두 번 연결하기(F-03), 등록 용어만 매칭(F-11), 한글 물리명이 경고 없이 나가는 문제(F-16·U-03), FK 0건 DDL(U-02·F-38)을 모두 화면 흐름으로 막았습니다.
2. **부족한 부분은 대부분 '대량 편집과 산출물'** 입니다: 일괄편집·찾기/바꾸기, 표준대상·정보보호 일괄 지정, 테이블 편집창(제약·인덱스), 엑셀·HTML 산출물, 모델 검토 보고서.
3. 서식·인쇄·타 도구 파일 등 데스크톱 전용 기능은 일부러 뺐습니다.
