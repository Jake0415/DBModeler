## 1. 모델러 업무 흐름 기준

```
① 찾아보기 → ② 담기(신규·변경·미사용·삭제) → ③ 검증 → ④ 품의 → ⑤ 추적·보완 → ⑥ 반영 → ⑦ 모델 적용
                 ↑ 엑셀 일괄 / 모델에서 후보 ↑
```

| 단계 | SWS | DA# | 목업 | 가장 큰 차이 |
|---|---|---|---|---|
| ① 찾아보기 | 탭 + 조회 조건(부분일치), URL 조건 보존 | 접두 일치, **빈 검색 0건** | 통합 검색(동의어 · 금칙어 · 초성), 최근 변경 | 목업이 가장 낫다 |
| ② 담기 | 신청 팝업 담기 목록(한 종류), 단어만 기존 불러오기 | 1건 폼 · 엑셀 3종 | 대기 목록(종류 혼합), 변경 1칸 · 미사용 | **기존 항목 여러 칸 변경 · 다중 선택 담기**가 세 곳 모두 약하다 |
| ③ 검증 | **입력 즉시 서버 검증** + 담을 때 재검증 | 중복확인 버튼 | 입력 즉시(클라이언트) + 담을 때 | SWS 수준 규칙 수가 필요(19 §3.2) |
| ④ 품의 | 사유 · 신청번호, 한 종류 | 없음 | 사유 · 결재선 · 참조자 · 신청번호, 종류 혼합 | 목업이 낫다 |
| ⑤ 추적 · 보완 | 대기 건만 목록, 재신청은 같은 내용 | 없음 | 대기함 · 내 신청 · 참조함, **반려 건 고쳐 다시 신청** | 목업이 낫다. 임시 저장은 셋 다 없음 |
| ⑥ 반영 | V+1, 이력 비교, 사용처 경고 | 즉시 반영 | V+1, 이력, 공표, 사용 중 항목 알림 | 비슷함 |
| ⑦ 모델 적용 | 참조 서명 · 재검토 · 선택 반영, 모델 화면에서 신청 경로 없음 | 동기화 3상태 · 자동분석 마법사 | 사전 패널 · 자동완성 · 표준 맞추기 · 후보 큐 | 목업이 낫다. DA# 분해 대안 표시는 가져올 만하다 |
