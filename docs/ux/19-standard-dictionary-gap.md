- **G1-3 공통표준코드 적재 · 용어 연결**(선택 · §5 Q3).
- **G1-4 원본 관리항목 필드**를 엔터티 정의(30 §2.1)에 추가.

## 3. 요구 3 — 지속 업데이트 · 결재 · 오류 검사

### 3.1 결재 (대체로 충분)

있음 ✔
- 사전 신청 문서(폼 · 엑셀 · 표준 맞추기), 결재선 DA(필수) → 최종 승인(기관 설정)
- 같은 항목 중복 신청 차단, 단계마다 재검사 · 실패 시 승인 취소
- 최종 승인에서 반영(V1 · +1), 사용 중 항목 변경 알림, 반려 · 회수 → 다시 신청, 자기 승인 사유
- 제정차수 **공표**(DA 별도 실행)

빠진 것
- **삭제(V0) 신청**이 W2. 영구 삭제만 있다.
- **변경 영향**은 사용처를 ‘이름 · 약어가 같은 컬럼’으로 찾는다. 설계(MD-11 · 51)의 사용처 색인 · 참조 서명 · 재검토 흐름이 목업에 없다.
- 도메인 변경 시 연결 용어 · 코드값 재검사(MD-11)가 없다.

### 3.2 표준화 오류 검사 (가장 부족)

지금 동작하는 검사
- `checkDictDoc`: 이름 공백, 금칙어 포함, 도메인 없음, 용어 약어 30자, 구성 단어 미승인, 단어 약어 누락 · 상한, 이름 중복 · 신청 중, 공통 항목 변경, 변경 칸 없음
- 등록 폼: 필수 · 길이, 이름 중복, 약어 유사 경고, 분해 결과(미등록 · 승인 전 · 1음절)
- 엑셀: D-NOTFOUND · T-SPACE · X-ZERO · X-DUPID · X-NAMEDUP + 기준본 비교 · 대기 확인
- 검수 기준 설정: 표는 있지만 **저장되는 값은 단어 약어 길이 하나**. 표준 제외 규칙 화면은 동작 안 함

빠진 검사 (SWS · DA#에는 있음)

| 대상 | 규칙 | 출처 |
|---|---|---|
| 단어 | 이름 + 약어 완전 중복 ⛔ · 한쪽 중복 📝 · 영문명 중복 ⛔(끌 수 있음) · 동의어/금칙어끼리 충돌 ⛔ · 복합어 중복 ⚠(MD-07) | S · D |
| 약어 공통 | 숫자 시작 · `__` 금지, 허용 문자, **대상 DBMS 예약어**, DBMS 바이트 상한 | S |
| 용어 | 약어 ≠ 단어 약어 조합 ⛔ · 형식단어로 끝나지 않음 ⚠ · 형식단어 분류와 다른 도메인 ⛔ · 이음동의어 → 표준명 치환 · 도메인 필수 | S · D |
| 도메인 · 분류 | 도메인명 ≠ 분류 + 타입 + 길이 ⛔ · 타입별 길이 · 소수점 규칙 · 사용 중 하위 있는데 미사용 ⛔ | S |
| 코드 · 코드값 | 범위(공통/시스템) · 그룹 · 값 중복 · 도메인 규격 · 허용값 · 계층 순환 · 시작일 > 종료일 | S |
| **사전 전체 정합성 점검**(일괄) | 연결 진단 15종(용어→단어 · 도메인→분류→그룹 끊김, 미승인 · 미사용 연결, 기준 서명 변경 …) + DA# 검토(명칭 중복 · 미입력 · 미사용 · 정합성) | S · D |
| 표준 대상 / 비대상 | 비대상 패턴(Pseudo · External · 시스템 컬럼) 자동 판정 | D |

**구조적 문제**: 검사가 화면마다 따로 있다(`checkDictDoc` · 폼 · 엑셀). 설계 v1.2 ⑤는 “프런트 · 서버 · 엑셀이 **공통 규칙 목록 하나**로 같은 결과”를 요구한다. 그런데 규칙 ID · 대상 · 수준 · 실행 시점을 담은 **규칙 카탈로그**가 설계에도 목업에도 없다.

## 5. 결정이 필요한 것

| # | 질문 | 권장 |
|---|---|---|
| Q1 | 사전 범위: 기관 사전 1개(지금 설계) vs **프로젝트(시스템)별 추가 단어 · 용어** | 기관 사전 1개 유지 + 항목에 ‘적용 범위(기관 공통 / 특정 시스템)’ 속성. 코드의 공통/시스템 범위와 같은 방식이다. 프로젝트마다 사전을 따로 두면 같은 이름 다른 약어가 생겨 표준이 깨진다 |
| Q2 | 공통표준 새 판 반영을 결재로 할지 | 관리자 실행 + 판 비교 미리보기 + 반영 기록(결재 아님). 공통 세트는 기관이 고칠 수 없는 원문이라서다. 기관 항목과 충돌하는 건만 DA 처리 목록으로 보낸다 |
| Q3 | 행정표준코드 적재 | 2차. 1차는 용어의 ‘행정표준코드명’ 글자를 보존하고, 코드 그룹 등록 때 참고로 보여 준다 |
| Q4 | 도메인분류 · 그룹 변경을 결재로 할지 | SWS처럼 그룹은 DA 직접 관리(기록 남김), 분류는 도메인 신청과 같은 결재 |
