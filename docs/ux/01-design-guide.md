> - 촘촘한 밀도
> - Pretendard + Geist Mono
> - 목록 + 우측 패널
> - 최신 SaaS 스타일

> - 참조 파일에 없는 것은 DBModeler 기준으로 새로 정의했다. 해당 항목에 **[자체]**로 표시한다.

>   - 업무 도구용 밀도·컴포넌트

## 1. 원칙

| # | 원칙 | 적용 |
|---|---|---|
| 1 | **무채색이 기본, 색은 의미에만** | 화면 대부분은 회색 단계와 잉크색(거의 검정)이다. 색은 표준 상태·결재 상태·오류처럼 **의미가 있을 때만** 쓴다. 장식용 그라데이션은 쓰지 않는다(업무 도구) |
| 2 | **잉크색 버튼은 화면당 하나** | 주 행동 하나만 잉크색 채움(신청 제출·승인·적용). 나머지는 보조(흰 바탕+테두리)나 고스트 |
| 3 | **얇은 선과 낮은 그림자** | 구분은 1px 헤어라인이 기본. 그림자는 떠 있는 요소(드롭다운·모달·토스트)에만 |
| 4 | **촘촘하되 답답하지 않게** | 행·입력 높이는 낮게(32px). 패널 사이 여백과 그룹 간격은 충분히 둔다 |
| 5 | **두 가지 글꼴 목소리** | 한글 UI·본문은 Pretendard. 물리명·약어·코드·DDL·도메인명(`번호V20`)은 Geist Mono → 논리명과 물리명이 한눈에 구분됨 |
| 6 | **색만으로 전달하지 않는다** | 상태는 항상 **색 + 아이콘/글자**로. 표준 4상태·엑셀 5색·결재 상태 모두 레이블을 함께 표시 |
| 7 | **결과는 항상 보인다** | 0건·실패·미산정도 명시. 빈 화면을 정상처럼 두지 않는다(20-priority 공통 UI 규칙) |

## 2. 색 토큰

모든 색은 CSS 변수 토큰으로만 사용한다. 화면 코드에 hex를 직접 쓰지 않는다.

| `--border` | `#ebebeb` | `#2a2a2a` | 1px 헤어라인(구분선·행·입력 테두리) |

## 4. 간격·반경·선·그림자

**간격 (4px 단위)**: `4 · 8 · 12 · 16 · 24 · 32 · 48`
- 셀 안쪽: 세로 0(높이 고정), 가로 12
- 폼 필드 사이: 12. 섹션 사이: 24. 패널 안쪽: 16

**반경**

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--r-sm` | 4px | 배지 아닌 작은 칩, 체크박스 |
| `--r-md` | **6px** | 버튼·입력·선택·드롭다운 (기본) |
| `--r-lg` | 8px | 카드·패널 안 그룹·토스트 |
| `--r-xl` | 12px | 모달 |
| `--r-full` | 9999px | 배지·상태 점·아이콘 버튼·필터 칩 |

마케팅용 100px 알약 버튼은 쓰지 않는다. 앱 버튼은 모두 6px이다(참조 원칙: 한 화면에 두 버튼 모양을 섞지 않음).

**선**: 모두 1px. 포커스는 2px `--focus` 링(바깥 2px 간격).

**그림자 (라이트; 다크는 그림자 대신 `--border` 링 강조)**

| 레벨 | 값 | 쓰임 |
|---|---|---|
| 0 | 없음 | 목록·패널(헤어라인으로 구분) |
| 1 | `0 0 0 1px rgba(0,0,0,.08)` | 카드 테두리 |
| 2 | `0 1px 1px rgba(0,0,0,.02), 0 2px 2px rgba(0,0,0,.04)` + 링 | 고정 헤더가 스크롤될 때 |
| 4 | `0 2px 2px rgba(0,0,0,.04), 0 8px 16px -4px rgba(0,0,0,.04)` + 링 | 토스트·팝오버 |
| 5 | `0 1px 1px rgba(0,0,0,.02), 0 8px 16px -4px rgba(0,0,0,.04), 0 24px 32px -8px rgba(0,0,0,.06)` + 링 | 모달·드롭다운·명령 팔레트 |

```
│ 로고 · 기관명 │ 전역 검색(⌘K) │                    알림 · 사용자     │
├────────┬──────────────────────────────────────────┬──────────────────┤
│ 내비    │ 페이지 헤더 (제목 · 범위 · 주 행동) 56px  │                  │
│ 224px  ├──────────────────────────────────────────┤  우측 패널        │
│ (접힘   │                                          │  420px            │
│  56px)  │  목록 / 캔버스 (가변)                     │  (360~560 조절)   │
│         │                                          │  상세·편집·신청   │
└────────┴──────────────────────────────────────────┴──────────────────┘
```

| 항목 | 값 |
|---|---|
| 기준 해상도 | 1920×1080, **최소 1366px**(모바일 대응 없음) |
| 좌측 내비 | 224px, 접으면 56px(아이콘). 항목: 사전 · 결재 · 시스템 트리(시스템 > 업무 영역) · 설정 |
| 우측 패널 | 기본 420px, 끌어서 360~560px. 닫으면 목록이 넓어짐. **모달 대신 패널**이 기본 |
| 페이지 헤더 | 제목 + 범위 표시(예: `인사시스템 › 급여` 또는 `기관 사전`) + 오른쪽에 주 행동 1개 |

| 최대 폭 | 앱은 전체 폭 사용(문서형 화면만 960px 본문) |

## 6. 컴포넌트

### 6.1 버튼

| 종류 | 모양 | 쓰임 |
|---|---|---|
| Primary | `--ink` 채움, `--on-ink` 글자 | 화면·패널당 1개(신청 제출, 승인, 적용) |
| Secondary | `--surface` + 1px `--border` | 일반 행동(취소, 엑셀 양식, 필터) |
| Ghost | 배경 없음, hover 시 `--surface-2` | 툴바·행 안의 아이콘 행동 |
| Danger | `--danger` 글자 + 테두리, 확인 시에만 채움 | 반려·삭제 신청 |
| 크기 | **32px(기본)** / 28px(표·툴바) / 36px(빈 상태 CTA) | 가로 패딩 12 / 8 / 16 |
| 비활성 | 투명도 50% + **툴팁으로 사유 표시**(필수) | 예: "미준수 3건 — 표준 맞추기에서 해결" |

### 6.2 입력

- 높이 32px, 6px 반경, 1px `--border`, 14px 글자, 가로 패딩 10.
- 오류 상태: `--danger` 테두리 + 아래 12px 사유. 경고 상태는 `--warning` 아이콘 + 사유.
- **선택(콤보박스)은 모두 검색 가능**(DA# F-26·F-40 반영): 타이핑 필터, ↑↓ Enter, 선택 즉시 반영.
- 물리명·약어 입력 칸은 Geist Mono.
- 기본값이 있는 이름 입력은 포커스 시 **전체 선택**(F-47).

### 6.3 표·목록 (핵심)

| 항목 | 값 |
|---|---|
| 행 높이 | **32px**(기본) · 28px(촘촘, 사용자 설정) |
| 헤더 | 32px, `--surface-2` 바탕, 12px `--fg-2`, 고정(sticky), 정렬 ↑↓↕ |
| 구분 | 행 사이 1px `--border`, 줄무늬 없음 |
| hover / 선택 | `--surface-2` / 왼쪽 2px `--ink` 막대 + `--surface-2` |
| 열 폭 | **내용 기준 자동**, 사용자가 조절한 폭은 기억(U-17) |
| 셀 글자 | 13px. 논리명은 Pretendard, 물리명·약어·도메인명 열은 Geist Mono |
| 상태 열 | 상태 배지(§6.4)를 맨 앞 또는 맨 뒤 고정 |
| 결과 표시 | 목록 위에 "N건" 항상 표시, 0건이면 빈 상태 컴포넌트(§6.9) |
| 페이지 | 서버 페이지(50/100/200) + 처음·끝 이동. 업무 영역 범위(수십 테이블)는 한 페이지 |
| 키보드 | ↑↓ 행 이동, Enter 우측 패널 열기, Space 선택 |

### 6.4 배지·칩

- 배지: 9999px, 높이 20px, 12px 글자, 가로 패딩 8. **아이콘 + 레이블**.
  - 상태 배지: `soft` 배경 + `deep` 글자 (예: 표준 = success-soft / success-deep).
  - 출처 배지: `공통` = `--surface-2` + `--fg-2`, `기관` = 투명 + 1px `--ink` 테두리.
- 필터 칩: 높이 28px, 선택 시 `--ink` 채움. 종류(단어·도메인·용어·코드), 출처, 상태 필터에 사용.

### 6.5 우측 패널

- 상단(고정): 제목(16/600) + 출처·상태 배지 + 닫기. 이름은 논리명(Pretendard) 아래 물리명(Geist Mono).
- 본문: 기본 정보 → 탭(사전 상세: **연관 · 사용처 · 이력 · 진행 중 신청**).
- 하단(고정 작업 영역): 왼쪽 위험 행동(삭제 신청), 오른쪽 주 행동(변경 신청/승인).
- 편집 중 다른 행을 누르면 저장하지 않은 내용 경고(패널 안 배너, 모달 아님).

### 6.6 모달 (최소 사용)

다음 경우에만 모달을 쓴다.
- 되돌릴 수 없는 확인(영구 삭제, 반려 확정)
- 파일 선택
- 자기 승인 사유 입력

12px 반경, 그림자 레벨 5, 최대 폭 480px. 오버레이는 `rgba(0,0,0,.4)` [자체]. Escape는 가장 위 모달만 닫는다(편집 취소이지 데이터 삭제가 아님).

### 6.7 결재 단계 표시 [자체]

```
● 신청 ─── ● DA 승인 ─── ○ 최종 승인(기관 담당자)
홍** 11/17   대기 중        사용 안 함이면 표시하지 않음
```
- 완료 = success 점, 진행 중 = info 점(깜박임 없음), 반려 = danger, 미도달 = 빈 원.
- 자기 승인은 단계 옆에 `자기 승인` 배지 + 사유 펼침.

### 6.8 토스트·배너

- 토스트: 오른쪽 아래, 8px 반경, 그림자 레벨 4, 14px. 성공 메시지에 **경고 아이콘 금지**(F-28). 4초 자동 닫힘, 오류 토스트는 수동 닫기.
- 배너: 패널·페이지 상단, 1px 의미색 테두리 + soft 배경. 비활성 사유·게이트 결과·저장 안 된 변경에 사용.

### 6.9 빈 상태·로딩·오류

- 빈 상태: 아이콘(무채색) + 한 줄 설명 + 다음 행동 버튼. 예: "기관 사전이 비어 있습니다 · [단어 추가] [엑셀 가져오기]".
- 로딩: 300ms 넘으면 스켈레톤 행. **긴 작업(엑셀 검증·분석)은 진행률 바 + 취소**, UI를 멈추지 않는다(F-20).
- 오류: 원인 문장 + 조치. 개발자 메시지(예: `CoCreateInstance fail!`) 노출 금지(F-42).

### 6.10 코드·DDL 블록

`--surface-2` 바탕(다크: `#0a0a0a`), 8px 반경, 16px 안쪽 여백, Geist Mono 13px, 줄 번호, 복사 버튼. 게이트 B 결과가 있는 줄은 왼쪽에 danger/warning 막대.

## 7. 아이콘·움직임 [자체]

- 아이콘: 1.5px 선 아이콘 한 세트만 사용(예: Lucide), 16px(표·버튼)·20px(내비). 색은 글자색을 따른다.
- 움직임: 패널 열림 150ms ease-out, 드롭다운 100ms, 토스트 200ms. 장식 애니메이션 없음. `prefers-reduced-motion`이면 즉시 전환.

## 8. 접근성

- 글자 대비 WCAG AA 이상(본문 4.5:1, 큰 글자·아이콘 3:1). `--fg-3`는 메타 정보에만 사용.
- 모든 기능은 키보드로 가능. 포커스 링 항상 표시.
- 명령 팔레트(⌘K / Ctrl+K)로 사전 검색·화면 이동.
