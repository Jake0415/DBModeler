## 0. 사용자 업무 (페르소나)

| 항목 | 내용 |
|---|---|
| 누가 | DA(주로)와 모델러. 기관 사전 수백~수천 건을 **엑셀 파일로 관리**해 왔음 |
| 원본 | 엑셀이 실질적인 작업 원본. 회의·검토도 엑셀로 함 |
| 반복 주기 | ① 시스템에서 현재 사전을 엑셀로 받음 → ② 엑셀에서 고침(추가·수정·미사용) → ③ 다시 올림 → ④ 오류를 고침 → ⑤ 신청·결재 → ⑥ 반영된 결과를 다시 받아 엑셀 원본을 맞춤 |
| 불안한 점 | "내 엑셀과 시스템이 어긋났나?", "누가 그사이에 고쳤나?", "이번에 뭐가 바뀌었나?", "어느 칸이 왜 틀렸나?", "그 단어 예전 이름이 뭐였지?" |

**핵심 요구 5가지**: 수정 버전 · 변경 이력 · 오류 체크와 보정 편의 · 검색 · (그리고 이를 묶는) **엑셀 왕복의 안전성**.

## 1. 현재 설계와의 차이

| # | 필요한 것 | 현재 설계·목업 | 차이 |
|---|---|---|---|
| G1 | **현재 사전을 편집용 엑셀로 내려받기** (항목 ID·버전 포함) | MD-08: 빈 양식 다운로드만. 목업은 "양식 내려받기" 버튼만 | 없음 |
| G2 | **업로드 = 차이 비교** (신규·변경·동일·파일에서 빠짐) | MD-08은 신규 신청 중심, 5색 중 "회색=기등록 동일"·"주황=중복"만 있고 **변경 행 → 변경 신청(MD-10)** 연결 없음 | 변경·빠짐 처리 없음 |
| G3 | **버전 충돌** — 내려받은 뒤 다른 사람이 고친 항목 | MD-08 "미리보기 이후 파일·DB가 바뀌면 ⛔"뿐, 내려받은 시점 기준 비교 없음 | 3방향 비교 없음 |
| G4 | **브라우저 안에서 오류 보정** (다시 엑셀로 가지 않고) | 02-flows §3.3: "오류 행 엑셀로 내려받기 → 원본 고쳐 다시 업로드" | 인라인 보정·자동 수정 제안 없음 |
| G5 | **보정본 내려받기** — 화면에서 고친 내용을 엑셀 원본에 되돌리기 | 없음 | 엑셀 원본과 시스템이 어긋남 |
| G6 | **업로드 이력·임시 저장** — 큰 파일을 여러 번 나눠 작업 | 30 §5: "로컬 파일 추적은 서버 측 업로드 이력으로 대체"라고만 함, 화면 없음. 목업 1단계에 '최근 가져오기' 4행 | 이어서 작업·재열기·비교 없음 |
| G7 | **버전별 변경 이력 화면** | MD-23 있음, 그러나 02-flows §1 "1차 목업에서 뺀 화면(W2)". PN-11 이력 탭 1건 | W2로 미뤄짐 |
| G8 | **기간별 사전 변경 보고서** ("이번 달에 뭐가 바뀌었나") | 없음 (산출물은 모델 기준) | 없음 |
| G9 | **강한 검색** — 약어·영문·동의어·금칙어·과거 이름·사용처·변경일 | 통합 검색·종류 칩만. 목업 검색은 동작 안 함(CX-01) | 대부분 없음 |
| G10 | **같은 검증 규칙을 엑셀·화면·서버에** (30 §4) + 규칙 ID·고치는 법 | 원칙만 있음, 오류 메시지·규칙 ID 체계 없음 | 오류 설명 체계 없음 |

## 2. 설계

### E1. 편집용 내려받기 (G1)

- 위치: 사전 목록 헤더 **[내려받기 ▾] → 편집용 엑셀**(필터 그대로) / 기관 사전 전체 / 빈 양식.
- 통합 문서 구성: `안내` · `단어` · `도메인` · `용어` · `코드` · `목록`(도메인·형식단어·분류 선택 목록) 시트.
- 각 행에 **숨김·보호 열**: 항목 ID · 버전 · 기준 시각(내려받은 시각) · 행 서명. 사용자가 지워도 이름+약어로 다시 짝지음(E2).
- 입력 보조: 선택 목록(도메인그룹·형식단어 Y/N·사용상태), 머리글 메모에 입력 규칙(검수 기준과 같은 값), 양식 버전 `양식 v2` 표기.
- 파일 이름: `KDA표준사전_단어_20261118-0930_기준.xlsx` — 기준 시각이 이름에 들어감.
- **서버 내려받기 기록(기준본)**: 내려받을 때마다 서버가 범위(필터)·기준 시각·항목 ID·버전 목록을 기록하고 파일에 기준본 ID를 넣는다. "파일에서 빠짐"과 버전 충돌은 이 기록으로만 판정한다(파일 안 정보만으로 판정하지 않음).
- **계산 칸은 잠금**: 용어 약어(단어 약어 조합)·도메인명(분류+타입+길이)은 계산 값이라 편집 불가 표시. 바꾸려면 구성 단어·타입·길이를 고친다.
- **신청 중 항목**: 승인된 현재 값을 내보내고 `진행 중 신청 REQ-…` 표시 열을 둔다(신청 값은 넣지 않음).
- 기관 사전만 편집 대상. 공통 항목은 참고 시트(읽기 전용)로만.

### E2. 왕복 업로드 = 차이 비교 (G2·G3)

SC-13 단계를 이렇게 바꿉니다: `1 종류 → 2 업로드 → 3 열 매핑 → 4 검증·비교 → 5 결과 검토·보정 → 6 신청`.

**왕복 계약 (교차 검토로 추가 — 대량 오변경 방지)**

| 규칙 | 내용 |
|---|---|
| 짝짓기 | ① 항목 ID → ② (ID 없으면) 이름+약어 정확 일치 → ③ 이름만 일치하면 "확인 필요". **같은 ID가 두 행**(행 복사)이면 둘 다 오류 |
| 빈 칸 | **"그대로 둠"**이 기본. 값을 지우려면 `#지움` 표시(머리글 메모로 안내). 빈 칸 때문에 값이 사라지는 일 없음 |
| 자료형 | 모든 칸을 **글자**로 읽음. 앞자리 0·날짜·지수 표기 자동 변환 감지 시 경고(예: `0012` → `12`) |
| 인코딩 | CSV는 UTF-8(BOM 유무)·CP949 자동 판별, 깨진 글자 감지 시 차단 |
| 양식 버전 | 구 양식은 머리글 별칭으로 매핑(MD-08), 매핑 결과를 3단계에서 확인 |
| 초기 적재 | 기관 사전이 빈 상태에서 첫 업로드는 **초기 적재 모드**(반영 구분 '초기 적재', 30 History) — 비교 대상이 없으므로 신규만 |

**결과 분류** — 상태(무슨 일인지)와 검사 수준(⛔·📝·⚠, 30 §4)을 **분리**하고, 5색은 **조치 수준**으로 유지합니다(MD-08 색 의미 보존).

| 상태 라벨 | 5색(조치) | 뜻 | 처리 |
|---|---|---|---|
| 신규 | 녹색 | 시스템에 없음 | 등록 신청 |
| **변경** | 녹색 + 바뀐 칸 강조 | 같은 항목, 값이 다름 — 칸별 전 → 후 | **변경 신청(MD-10)** |
| 동일 | 회색 | 바뀐 것 없음 | 제외 |
| **동일 내용 결재 대기** | 파란색 | 같은 항목·같은 값의 신청이 진행 중 | 제외 · 해당 신청 링크 |
| **다른 내용 결재 대기** | 주황색 | 같은 항목에 다른 값의 신청이 진행 중 | 제외(MD-10 ⛔) · **고친 값은 보류 행으로 보존**(사라지지 않음) · 신청 끝나면 [보류 행 다시 검증] |
| **버전 충돌** | 주황색 | 내려받은 뒤 시스템 값이 바뀜 | **칸 단위 3방향 비교**: 다른 칸끼리면 자동 병합 제안, 같은 칸이면 선택(현재 값 유지 기본 / 파일 값으로 변경 신청) |
| 중복·확인 필요 | 주황색 | 이름만 같음·약어 충돌·분해 후보 여러 개(MD-09) | 📝 사유 또는 후보 선택 |
| 선행 승인 필요 | 주황색 | 같은 파일의 **새 단어로 만든 용어** 등 | 보류 → 단어 승인 시 **자동 재검증 + 알림** |
| 오류 | 붉은색 | ⛔ 위반 | 보정해야 신청 |
| **파일에서 빠짐** | 회색 점선 | 기준본 범위에 있었는데 파일에 없음(서버 기록으로 확인될 때만) | **기본 무시.** 미사용은 사용상태 열이나 명시 선택 + 사유 + 영향 확인(MD-12). 삭제는 W2(MD-24, V0) |

- ⚠ 경고는 색과 별개로 아이콘으로 표시하고 신청 시 확인 기록을 남깁니다.
- 통계는 행 단위와 **칸 단위**(바뀐 칸 수)를 함께.
- **낡은 제출 차단**: 신청 직전 서버가 다시 비교하고, 달라진 행만 다시 확인하게 합니다(MD-08 ⛔ 유지 — 전체 차단 대신 달라진 행만). 같은 제출을 다시 눌러도 신청이 두 번 생기지 않습니다(멱등).

### E3. 오류 확인과 브라우저 안 보정 (G4·G10)

- **오류 요약 바**: 규칙별 건수(예: `W-ABBR-LEN 약어 6자 초과 12` · `T-UNREG 미등록 단어 4`) → 누르면 해당 행만.
- **셀 단위 표시**: 오류 칸 붉은 테두리 + 마우스 올림/포커스 시 "무엇이 왜 틀렸고 어떻게 고치는지"(규칙 ID·허용값·예).
- **인라인 편집**: 결과 표에서 바로 고침 → 그 행 **즉시 다시 검증**, 상태 색 갱신. 원본 값은 '파일 값'으로 남아 비교 가능.
- **자동 수정 제안**: 공백·전각·대소문자 정규화, 이음동의어 → 표준명 치환(30 MD-04), 도메인 이름 재구성(분류+타입+길이), 약어 조합값 제안 — 행별 [적용] 또는 같은 규칙 [모두 적용]. **[모두 적용] 전에 대상 행·전후 미리보기**, 적용 후 **그 작업만** 되돌리는 [실행 취소](06 R6).
- **업로드 안 찾아 바꾸기**: 보이는 행만 대상(06 R3 교훈), 실행 전 건수.
- 보정한 칸은 '파일 값 → 보정 값'으로 남아 보정본·감사에 그대로 전달.
- **다음 오류로 이동** (`F8`), 오류만 보기 필터, 진행률("오류 16 → 3").
- 규칙 ID 체계: `W-`(단어)·`D-`(도메인)·`T-`(용어)·`C-`(코드)·`X-`(파일·형식). 검수 기준(SC-43)과 같은 원천에서 나옴 → 엑셀 머리글 메모·화면 툴팁·서버 메시지가 같은 문장.

### E4. 보정본 내려받기 · 업로드 이력 · 임시 저장 (G5·G6)

- **[보정본 내려받기]**: 화면에서 고친 값을 반영한 엑셀 + `변경점` 시트(행·칸·파일 값 → 고친 값·규칙). 엑셀 원본을 시스템과 맞추는 수단.
- **결재 후 동기화**: 신청이 반영되면 알림에 **[반영본 내려받기]** — 새 버전·ID가 들어간 편집용 엑셀.
- **임시 저장**: 5단계에서 자동 저장. 업로드 이력에서 [이어서 작업]. 30일 보관.
- **업로드 이력 화면(SC-15)**: 파일명·종류·올린 사람·시각·행 수·결과(신규/변경/동일/충돌/오류/보류)·**연결 신청번호**·상태(임시 저장/검증 중/신청됨/일부 반영/반려·회수/취소). 원본 파일 다시 받기. 열람 권한: 올린 사람·DA.
- **반복 주기의 복귀 경로**: 반려·회수된 신청과 보류 행은 [그 업로드로 돌아가 보정] → 고쳐서 **새 신청번호로 재신청**(MD-21). 반영본을 다시 올리면 모두 '동일'로 판정되는 것이 왕복 완료 조건.
- 같은 업로드의 숫자(신규·변경·보류·신청 건수)는 결과 화면·결재 문서·알림이 **같은 업로드 묶음 데이터**를 읽음(06 R2·R4 재발 방지).

### E5. 수정 버전 · 변경 이력 (G7·G8)

버전은 세 층으로 보여 줍니다(06 §3.1과 같은 원칙 — 이름과 자리를 다르게):

| 층 | 예 | 의미 | 보이는 곳 |
|---|---|---|---|
| 항목 버전 | `V3` | 승인된 변경마다 +1 (30 §2 버전 규칙) | 목록 열·상세·엑셀 숨김 열 |
| 사전 기준 시각 | `2026-11-18 09:30 기준` | 내려받기·비교·보고서의 기준점 | 내려받기 파일명·업로드 비교·보고서 |
| 제정차수 | `기관 사전 제정 12차` | 원문 메타데이터(공식 공표 단위). 항목마다 갖는 속성(30 Word·Domain·Term) | 사전 헤더·항목 상세·산출물 표지 |

- **제정차수 규칙(합의)**: 결재 반영은 **항목 버전(Vn)만** 올린다. 제정차수는 원문 값을 보존하고, 기관이 자체 차수를 올리는 것은 **DA의 명시적 공표**로만 한다. 목업의 사전 승인 토스트 "제정 13차"는 잘못된 표현이라 v5에서 제거.

- **항목 이력(PN-11 이력 탭 확장)**: V1 → V2 → V3 타임라인, 각 버전의 **필드별 전후 비교**(NULL·빈 문자열·0 구분, MD-23), 반영 구분(초기 적재/데이터 보완/사용자 변경 승인), 신청번호·결재자·사유, **그 버전을 엑셀로**.
- **사전 변경 내역 화면(SC-16)**: W1 = 기간·종류·변경 구분(추가/변경/미사용)·사람·신청번호로 검색 → 목록·필드 비교 → **엑셀 보고서**. W2 = 두 기준 시각 비교("11/03 대비 11/18", History로 그 시점 상태 재구성)·삭제 보관 표시.
- 참고: 30에서 MD-23(버전별 이력)은 이미 W1. W2로 미뤄진 것은 02-flows의 **전체 이력 화면**뿐이었으므로, 그 화면을 SC-16으로 W1에 올린다.
- **모델 영향 연결**: 변경 내역 행마다 "모델 사용처 N" → 재검토 알림(MD-11·43)과 연결.
- 원칙: 이력은 **추가만**(06 R2와 같은 규칙), 삭제는 V0 보관(MD-24).
