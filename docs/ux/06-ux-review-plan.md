### 0.1 교차 검토에서 합의한 판단 원칙

| 원칙 | 내용 | 예 |
|---|---|---|

| 후속 차수로 정한 기능은 올리지 않는다 | 02-flows에서 미룬 범위(코드값 전용 관리, DBMS 접속)는 안내 문구 일치만 요구 | CL-11, CL-41 → 하 |

### T8 사전·엑셀·후보 흐름 — P1

CX-01~07 · CX-14~17 · CL-11~20 · CL2-01 · CL2-03 · CL2-06. 핵심만:
- 검색어·출처·신청 중·도메인그룹을 결합해 결과 수와 **0건 빈 상태**를 갱신(CX-01·CL-13).
- 행별 상세, 공통 항목은 **읽기 전용**(CX-02·CL-14). 엔터티 용어·코드 신청 폼 분리(CX-03·CL-11, 코드값 전용 관리는 후속).
- 대기 목록 추가·수정·삭제와 패널 닫기 시 "임시 저장/버리기"(CX-04·CL2-01). 삭제·미사용 신청 + 사용처 영향(CL-12).
- 엑셀: 종류 카드 선택·파일 필수·검증 중 버튼 잠금·타이머 정리(CX-14·16·CL-17·18), 상태 용어 하나로 통일(CL-20).

### T9 1600 작업 공간·패널 — P1

- 사전 패널 접은 뒤 캔버스 왼쪽에 **[사전 ▸] 탭**(CL-25·CX-38).
- 우측 패널 **닫기·폭 조절(380~560)**, 모델 화면은 내비 기본 접기(아이콘 레일) 검토(CL-26·CX-37). 1600 캔버스는 현재 약 756px.

### T10 접근성 기반 — P1 (공통 컴포넌트에서 한 번에)
