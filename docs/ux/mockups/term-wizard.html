    ① 대상 선택

    분석할 업무 영역·테이블과 이름을 읽는 규칙을 정합니다. 모델은 이 단계에서 바뀌지 않습니다.
    테이블(엔터티)
    분석 기준
    대상 범위
    설정의 표준 제외 규칙을 기본값으로 가져옵니다. 여기서 고친 규칙은 이번 분석에만 씁니다.

    ② 분석 결과

    상태테이블현재 이름현재 물리명최적 후보 용어약어(물리명)도메인점수근거단어 구성

    ③ 단어 구성

      ④ 용어 등록

      ②에서 포함한 항목의 선택한 분해로 계산합니다. 사전에 이미 있는 용어는 할 일이 없습니다.
      구분이름약어도메인쓰는 곳상태
      바구니는 표준 사전의 [신청 바구니]에서 이어서 신청합니다. 후보 큐는 DA가 검토합니다(후보 큐).

      ⑤ 모델 반영

      체크한 행만 작업 버전에 반영합니다. 신청 중인 용어는 ‘신청 중’ 상태로, 미등록 단어가 남은 항목은 이름만 맞추고 미등록으로 남습니다.
      테이블논리명물리명타입반영 뒤 상태

      바로 신청

      같은 신청 안에서 새 단어 → 용어 순서로 정렬합니다. 신청 뒤 ⑤에서 이 용어를 쓰는 항목은 ‘신청 중’으로 반영됩니다.
