[바구니로 보내기]는 신청할 행을 내 바구니에 담습니다. 사전 화면에서 손으로 고른 항목(새 단어·용어 변경 등)과 한 신청으로 묶어 올릴 때 쓰세요. 바로 [신청]하면 이 파일의 행만 따로 신청됩니다. 바구니에 같은 항목이 이미 있으면 건너뜁니다.
