축약명논리 타입인자종류적용 범위예 · 도메인속성상태
축약명은 도메인 이름(분류명 + 축약명 + 길이)에 들어갑니다 — 표준은 영문 대문자 1자, 추가 · DBMS 전용은 2~3자. 쓰는 곳이 있는 축약명은 바꾸지 않고 [새 축약명으로 옮기기]로 도메인 이름까지 함께 바꿉니다.
축약명논리 타입종류길이 범위 → 물리 타입점검
범위는 길이(숫자는 정밀도, 일시는 초 아래 자릿수) 기준입니다. 끝을 비우면 ‘끝없음’. 범위가 겹치거나 빈 구간이 있으면 저장되지 않습니다. 매핑이 빈 타입을 쓰는 컬럼은 DDL 전 점검에서 막습니다. 다른 시스템으로 옮기거나 복제할 때도 이 규칙으로 타입을 바꿉니다.
