엑셀 파일을 올립니다

1. 양식 받기

시트 ‘테이블 설계’ 한 장에 한 행 = 한 컬럼으로 씁니다. 테이블 물리명 · 논리명 · 설명은 모든 행에 반복합니다. 필수 열: 테이블 물리명 · 컬럼 물리명 · 컬럼 논리명 · 컬럼 타입.

관계는 참조 테이블 · 참조 컬럼으로 적습니다(부모 PK 전체). 관계명은 가져온 뒤 ERD에서 입력합니다. 인덱스는 엑셀로 받지 않습니다.

2. 파일 올리기

.xlsx 파일을 끌어 놓거나 눌러서 고르세요 SWS 테이블 설계 양식 · 예전 18열 양식도 읽습니다 · 10MB까지
파일 없이 시험:
순서: 파일 → 가져올 위치 → 검사 · 미리보기 → 완료. 검사는 고른 위치를 기준으로 합니다. 업로드 때는 파일 · 구조 오류(빈 칸 · 중복 · 참조 오류)만 막고, 원본 이름 · 타입은 고치지 않습니다. 표준 사전 판정 · 구조 점검은 가져온 뒤 모델에서 합니다.
