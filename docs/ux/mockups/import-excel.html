모델 엑셀 가져오기(정의서)

엑셀 파일을 올립니다

1. 양식 내려받기

시트 ‘테이블 설계’ 한 장에 한 행 = 한 컬럼으로 씁니다. 테이블 물리명 · 논리명 · 설명은 모든 행에 반복합니다. 필수 열: 테이블 물리명 · 컬럼 물리명 · 컬럼 논리명 · 컬럼 타입.

관계는 참조 테이블 · 참조 컬럼으로 적습니다(부모 PK 전체). 관계명은 가져온 뒤 ERD에서 입력합니다. 인덱스는 엑셀로 받지 않습니다.

2. 파일 올리기

.xlsx 파일을 끌어 놓거나 눌러서 고르세요 SWS 테이블 설계 양식 · 예전 18열 양식도 읽습니다 · 10MB까지
파일 없이 시험:
순서: 파일 → 가져올 위치 → 검사 · 미리보기 → 완료. 검사는 고른 위치를 기준으로 합니다. 업로드 때는 빈 칸 · 이름 중복만 막고, 참조 오류 · 타입 같은 나머지는 경고로 알린 뒤 가져옵니다. 원본 이름 · 타입은 고치지 않습니다. 표준 맞추기 · 모델 검증은 가져온 뒤 모델에서 합니다.

어디로 가져올까요?

이 엑셀로 업무 영역(v1 작업 버전)을 만듭니다
작업 중이고 편집 권한이 있는 영역에만 올릴 수 있습니다
추가만 — 엑셀의 새 테이블만 추가합니다. 같은 시스템에 논리명 또는 물리명이 같은 테이블이 이미 있으면 그 테이블은 추가하지 않고, 기존 테이블 · 관계는 바꾸지 않습니다. 기존 테이블을 바꾸려면 모델에서 고치거나 삭제한 뒤 다시 올리세요.
