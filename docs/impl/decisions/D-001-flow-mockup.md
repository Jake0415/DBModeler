## 결정과 이유
- **R6-1: 기각** — 목업 브라우저 저장소에만 있는, 이번 세션 중간에 생긴 일시 초안 문제다. 실제 사용자 데이터가 없고, 구현(T-P2-504 · 마법사)은 처음부터 초안 형식 버전을 저장한다(사양 문장으로 남김: 02-flows §5.3 · MD-56 ‘초안은 형식 버전을 함께 저장’).
- **R6-2: 보류(구현에서 처리)** — 목업 동작을 더 바꾸는 것은 자체 결정 금지 영역(목업 동작 변경)이라 보류만 가능. 지금 동작은 FK를 잘못 만들지 않는 보수적 방향이다. 구현 사양은 02-flows §5.6.1 ‘미처리 판정은 그 접두어 묶음에만’으로 명확하므로 T-P2-406 구현과 E2E에서 그 규칙을 따른다 → 후속 F-019(높음).
- 그 밖의 결정 범위 안 항목은 모두 반영 · 검증됨 → 이번 변경 **채택**.

## 영향 범위
모델 검증 일괄 처리(FK 후보 [관계 한 번에 만들기])의 드문 복합 키 사례, 용어 자동분석의 목업 초안 복원. 권한표 · 다른 화면 영향 없음.

이 결정을 담은 커밋을 되돌리면 흐름 잇기 목업 전체가 되돌아간다. R6-2만 다시 다룰 때는 model.html `bulkFk`의 묶음 미처리 판정을 접두어 묶음 단위로 바꾼다.
