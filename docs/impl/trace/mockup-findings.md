# 목업 점검 메모 — 동작 목록 작성 중 발견 (2026-11-25)

> 화면 동작 목록(`behaviors/*.json`)을 쓰면서 하위 에이전트가 찾은 **목업과 문서가 어긋나거나 목업이 흉내만 내는 동작**. 해당 동작 행에는 `expected` 끝에 ‘(목업에서 확인 필요)’가 붙어 있다.
