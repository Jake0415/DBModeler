# 화면 동작 목록 작성 규칙

> 목적: 목업의 **사용자가 관찰할 수 있는 동작을 하나도 빠짐없이** 행으로 만든다. 각 행은 구현 작업과 인수 테스트에 연결되고, `npm run trace:check`가 테스트 없는 행을 실패로 센다(계획 §15).
> 원본: `docs/ux/mockups/<화면>.html` + 그 화면이 쓰는 `docs/ux/mockups/assets/app.js` 함수. 화면 · 상태 목록: `docs/impl/screen-manifest.json`. 권한: `docs/impl/rbac-matrix.md`.

## 파일
`docs/impl/trace/behaviors/<화면 파일 이름에서 .html 뺀 것>.json` (공통 셸은 `_shell.json`), UTF-8, 2칸 들여쓰기.

```json
{
  "screen": "approvals.html",
  "ids": "SC-20 · PN-21 · MO-22 · MO-23",
  "source": "docs/ux/mockups/approvals.html",
  "behaviors": [
    {
      "id": "BH-approvals-001",
      "where": "대기함 목록",
      "trigger": "버튼 '승인' 클릭",
      "expected": "자기 승인이면 MO-22 확인 창, 아니면 승인 처리 후 다음 단계로 이동하고 대기함에서 사라짐",
      "roles": "appr.da 가진 담당 시스템 DA · 대리인",
      "refs": ["appr.da", "R-02", "MO-22"],
      "states": ["approvals.html?doc=REQ-2026-0016"],
      "verify": "e2e"
    }
  ]
}
```

## 필드
| 필드 | 뜻 |
|---|---|
| `id` | `BH-<화면>-<세 자리 번호>` — 화면 안에서 위에서 아래 순서 |
| `where` | 화면 안 위치(영역 · 패널 · 탭 · 창) |
| `trigger` | 사용자가 하는 일(클릭 · 입력 · 단축키 · 끌기 · 주소 열기) 또는 자동 조건(‘데이터가 없을 때’, ‘권한이 없을 때’) |
| `expected` | 관찰할 수 있는 결과 — 화면 변화 · 문구(목업 그대로) · 상태 저장 · 다른 화면/계정에서 보이는 변화 · 오류 문구 |
| `roles` | 누가 할 수 있는지(권한 id · 역할 · 조건). 모두면 `전체` |
| `refs` | 관련 ID — 권한 id(`appr.da`) · 요구 ID(`ST-R08`) · 메타 규칙(`MD-03`) · RBAC(`R-02`) · 화면/패널(`PN-21`). 확실한 것만 |
| `states` | 이 동작을 볼 수 있는 목업 주소(screen-manifest의 상태 주소 우선) |
| `verify` | `e2e`(화면 · API로 검증) · `unit`(순수 규칙 함수로 충분) · `exempt`(검증 제외) |
| `exemptReason` | `verify: exempt`일 때만, 필수 — 예: ‘목업 전용 데모 기능(역할 바꾸기)’, ‘W2 범위 — 20 §2’ |

## 행을 만드는 기준
- **한 행 = 하나의 관찰 가능한 동작.** 버튼 · 링크 · 입력 검증 · 단축키 · 오른쪽 클릭 메뉴 · 끌어 놓기 · 자동 계산 표시 · 빈 상태 · 오류 · 권한별 표시(숨김/흐리게 + 이유)를 각각 센다.
- 같은 동작을 하는 반복 요소(목록의 행마다 같은 버튼)는 한 행으로.
- **권한에 따라 달라지면 나눈다**: 예) ‘DA에게 [승인] 보임’ · ‘모델러에게 [승인] 숨김’ · ‘임시 비밀번호 DA에게 흐리게 + 이유’.
- 입력 검증은 규칙마다 한 행(예: 길이 초과 · 중복 · 금칙어).
- 목업에만 있는 데모 장치(목업 배지 · 역할 바꾸기 · `?as=` · 초기화 버튼 등)는 `exempt` + 사유.
- **W2 범위 동작은 제외가 아니다** — 추출 스크립트가 P5(W2)로 배정한다. 제외(`exempt`)는 ‘구현하지 않는 것’에만.
- 확실하지 않은 동작은 `expected` 끝에 ‘(목업에서 확인 필요)’를 붙인다 — 지어내지 않는다.
- 목업 문구는 그대로 옮긴다(따옴표).
